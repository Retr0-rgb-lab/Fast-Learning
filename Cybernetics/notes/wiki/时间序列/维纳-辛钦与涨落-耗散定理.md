# 维纳-辛钦与涨落-耗散定理

## 一句话
两条硬定理把自相关、功率谱、记忆核**焊死成同一件事的三张面孔**：维纳-辛钦（$R \leftrightarrow S$，时域↔频域）与涨落-耗散（$K \leftrightarrow R$，沃尔泰拉积分方程——耗散与涨落同源）。

```
                │   X(t)  原始信号    │ ← 一切起点：温度、心率、粒子位置、股价
                └─────────┬──────────┘
                          │  自相关 R(τ) = E[X(t)X(t+τ)]   —— 第一步加工
                          ▼

                │  时间域  R(τ)      │ ← "信号跟自己隔 τ 还像不像"
                └────────┬─────┬─────┘
                         │     │  傅里叶变换（Wiener–Khinchin 定理）
                         │     ▼
                         │  ┌────────────────────┐
                         │  │  频率域  S(ω)      │ ← "慢波动占多少能量？快波动占多少？"
                         │  └─────────┬──────────┘
                         │            │  涨落–耗散（沃尔泰拉积分方程）
                         │            ▼
                         │  ┌────────────────────┐
                         └──┤  因果核  K(t−s)    │ ← "过去的状态现在还剩多少劲"
                            └────────────────────┘

```

> **记忆顺序提示**：图要从 **X(t) 往下读**，不要从 K 往上读。信号 → R（像不像）→ S（啥节奏）→ K（怎么因果）。记忆核是**最戏剧性但最不基础**的一个——它是衍生物，靠 R/S 才有意义。

## 定理一：Wiener–Khinchin（R ↔ S）
$$S(\omega) = \int_{-\infty}^{\infty} R(\tau)\,e^{-i\omega\tau}\,d\tau \qquad \Longleftrightarrow \qquad R(\tau) = \frac{1}{2\pi}\int_{-\infty}^{\infty} S(\omega)\,e^{i\omega\tau}\,d\omega$$

自相关与功率谱互为傅里叶变换对，时域卷积 $\leftrightarrow$ 频域乘积是核心操作。定义与直觉见 [[自相关函数]]、[[功率谱]]。

## 定理二：涨落-耗散（K ↔ R）
$$\frac{dR(\tau)}{d\tau} = -\int_0^\tau K(u)\,R(\tau-u)\,du$$

方程右边是 $K$ 和 $R$ 的**卷积**——记忆核 $K$（耗散/摩擦）和自相关 $R$（涨落/噪声的统计）**不是独立的**。耗散（摩擦带走能量）与涨落（噪声注入）**出自同一来源**，即涨落-耗散定理雏形。

## 六步推导链（完整骨架）
### ① 朗之万方程（无记忆）
$$\frac{dx(t)}{dt} = -\gamma x(t) + \eta(t)$$——摩擦力（瞬时响应）+ 随机噪声（热涨落），**只有"现在"**。

### ② 广义朗之万（记忆核登场）
$$\frac{dx(t)}{dt} = -\int_0^t K(t-s)\,x(s)\,ds + \eta(t)$$——$K(t-s)$ 衡量过去状态的残留影响，只对 $s<t$ 积分（因果性）。

### ③ 两边乘 x(t′)，取平均（t′<t）
$$\frac{d}{dt}\mathbb{E}[x(t)x(t')] = -\int_0^t K(t-s)\,\mathbb{E}[x(s)x(t')]\,ds + \mathbb{E}[\eta(t)x(t')]$$

### ④ 平稳 + 噪声无关联 → 沃尔泰拉方程
平稳假设 $\mathbb{E}[x(t)x(t')]=R(t-t')$；噪声无关联（因果）$t>t'$ 时 $\mathbb{E}[\eta(t)x(t')]=0$。令 $\tau=t-t'$、$u=t-s$：

$$\frac{dR(\tau)}{d\tau} = -\int_0^\tau K(u)\,R(\tau-u)\,du$$

右边是 $K$ 与 $R$ 的**卷积**——涨落-耗散雏形就此成立。

### ⑤ δ 函数退化 → 指数衰减
直接全量傅里叶变换是**平凡陷阱**：$-i\omega\tilde R=-\tilde K\tilde R\Rightarrow\tilde K(\omega)=i\omega$，$K$ 被消掉、什么都没学到。原因：只写了耗散半边、没写噪声自相关（涨落半边）。有意义的退化是瞬时响应 $K(t-s)=\gamma\delta(t-s)$：

$$\frac{dR}{d\tau} = -\gamma R(\tau) \;\Longrightarrow\; R(\tau) = R(0)\,e^{-\gamma\tau}$$

### ⑥ 傅里叶 → 洛伦兹谱
$$S(\omega) = \int_{-\infty}^{\infty} R(\tau)e^{-i\omega\tau}d\tau = \frac{2\gamma R(0)}{\gamma^2 + \omega^2}$$——低频胖、高频瘦。闭环：**OU 动力学 → R 指数衰减 → S 洛伦兹**，每个环节都从上一个推导出来。
