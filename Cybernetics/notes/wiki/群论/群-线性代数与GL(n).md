# 群-线性代数与GL(n)

> **一句话**：线性代数 ≠ 一个群。它是整个工具箱，其中"**可以翻过去再翻回来**"的那一类操作——可逆矩阵——构成群 **GL(n)**。

## 最经典的例子：可逆矩阵 GL(n)

把 $n\times n$ 的可逆矩阵（行列式不为零）全部收集起来，配上矩阵乘法：

| 公理 | 在矩阵世界 |
|------|-----------|
| 集合 | 所有可逆的 $n\times n$ 矩阵 |
| 运算 | 矩阵乘法 |
| 封闭性 | 可逆矩阵相乘仍可逆 |
| 结合律 | 矩阵乘法天然满足 |
| 单位元 | 单位矩阵 $I$（乘它等于没乘） |
| 逆元 | 每个 $A$ 都有 $A^{-1}$ |

四条全满足 → 全体可逆 $n\times n$ 矩阵是一个群，记作 **GL(n)**（General Linear group，一般线性群）。行列式条件恰好保证逆元存在：

$$\det A\neq 0 \iff A^{-1}\ \text{存在}$$

## 但整个线性代数不只是群

- **向量本身不是群**（乘法意义下）——没有"逆向量"的概念，不能让一个向量变成"反操作"去抵消
- **零矩阵没有逆**，不可逆矩阵进不了 GL(n)：$\det A=0$ 会把信息压扁，无法还原
- 加法下所有 $n$ 维向量构成的是**加法群** $(\mathbb{R}^n,+)$——同一个集合配上不同运算，是不同的代数结构

> 一句话：线性代数 = 整个工具箱；GL(n) = 工具箱里"可以翻过去再翻回来"的那一类操作。群描述的是**变换之间的关系**，向量只是变换作用的空间。

## 为什么物理学家特别爱用群

物理里的"变换"恰好就是矩阵乘法：

- **旋转**：三维旋转构成**旋转群 SO(3)**——保持长度不变的正交矩阵
- **时空旋转**：狭义相对论的坐标变换构成**洛伦兹群**
- **连续对称**：旋转可以任意小角度，是"连续"的群，叫**李群**（Lie group）
- **粒子分类**：SU(2)、SU(3) 描述基本粒子的内部对称性

> 物理学家爱用群的深层原因：**一条守恒定律 = 一个对称群**（诺特定理）——群是给自然"分类"的骨架。
