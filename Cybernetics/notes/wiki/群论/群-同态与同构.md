# 群-同态与同构

> **一句话**：同态是保持运算的"翻译"（可以多对一）；同构是保持运算的一一对应（双射）——两个群同构，说明它们只是"穿了不同衣服"的同一个东西。

## 同态（homomorphism）：保持运算的翻译

想象两个公司各有内部规矩（A 公司握手、B 公司抱拳）。来了个翻译把 A 公司员工映射到 B 公司，同态要求：

> 不管两个人在 A 公司怎么打招呼，翻译过去之后，对应的人在 B 公司必须用 B 的方式"做同一件事"。

符号：

$$
f(x\cdot y) = f(x)*f(y)
$$

**例子**：$\mathbb{Z}_6 \to \mathbb{Z}_3$，映射是"取模" $f(x)=x\bmod 3$。
- $f(1+5)=f(6)=0$
- $f(1)+f(5)=1+2=3\equiv0$ ✓

同态就是保持运算结构的对应关系，群与群之间的"翻译规则"。可以**多对一**（多个元素映到同一个）。

## 同构（isomorphism）：完美一一对应

同构 = 同态 + 双射（一一对应）。

- 同态：只要翻译过去"运算对得上"就行，可以多个映一个
- 同构：必须一一对应且保持运算

> 直观说：两个群同构，只是"穿了不同衣服"的同一个东西——元素个数、单位元、互逆关系、交换性等所有结构性质都完全一样，只是名字不同。

## 用 $\mathbb{Z}_6/\{0,3\}$ 举例

商群 $\mathbb{Z}_6/\{0,3\}$：
- 元素：$\{0,3\},\{1,4\},\{2,5\}$，运算是陪集相加
- 单位元 $\{0,3\}$；$\{2,5\}$ 和 $\{1,4\}$ 互逆

$\mathbb{Z}_3$：元素 $0,1,2$，模 3 加法，$2$ 和 $1$ 互逆。

两者结构一模一样。映射 $\phi$：$\{0,3\}\to0$，$\{1,4\}\to1$，$\{2,5\}\to2$，验证：

$$
\phi(\{1,4\}+\{2,5\}) = \phi(\{0,3\}) = 0 = 1+2 = \phi(\{1,4\})+\phi(\{2,5\})
$$

所以 $\mathbb{Z}_6/\{0,3\} \cong \mathbb{Z}_3$。

## 一句话总结

- 同态 = 保持运算的映射（可以多对一）
- 同构 = 保持运算的一一对应映射（同态 + 双射）
- 商群 = 用正规子群把原群"折叠"得到的新群，本质是让"陪集之间"的运算变得合法

到这里，群论最核心的概念——群、子群、商群、同态、同构——就串成了一条线。
