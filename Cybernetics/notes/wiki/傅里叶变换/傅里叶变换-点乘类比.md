# 傅里叶变换-点乘类比

> **一句话**：傅里叶变换和向量点乘是同一件事——因为**基之间互相垂直，所以用基去"点乘"原函数，其他分量全部被消掉，只剩自己要的那一个**。这就是傅里叶变换全部的秘密。

## 为什么 $a = \vec{v}\cdot\hat{e}_1$

设 $\hat{e}_1, \hat{e}_2$ 是互相垂直的单位向量，任何 2D 向量可唯一写成 $\vec{v} = a\hat{e}_1 + b\hat{e}_2$。怎么把系数 $a$ 拎出来？两边点乘 $\hat{e}_1$：

$$
\vec{v}\cdot\hat{e}_1 = (a\hat{e}_1+b\hat{e}_2)\cdot\hat{e}_1 = a(\hat{e}_1\cdot\hat{e}_1) + b(\hat{e}_2\cdot\hat{e}_1)
$$

点乘只用三条代数规则（不看几何）：

- **跟自己点乘 = 长度平方**：$\hat{e}_1\cdot\hat{e}_1=1$
- **垂直的两个向量点乘为 0**：$\hat{e}_2\cdot\hat{e}_1=0$
- 分配律

代入即得 $\vec{v}\cdot\hat{e}_1 = a\cdot 1 + b\cdot 0 = a$。

> 核心不是"我聪明所以 a 等于点乘"，而是"因为基正交，点乘一下其他分量全消掉，只剩自己要的那个"。**$b\hat{e}_2$ 在 $\hat{e}_1$ 方向上的投影是 0（因为垂直），所以点乘一过，只剩下 $a$。**

## 类比表：向量世界 vs 傅里叶世界

| 向量世界 | 傅里叶世界 |
|---|---|
| 原对象 $\vec v$ | 原函数 $f(t)$ |
| 基 $\hat e_1,\hat e_2$（有限个） | 基 $e^{i\omega t}$（**连续**一族，$\omega$ 取遍一切实数） |
| 点乘 $\vec v\cdot\hat e_1=\sum_i v_i e_{1,i}$ | 内积 $\int f(t)\,e^{-i\omega_0 t}\,dt$ |
| 系数 $a$ | 系数 $F(\omega_0)$ |
| 输出 $a=3$（实数） | 输出 $F(\omega_0)$（复数） |
| 输出含义：$v$ 在 $\hat e_1$ 方向的长度 | 含义：$f$ 在 $\omega_0$ 频率上的含量 |
| 全部输出：$(a,b)$ 两个数 | 全部输出：$F(\omega)$ 一整条曲线 |

## 为什么点乘变成积分

离散向量点乘 = 对应分量相乘再加总。连续世界没有"分量"，要把无穷多个 $t$ 上的值加起来，加总就变成积分：

$$
F(\omega_0) = \int_{-\infty}^{+\infty} f(t)\,e^{-i\omega_0 t}\,dt
$$

> "积分"在连续世界扮演的角色就是"求和"。没有更深的东西。

## 为什么是 $e^{-i\omega t}$ 而不是 $e^{+i\omega t}$

复向量的"点乘"里有一个**取共轭**的步骤：$e^{i\omega t}$ 的共轭是把 $i$ 换成 $-i$，即 $e^{-i\omega t}$。

**为什么必须取共轭**：不取的话，$e^{i\omega_1 t}$ 和 $e^{i\omega_2 t}$ 在 $\omega_1\neq\omega_2$ 时**不正交**（积分消不掉），无法"独立提出"单个 $F(\omega)$。取共轭后才有正交性：

$$
\int_{-\infty}^{+\infty} e^{i\omega_1 t}\, e^{-i\omega_2 t}\,dt = 2\pi\,\delta(\omega_1-\omega_2)
$$

$\omega_1=\omega_2$ 时为 1（Dirac δ），否则为 0——完美分开每个频率。

## 验证复指数基真的互相垂直

当 $\omega_1\neq\omega_2$ 时，$\int e^{i(\omega_1-\omega_2)t}dt$ 的实部 $\int\cos[(\omega_1-\omega_2)t]dt$ 在 $(-\infty,+\infty)$ 上正负震荡抵消 → 0；虚部同样对称抵消 → 0。当 $\omega_1=\omega_2$ 时被积函数变 1，积分发散 → 对应"跟自己点乘 = 长度平方"的语义（用 Dirac δ 规范化）。

> 所以 $e^{i\omega t}$ 在不同 $\omega$ 下两两正交 → 是傅里叶变换里"基"的合法候选。

## 总结：五步

1. 有对象（$\vec v$ 或 $f(t)$），它被分解成若干基的加权和
2. 基之间相互"垂直"（点乘/积分 = 0）
3. 用某个基去"点乘"原对象 → 该基系数自动浮出，其他基因垂直被消掉
4. 离散 → 连续：求和变积分，$\hat e_1$ 变 $e^{i\omega t}$
5. 按惯例带共轭：$e^{i\omega t}\to e^{-i\omega t}$（保证正交性成立）

> **傅里叶变换就是用基去点乘原函数**，这件事到这里不再神秘。
