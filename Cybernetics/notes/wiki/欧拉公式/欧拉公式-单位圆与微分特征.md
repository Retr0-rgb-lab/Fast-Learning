# 欧拉公式-单位圆与微分特征

> **一句话**：$e^{i\theta}$ 是单位圆上"以角速度 1 转圈"的点——长度永远是 1，只有方向在变；它同时是**微分算子的特征函数**（求导 = 旋转 90°，长度不变）。这正是傅里叶变换能用它当基的根本原因。

## 单位圆几何：$e^{i\theta}$ 是转圈的点

复平面：横轴 = 实部，纵轴 = 虚部。点 $(a,b)$ 到原点的距离 $r$、与横轴的夹角 $\theta$，由三角函数定义反解出 $a + bi = r\cos\theta + i\,r\sin\theta$。$r=1$ 时：

$$e^{i\theta} = \cos\theta + i\sin\theta = \text{单位圆上的点}$$

把 $\theta$ 当**时间**，让 $\theta$ 从 0 慢慢变大，看这个点怎么动：

| $\theta$ | 位置 | 意义 |
|----------|------|------|
| $0$ | $(1,0)$ | 起点，最右边 |
| $\pi/2$ | $(0,1)=i$ | 最上边 |
| $\pi$ | $(-1,0)$ | 最左边 |
| $3\pi/2$ | $(0,-1)$ | 最下边 |
| $2\pi$ | $(1,0)$ | 回到起点，转一圈 |

> **$\theta$ 就是转过的角度（=时间），$e^{i\theta}$ 就是当前位置。长度永远是 1，只有方向在变。**

## 代数与几何的缝合

- **代数那边**（泰勒展开）："$e^{ix}$ 的实部 = $\cos x$ 的级数，虚部 = $\sin x$ 的级数"
- **几何这边**（单位圆）："$e^{ix}$ 刚好是单位圆上那个点的坐标"

两个完全不同的入口，得到同一个东西。**不是 $e^{i\theta}$ 碰巧长得像单位圆，而是它的代数结构本身就编码了旋转**——这也是傅里叶变换能用它的根本原因。

## 复指数：微分算子的特征函数

复指数最特殊的性质——它对微分算子是**自己的特征函数**：

$$\frac{d}{dx} e^{ix} = i \cdot e^{ix}$$

- 求导结果只是把 $e^{ix}$ 转一个 $90^\circ$（乘以 $i$ = 旋转 $90^\circ$），**长度一点没变**
- 普通函数求导会变复杂（$x^2 \to 2x$），$e^{ix}$ 求导后还是同一类东西
- 含 $e^{ix}$ 的微分方程解起来像代数方程一样简单；常系数线性微分方程的"灵魂"就是这些 $e^{ix}$

## $\sin x$ / $\cos x$：二阶微分算子的特征函数

为什么偏偏是 sin 和 cos？因为它们的二阶导等于自己乘以 $-1$：

$$\frac{d^2}{dx^2}\cos x = -\cos x, \qquad \frac{d^2}{dx^2}\sin x = -\sin x$$

它们是**二阶微分算子的特征函数**——在傅里叶级数里当基，信号求二阶导后各项仍是自己，方程不"变形"。

## 微分变成乘法：$i\omega$

用欧拉公式把 sin/cos 写成 $e^{i\omega t}$ 的实部和虚部后，"微分"这一最难的操作就变成了"乘以 $i\omega$"的**乘法**：

$$\frac{d}{dt} e^{i\omega t} = i\omega\, e^{i\omega t}$$

> 傅里叶变换的物理意义：把任意信号分解成一堆"微分算子的不动点"，**把微分方程变成代数方程**——对 $e^{i\omega t}$ 求导永远只是乘个常数。
