# 复数

§1 Algebra。复数是后续一切（[[共轭]]、[[模]]、[[极形式]]、[[n次方根]]）的基底，归属 [[AMA2111 Lecture 01 复数]]。

## 记号

- 虚数单位：$i^2 = -1$
- $z = x + iy$，其中 $x,y \in \mathbb R$；$x=\mathrm{Re}(z)$，$y=\mathrm{Im}(z)$，即 $z=\mathrm{Re}(z)+i\,\mathrm{Im}(z)$
- $\mathbb C$：全体复数；$\mathbb R \subset \mathbb C$（虚部为 0）
- **相等**：$z_1 = z_2 \iff \mathrm{Re}(z_1)=\mathrm{Re}(z_2)$ 且 $\mathrm{Im}(z_1)=\mathrm{Im}(z_2)$（一个方程 = 两个实方程，这是复数解题的核心手段）

## 四则运算（按定义，令 $z=a+ib,\ w=c+id$）

| 运算 | 公式 |
|---|---|
| 加/减 | $z \pm w = (a\pm c) + i(b\pm d)$ |
| 乘 | $zw = (ac-bd) + i(ad+bc)$ |
| 倒数 | $\dfrac1z = \dfrac{a-bi}{a^2+b^2}$（$z\neq 0$） |
| 商 | $\dfrac wz = \dfrac{ac+bd}{a^2+b^2} + i\,\dfrac{ad-bc}{a^2+b^2}$ |

要点：**乘法直接展开再用 $i^2=-1$**；除法=分子分母同乘分母的 [[共轭]]（分母实数化）。

## 幂与等比数列

- $z^0=1,\ z^n = z\cdot z^{n-1}$；负整数次幂 $z^{-m} = 1/z^m$
- 指数律：$z^1/z = 1$，$z^{p+q}=z^p z^q$
- **等比数列求和**（公比 $z$）：$1+z+z^2+\cdots+z^n = \dfrac{1-z^{n+1}}{1-z}$

复数版等比求和在后面章节（级数、Laplace）会反复出现。
