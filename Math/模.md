# 模

归属 [[AMA2111 Lecture 01 复数]]。$|z| = \sqrt{z\bar z} = \sqrt{x^2+y^2}$，几何上是点到原点的距离（见 [[复平面]]、[[极形式]] 中的 $r$）。

## 六条性质（$z,w\in\mathbb C$）

1. $|z|\ge 0$，且 $|z|=0 \iff z=0$
2. $|\bar z| = |z|$（反射不改变距离）
3. $z\bar z = |z|^2$
4. $\dfrac1z = \dfrac{\bar z}{|z|^2}$
5. $|zw| = |z|\,|w|$ ← **乘法的模等于模的乘积**
6. $\left|\dfrac zw\right| = \dfrac{|z|}{|w|}$ ← 除法同理

## 用法提示

- 求除法结果的模：性质 6 直接算，不必先除
- 配合 [[De Moivre 定理]]：$|z^n| = |z|^n$
- 注意：$|z+w| \ne |z|+|w|$（三角不等式 $|z+w|\le|z|+|w|$，讲义未列但常用）
