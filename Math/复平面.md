# 复平面

归属 [[AMA2111 Lecture 01 复数]]，是 [[极形式]] 的几何基础。

## 核心

把 $z = x + iy$ 等同于笛卡尔平面 $\mathbb R^2$ 上的点 $(x,y)$（**Argand 平面**）：

- 原点 ↔ $0$
- x 轴 = **实轴**（全体实数）
- y 轴 = **虚轴**（$1 \leftrightarrow (1,0)$，$i \leftrightarrow (0,1)$）

## 由此获得的几何直觉

- 复数加法 = 向量加法（平行四边形法则）
- [[模]] = 到原点的距离
- [[共轭]] = 关于实轴的镜像反射
- [[极形式]] 的 $(r,\theta)$ = 点的极坐标
- [[n次方根]] 的根 = 圆上均匀分布的点

复数强大的根源：代数运算全部获得几何对应。
