## 四、三个主题是怎么串起来的

这是本课程真正的结构，三讲不是并列的：

```
复数（1 讲）
  复平面 → 极形式 → 复指数函数 → De Moivre → n 次方根
  └─ 复指数函数 e^{iθ} 给 ODE 二阶方程的 Case 3 提供现成解形式
                                    ↓
矩阵（2 讲 §1-2）→ 向量空间（§3）→ 行列式（§4）→ 特征值（§5）→ 内积（§6）
       └─ 矩阵运算是后面每一节的工具
                                    ↓
常微分方程（3 讲）
  一阶 → 一阶方程组（用到 §5 对角化）→ 二阶 → 拉普拉斯变换
```

三条最值得单独记的**跨讲主线**（细节见 [[index]] 的连接表）：

1. **复指数函数 → 二阶方程 Case 3**。第 3 讲证 $e^{iy}=\cos y+i\sin y$ 是为了把乘法变指数律；而二阶常系数齐次方程遇共轭根 $a=\alpha+i\beta$ 时，通解恰好是 $e^{\alpha x}\cos\beta x$ 与 $e^{\alpha x}\sin\beta x$ —— **就是第 1 讲的复指数函数的实部与虚部**。
2. **对角化 → 一阶方程组**。第 3 讲 §2 解 $y'=Ay$ 的全部前提，就是第 2 讲 §5 的"可对角化"：$A=PDP^{-1}$ 换元 $y=Pw$ 得到 $w'=Dw$，**这是整套课程唯一一处线性代数直接驱动 ODE 的地方**。
3. **齐次方程组 → 线性无关**。第 2 讲 §2 的 $At=0$ 只有平凡解 iff 列向量线性无关，是 §3 的定义；§5 的"可对角化 ⟺ n 个线性无关特征向量"是同一句话的第二次出现。

## 五、关于 PDF 的一个技术说明

两份 `Stu`（student）版 PDF 的数学符号是**二维排版**（分式堆叠、上下标、根号）。用纯文本工具提取时，**分式和根号会被压平成一串字符**，例如

```
课件实际：  |z| = √(zz̄) = √(x²+y²)
提取得到：  |z| = √z¯z = p x2 + y2
```

这**不是课件写错了，也不是笔记转述错了**。本库的处理办法：

- **打开 PDF 看原件**永远是权威来源，尤其是几何图、矩阵排版、Wheatstone 桥电路。
- 笔记里的公式按**标准写法用 LaTeX 重排**，并已逐条与 PDF 原页比对过（见 [[#六、本库做过的一次核对]]）。
- 提取时还发现课件里的角度符号 $\theta$ 在某些页的文本层显示为 `✓` —— 那是字体替换的伪影，**实际是 $\theta$**。`i` 表示虚数单位，`ẏ`/`ÿ` 表示对时间 $t$ 的导数（课件里 `y′` 表示对 $x$ 的导数）。

## 八、目录与命名规则

- **目录名一律不带数字**（`复数` / `矩阵` / `常微分方程`…），按**主题**划分而非按讲次。与本 vault 其余课程一致。
- **文件名不带数字、不带 `L0x_` 前缀**。课件讲 3，内容叫 `拉普拉斯变换.md`。
- 目录名与文件名用中文；数学术语以中文为主、括注英文（linear algebra、determinant、eigenvalue…）。

- **"一句话"**：结论先给出来，再展开。

- **`## 关联` 段**：反向连接，每条写清**关系类型**和**为什么连**。跨讲的长线索集中在 [[index]] 的连接表，不在每篇重复。
- 用 `> [!warning]` 标注易错点、`> [!important]` 标注关键结论。
