## 八个主题

### 复数 · Complex Number（L01）

主线：复数从**代数对象**（§1）到**几何对象**（§2），再到**指数对象**（§3），最终用几何＋指数一次性解决 n 次方根（§4）。

- [[复数与代数]] — $i$、$z=x+iy$、$\mathrm{Re}/\mathrm{Im}$、**一个复数方程 = 两个实方程**、四则运算、幂、等比数列
- [[复平面]] — 复数 ↔ 平面向量（Argand 平面），实轴 / 虚轴
- [[共轭]] — 提取实部虚部的钥匙，$z\bar z=|z|^2$，**分母实数化**
- [[模]] — $|z|$ 就是距离，$|zw|=|z||w|$
- [[极形式]] — $(r,\theta)$，**辐角只在相差 $2\pi$ 整数倍意义下确定**
- [[复指数函数]] — 由 Maclaurin 级数推出**欧拉公式** $e^{iy}=\cos y+i\sin y$
- [[De Moivre定理]] — **模相乘除，辐角相加减**；$z^n=r^ne^{in\theta}$
- [[n次方根与单位根]] — 恰 n 个根，均匀分布在圆上，**正 n 边形顶点**；一般根 = 单位根的旋转＋缩放

### 矩阵 · Matrix（L02 §1 `(AMA1120)`）

- [[矩阵与向量]] — $m\times n$、元素 $a_{ij}$、行向量 / 列向量、$\mathbb R^n$
- [[特殊矩阵]] — 零矩阵、方阵、上 / 下三角、对角、**单位矩阵**
- [[矩阵运算]] — 加减、数乘、**矩阵乘 $c_{ij}=\sum_s a_{is}b_{sj}$**、九条运算律、矩阵幂
- [[转置]] — $(AB)^{T}=B^{T}A^{T}$（**顺序反了**）、对称矩阵
- [[逆矩阵]] — 非奇异、**逆唯一**、$(AB)^{-1}=B^{-1}A^{-1}$

### 线性方程组 · System of Linear Equations（L02 §2 `(AMA1120)`）

- [[线性方程组与增广矩阵]] — $Ax=b$、系数矩阵、增广矩阵；开场例子是 **Wheatstone 桥电路**
- [[阶梯形与最简阶梯形]] — 阶梯形三个条件；**最简阶梯形 = 主元列外全零**
- [[高斯消去法]] — 化 $[A|b]\to[R|c]$ 再回代；**解集三态**（唯一 / 无穷 / 无解）的判据
- [[高斯若尔当法与齐次方程组]] — $[A|I]\to[I|A^{-1}]$；**齐次系统只有平凡解或无穷多解**

### 向量空间 · Vector Space（L02 §3，本课新）

- [[向量空间]] — 含零向量、对加法封闭、对数乘封闭；$\mathbb R^2$/$\mathbb R^3$ 就是通常的平面与空间
- [[线性相关与无关]] — 线性组合、$\operatorname{span}$、相关 / 无关的**定义互为否定**；**相关 ⟺ 齐次系统 $At=0$ 无穷多解**
- [[秩]] — 秩 = 列向量张成空间的维数 = **最多线性无关列数 = 主元个数**

### 行列式 · Determinant（L02 §4 `(AMA1120)`）

- [[行列式定义与余子式展开]] — 子式 $M_{ik}$、代数余子式 $C_{ik}=(-1)^{i+k}M_{ik}$、**沿任何行或列展开**、符号阵列
- [[行列式的性质]] — 九条性质；$|A^{T}|=|A|$、$|AB|=|A||B|$、两行相同则 $|A|=0$；**七条等价命题**（本讲最值钱的一页）

### 特征值与对角化 · Eigenvalue & Eigenvector（L02 §5，本课新）

- [[特征值与特征向量]] — $Av=\lambda v$；**$\lambda$ 是特征值 $\iff|A-\lambda I|=0$**；特征多项式是 $n$ 次、首项系数 $(-1)^n$
- [[对角化]] — $P^{-1}AP$ 对角；**可对角化 $\iff$ 有 n 个线性无关特征向量**；$AP=PD$
- [[对角化的应用]] — $A^{m}=PD^{m}P^{-1}$，**这是 L03 解一阶方程组的全部前提**

### 内积与正交性 · Inner Product & Orthogonality（L02 §6，本课新）

- [[内积与范数]] — $\langle v,w\rangle=v^{T}w$、四条性质、$\|v\|$、单位向量、夹角余弦公式
- [[正交性]] — 正交 / 正交集 / **标准正交集**（两条件：互相正交 ＋ 都是单位向量）
- [[Gram-Schmidt与正交矩阵]] — 投影 $\operatorname{proj}_{w}v$；**对称矩阵可正交对角化** $A=QDQ^{T}$

### 常微分方程 · Ordinary Differential Equation（L03）

- [[常微分方程与初值问题]] — ODE 定义、$y'/y''$ 与 $ẏ/ÿ$、解的定义、**IVP**
- [[一阶可分离变量方程]] — $\dfrac{dy}{dx}=g(x)h(y)\Rightarrow\int\dfrac{dy}{h(y)}=\int g(x)dx$
- [[可化为可分离的方程]] — $\dfrac{dy}{dx}=G(\tfrac yx)$，换元 $v=\tfrac yx$ 后 $y=xv$、$\dfrac{dy}{dx}=x\dfrac{dv}{dx}+v$
- [[一阶线性方程与积分因子]] — $\dfrac{dy}{dx}+p(x)y=q(x)$，积分因子 $\mu=e^{\int p(x)dx}$
- [[伯努利方程]] — $y'+p(x)y=q(x)y^{n}$，换元 $v=y^{1-n}$ 化为一阶线性
- [[一阶线性方程组]] — $y'=Ay+f(x)$；$A=PDP^{-1}$ 换元 $y=Pw$ 得 $w'=Dw$，**通解 $y=\sum c_jv_je^{\lambda_jx}$**
- [[二阶常系数齐次方程]] — 辅助方程 $m^2+pm+q=0$；**三种根型三种解**（相异实根 / 重根 / 共轭根）
- [[二阶常系数非齐次方程]] — $y=y_h+y_p$；**待定系数法**（含撞上齐次解时乘 $x$）与**参数变易法**（Wronskian）
- [[拉普拉斯变换]] — $F(s)=\int_0^{\infty}e^{-st}f(t)dt$；**$F(s)$ 的变量 $s=\sigma+i\omega$ 是复数**；线性性、$L\{f'\}=sF(s)-f(0)$
- [[拉普拉斯变换的应用]] — 解 IVP 化为**代数方程** $Y(s)=\dfrac{F(s)+\alpha s+\alpha p+\beta}{s^2+ps+q}$、时移定理、**卷积定理**（课件标 `*`）

## 跨讲的关键连接

这些连接**跨越讲次**，是复习时最值得单独记的线索：

| 连接 | 说明 |
|---|---|
| [[复指数函数]] → [[二阶常系数齐次方程]] | 共轭根 $a=\alpha+i\beta$ 的解 $e^{\alpha x}\cos\beta x,\ e^{\alpha x}\sin\beta x$，**就是 L01 复指数函数的实部与虚部** |
| [[对角化]] → [[一阶线性方程组]] | L03 §2 解 $y'=Ay$ 的**唯一前提**就是 L02 §5 的可对角化；$A=PDP^{-1}$ → $w'=Dw$ |
| [[线性相关与无关]] ↔ [[高斯若尔当法与齐次方程组]] | 「$At=0$ 只有平凡解 ⟺ 列向量线性无关」是同一句话；[[秩]] 的主元计数就是它的数值形式 |
| [[行列式的性质]] → [[特征值与特征向量]] | $\lambda$ 是特征值 $\iff|A-\lambda I|=0$，**用行列式定多项式方程的根** |
| [[行列式的性质]]（七条等价） | 把 L02 的 §2、§3、§4 串成一条链：唯一解 ↔ 可行化简 ↔ 非奇异 ↔ 只有平凡解 ↔ 列无关 ↔ 满秩 ↔ $|A|\neq0$ |
| [[矩阵运算]] → 几乎每一篇 L02 | 矩阵乘、$A^0=I$、$(AB)^{T}=B^{T}A^{T}$、$(AB)^{-1}=B^{-1}A^{-1}$ 的**顺序反转**是全课最高频的易错点 |
| [[转置]] → [[内积与范数]] | $\langle v,w\rangle=v^{T}w$ —— **内积就是用转置写的**，正交性判据 $\langle v,w\rangle=0$ 是矩阵语言的几何翻译 |
| [[Gram-Schmidt与正交矩阵]] → [[对角化]] | 一般的 $P^{-1}AP$ 要求特征向量线性无关；**对称矩阵时 Gram-Schmidt 保证它们还能正交**，于是得到更强的 $QDQ^{T}$ |
| [[模]] → [[拉普拉斯变换的应用]] | 模的乘法性质 $\lvert zw\rvert=\lvert z\rvert\lvert w\rvert$ 是 L01 与「$L\{f*g\}=F(s)G(s)$」之间少不了的桥：**卷积结果的大小由两边相乘给出** |
| [[一阶可分离变量方程]] ↔ [[复数与代数]] 的等比求和 | $1+z+\cdots+z^n=\dfrac{1-z^{n+1}}{1-z}$ 在 L01 出现，L03 的分离变量法与之同形（对数替换 ↔ 指数求和） |
| [[拉普拉斯变换]] ↔ [[二阶常系数非齐次方程]] | 特征根法要分类讨论重根；**拉普拉斯法把三者统一成一次代数运算**，这是它最重要的价值 |
