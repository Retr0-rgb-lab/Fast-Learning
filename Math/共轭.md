# 共轭

归属 [[AMA2111 Lecture 01 复数]]。$\bar z = x - iy$（$z=x+iy$），几何上是关于实轴的反射，见 [[复平面]]。

## 两个基本提取公式

$$\mathrm{Re}(z) = \frac{z+\bar z}{2}, \qquad \mathrm{Im}(z) = \frac{z-\bar z}{2i}$$

## 四条运算性质（$z,w\in\mathbb C$）

1. $\overline{\bar z} = z$（ involutive，反射两次还原）
2. $\overline{z\pm w} = \bar z \pm \bar w$
3. $\overline{zw} = \bar z\,\bar w$
4. $\overline{\left(\dfrac zw\right)} = \dfrac{\bar z}{\bar w}$（$w\neq0$）

证明全部直接展开即可（讲义以加法为例示范）。

## 为什么重要

- **分母实数化**：$\dfrac{w}{z} = \dfrac{w\bar z}{z\bar z} = \dfrac{w\bar z}{|z|^2}$，见 [[复数]] 除法
- 与 [[模]] 的桥梁：$z\bar z = x^2+y^2 = |z|^2$
- 与 [[复指数函数]]：$\overline{re^{i\theta}} = re^{-i\theta}$
