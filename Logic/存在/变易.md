# 变易（Werden）

## 一句话
变易 = 有与无的统一 = "有↔无"的不断转化本身。它是存在论第一个**具体**范畴，是"万物的开端"。

## 为什么要变易
纯有与纯无是同一体两面，思想不能停留在任何一个上，必须在两者之间来回跑：
- 有被否定 → 无
- 无被否定 → 有
- 再否定 → 无……这种不断的过渡就是变易

注意：**变易不是静止状态，是过程**。过程必须落到某个地方，所以下一步是 [[存在/定在与质|定在]]。

## 变易的两个必要条件
1. 有与无必须是同一件事（同时等价，不是先后）
2. 思想必须在两者间跑动，但不停留在任何一个上

- 只满足① → 死的等同（纯有阶段"有=无"）
- 只满足② → "一个东西变成另一个东西"，已预设静止的两个端点（那是"某物变某物"）

变易的独特：**两个端点本身都不存在**，有和无都只是过渡本身的一个瞬间。

## 变易的瞬间（生活例子）
- **伸手够水杯**：碰到瞬间，"还没碰到"和"已经碰到"彼此渗透，动作未完成也不需要完成
- **黎明**：不是"先黑暗再光明"，而是黑暗与光明同时在场；一旦你说出"现在是早晨"，变易就结束了
- **心跳**：收缩（有）与舒张（无）彼此渗透——纯粹的收缩是痉挛，纯粹的舒张是心脏停
- **学外语"突然会了"**：那个瞬间"不会"和"会"同时在场；一旦稳定"会了"，变易过去，进入新定在
- **水的相变**：100.0°C 是变易的极限瞬间——但更接近 [[存在/质与量|尺度破裂]]（已有温度作前提）

## 为什么"半杯水"不是变易
"半满半空"是满和空两种状态的叠加，仍持有两个确定端点。变易是**连端点都溶解**的状态。更接近纯变易的是黎明/心跳，不是半杯水。

## 哲学史上的"亲戚"
| 思想 | 接近处 | 差异 |
|------|--------|------|
| 老子「有无相生」 | 有无互相生成 | 老子作宇宙论观察，黑格尔作逻辑结构起点 |
| 赫拉克利特「人不能两次踏进同一条河」 | 一切在流动 | 前者感性情绪化，黑格尔做概念运动 |
| 佛教中道「不常不断」 | 超越常/断两极端 | 精神接近 |
| 亚里士多德运动定义 | 潜能→现实 | 预设两端，不是变易 |

## 最反常识的一点
变易的核心**不是变化，而是没有静止**。日常"变化"（花开、季节）是已沉淀的变易（某物变某物），预设了确定端点；纯变易连端点都不预设。
