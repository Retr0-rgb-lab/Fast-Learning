# 存在论 · 总览

## 一句话
存在论（Ontology）= 追问"到底有什么东西是真的存在的"，以及"存在"本身如何自己展开自己。黑格尔的回答：最纯粹的"存在"就是"虚无"，二者相互转化就是万物生成的开端。

## Ontology 是什么
- 世界最根本的"料"是什么？（物质？精神？关系？事件？）
- "存在"这件事本身有没有规律？
- 不同存在者（石头、人、数字、上帝）之间的关系？

注意混淆：英语 ontology 和 being 共用一个词根 ont-，所以"存在论"字面上就是"关于存在的学问"。

## 存在与虚无为什么分不开
1. **概念上互相定义**：说"这朵花存在"已预设"不存在"作对照；说"上帝不存在"时"存在"才有意义
2. **经验上互相渗透**：能感到"刚才那阵风没了"——"没了"是被经验的；海德格尔把对"无"的体验叫畏（Angst）
3. **逻辑上互相转化**："没有 100 块"本身是一个确定状态（=有 0 块）——"无"也是某种"有"

## 黑格尔的开篇四步
> 纯存在 → 纯存在 = 纯无 → 变易（Werden）→ 定在（Dasein）

- **纯存在**：没任何规定性的"有"，等于什么都没有
- **纯有 = 纯无**："想一个纯粹的'有'想到底，发现它就是'无'"
- **变易**：有和无是同一体两面，不停相互转化——这个"转化"本身是第三个概念
- **定在**：变易稳定下来，变成有规定性的存在——"这"张桌子、"那"个人；进入具体范畴（质、量、度）

## 存在论的三阶段展开
| 阶段 | 内容 |
|------|------|
| 直接性的王国（质） | 纯有 → 无 → 变易 → 定在 → 有限 → 无限 → 自为存在（"一"） |
| 量的王国 | 自为存在发现自身"漠不关心"→ 质脱开成量：纯量 → 定量 → 数量 → 程度 |
| 尺度 | 质与量的统一；尺度破裂（如水 100°C 沸腾）→ 存在论崩解 → 进入本质论 |

## 一句白话
存在论问"什么存在"；黑格尔答"最纯粹的'存在'其实就是'虚无'，而'存在'与'虚无'相互转化就是万物生成的开端"。
