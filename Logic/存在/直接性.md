# 直接性（直接性的王国）

## 一句话
直接性（Unmittelbarkeit）= 未经"中介"（Vermittlung）、未被反思的范畴状态——存在论第一阶段的统称，从纯有的绝对无规定到有限、最终孕育否定性过渡到本质。

## 直接性 vs 中介性
- **直接性**：一个概念还没有通过他者、通过否定、通过对立面回到自身的状态。逻辑学的起点，最抽象、最贫乏、但最纯粹
- **中介性**：通过否定、通过他者回到自身

比喻：直接性 = 一粒还没发芽的种子，纯粹是"在"；中介性 = 种子经历发芽、长叶、开花、结新种的整个过程。

## 存在论三阶段的位置
| 篇 | 王国 | 特征 |
|----|------|------|
| 存在论 | **直接性的王国** ← 当前位置 | 直接地看 |
| 本质论 | 反思/映现的王国 | 回过头来反思 |
| 概念论 | 概念自己发展的王国 | 在概念中重新把握整体 |

## 内部小节奏（从最贫乏到最丰富）
1. **纯有（Sein）**：绝对起点，纯粹无规定的存在，几乎空名
2. **无（Nichts）**：纯有与纯无无任何区别 → 有 = 无
3. **变易（Werden）**：有与无的统一，第一次出现"中介性"萌芽，第一个具体范畴
4. **定在（Dasein）**：变易沉淀，出现质、实有、某物、界限
5. **有限性（Endlichkeit）**：某物必有界限，界限 = 否定性，有限必然超出自身
6. **无限性（Unendlichkeit）**：有限的超出产生坏无限（线），但真无限是自否定、自回归 → 过渡到本质论

## 为什么叫"王国"
这一阶段的范畴都有共同特征：**还"自在地"（an sich）存在，还没"自为地"（für sich）通过他者反思自身**。它们像各自独立存在的小王国——有、无、定在、有限……每个都直接朴素地呈现，还不知道自己与他者的关系。直到进入本质论，范畴才开始"映现"。

## 关键对照表
| 范畴 | 含义 |
|------|------|
| 直接性 | 未经过他者中介的范畴状态 |
| 中介性 | 通过否定、通过他者回到自身 |
| 自在（an sich） | 潜在的、尚未展开的 |
| 自为（für sich） | 通过否定而自觉的 |
| 质 | 直接性的规定（是"这样"而非"那样"） |
| 否定性 | 让范畴运动起来的内在力量 |
