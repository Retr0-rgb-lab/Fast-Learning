# 定在与质

## 一句话
定在（Dasein）= 变易"沉淀"下来后，有规定性的存在——"这"张桌子、"那"个人。质（Qualität）是让一个东西"是这样而非那样"的规定性。

## 从变易到定在
变易是不断的过渡，但不能永远在路上飘。思想会停下来，把一个瞬间固定下来——"现在，这一刻，它是这样的"。这个沉淀下来的状态就是定在（Dasein，也可译"限有""特定存在"）。

定在的特征：
- 不再是纯粹的过渡
- 有了"如此这般"的规定性 → 这种规定性叫**质**
- 定在 = 质 + 某物

## 质是什么
质 = 你说出"它是红的""它是硬的""它是方的"这些规定性。**质使一个东西成为"这个东西"，而不是别的。**
- 失去了质，一个东西就不再是这个东西（水失去液态的质就不再是水）
- 质比量更"贴着存在"——见 [[存在/质与量]]

## 某物与他者
质立刻引出"某物"和"他物"：
- 一个某物之所以是它自己，恰恰因为它不是他物
- 某物 = 它 + 它的边界
- 边界 = 否定
- 否定 = 它有限

## 有限性就是否定性
**一个东西之所以存在，恰恰因为它有限。** 如果它什么都包含，就什么都区分不出，那就回到了纯有。但有限的东西必然会被超越——它会消亡，会被别的东西否定。这就引出 [[存在/有限与无限]]。

## 白话版路线
抽象 → 具体 / 虚空 → 有规定 / 无差别 → 有差别。
纯有 → 定在，走的就是这条路。
