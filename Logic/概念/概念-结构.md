# 概念论 · 结构

## 一句话
概念论（Begriffslehre）是《逻辑学》第三部分：前面讲的都是抽象、有限的范畴，只有到概念阶段，思维才开始把握真理——"概念的自我展开"。

## 在体系中的位置
| 部分 | 德文 | 主题 | 状态 |
|------|------|------|------|
| 1. 存在论 | Sein | 直接性、无规定性的"有" | 抽象的、起点的 |
| 2. 本质论 | Wesen | 反思、关系、矛盾 | 中介的、过渡的 |
| 3. 概念论 | Begriff | 普遍与特殊的统一、自发能动 | 具体的、最高的 |

## 概念论内部的三段
概念不是静止的，它自己展开为三个环节：
- **主观概念**（对应传统形式逻辑）：概念 → 判断 → 推论
- **客观概念**（概念外化为客体）：机械性 → 化学性 → 目的性
- **理念**（主观与客观的统一）：生命 → 认识 → 绝对理念

**绝对理念**是逻辑学的终点——无限自由的概念，把自己和世界都把握在内。它不是矛盾的终结，而是矛盾被最充分展开、被概念最彻底理解的状态（概念依然活着，因为它要外化进自然、历史、精神活动）。

## 三个关键特征（与日常"概念"区分）
1. **具体普遍性**：不是把共同点抽出来那种抽象普遍性（那叫"知性"），而是把差异、特殊、个别都包含在自身内的普遍
2. **自发性、能动性**：概念能自己分化、自己产生内容、又返回自身。形式逻辑把概念看成死的、被动的；黑格尔认为它活的
3. **自由**：不依赖外在给定，从自身出发
