# 逻辑学 · 学习路线

## 一句话
从**存在论**开始按书走；"概念是真理"是结论不是入口，别被它骗去先读概念论。

## "概念是第一"的误会
黑格尔说"概念是存在和本质的真理"——不是说概念在时序上第一，而是存在和本质"一直在偷偷奔向概念"。

**橡子/橡树比喻**：
- 从重要性看，橡子是"第一"（橡树一生在努力成为能结橡子的树）
- 从时间/学习顺序看，橡子在最后（先看见橡树，再回头认出那颗橡子）

概念最"厚"、最具体、最能自己决定自己；存在论最"薄"（就一句"有个东西在"）；本质论在中间。读的顺序：薄 → 中 → 厚。理解到位后回头看：厚才是真正的起点（橡子才是主角）。

## 路线 A（推荐）：从存在论起步，按书走
理由：黑格尔的论证是**累积的**。存在论里"有/无/变易"看着很蠢，但概念论里"概念自己决定自己"的高能时刻，依赖你在存在论里被训练出的**耐心**——愿意看着一个无聊的起点自己慢慢长出形状。跳过存在论直接读概念论，会觉得黑格尔在变魔术。

实操节奏：
1. 先把存在论读完，别赶。"质/量/尺度"前两章特别磨人，第三章开始起飞
2. 然后本质论——"本质"是"存在"回头看自己，出现现象/现实/同一/差异/矛盾
3. 最后概念论——前两卷伏笔一条条炸开

## 路线 B（已有一次通读时）：先《小逻辑》再《大逻辑》
小逻辑是大逻辑的缩写+修订版，更紧更清楚，但很多论证被砍。初学用小逻辑打底、大逻辑补血肉——这是不少研究者的实际顺序。第一遍仍建议大逻辑存在论起步，因为大逻辑"笨拙"的地方正是它教你慢下来的地方。
