# 逻辑学 · 与康德的背景

## 一句话
黑格尔几乎把《逻辑学》当成对康德的回应——他要拆掉康德"思维够不到物自体"的墙，把逻辑学做成"事物自身的逻辑"。

## 康德留下了什么遗产

1. **批判转向**：康德把传统形而上学（莱布尼茨—沃尔夫式的抽象推理）判为"先验幻相"——理性越界使用产生[[_辩证法与当代/矛盾与二律背反|二律背反]]，用有限知性范畴去把握无限者（上帝、灵魂、世界整体）必然崩溃。

2. **物自体的"空洞"**：我们认识的是现象，物自体（Ding an sich）永远在认识之外。黑格尔觉得这是怯懦的妥协——你不能既承认思维有认识权利，又在最关键处说"这里不行"。

3. **形式逻辑的局限**：康德保留形式逻辑作"分析真理"工具，但认为它不能产生扩展知识的新真理。黑格尔要把它从"思维的形式学"提升为"存在的逻辑结构本身"。

4. **范畴表的不彻底**：康德十二范畴是现成列表。黑格尔嘲笑：范畴之间怎么会没有推导关系、怎么会是平铺的？

## 黑格尔为什么必须"重做"
康德摧毁了旧形而上学，却没建立新的——留下的"不可知之物自体"和"空洞的形式逻辑"是同一件事的两面：都是把**思维与存在割裂**。

黑格尔的赌注：
> 把逻辑学做成"形而上学本身"——不是思维的形式学，而是"事物自身的逻辑"。范畴不是套在事物上的框架，而是事物自己展开自己的过程。

《逻辑学》副标题"或概念论科学"的意味：它既是逻辑，又是 ontology（存在论、万物之学）。

三个层次的动机：
- **思想史**：用不预设主客分裂的新方式，拯救被康德赶出科学殿堂的形而上学
- **科学**：理性不是要被限制的东西，而是应当自我展开到底
- **现实**：终点"绝对理念"与现实合一——呼应"凡是合乎理性的都是现实的，凡是现实的都是合乎理性的"

## 白话版吐槽
- 康德说"思维够不到现实"又说"思维对自己能到的地方有效"——骑墙
- 物自体把一切剥光后只剩"东西"两个字，是空的
- 形式逻辑当工具，预设了"大脑"和"世界"是两回事，却没回答它们为何对得上
- 范畴表是个清单：为啥是这些？为啥没故事？

黑格尔的赌注：如果思维和现实真断开，我们对世界一句真话都说不出；显然我们在说真话，所以断开是假的。整本《逻辑学》就是"让纯思维走一趟长路"，走到"思维=存在"。
