# 循环语句 · for, for...in, for...of, while

> **一句话**：`for` 管"次数我数得清"（括号里三段：**初始化；条件；更新**，走数组时条件是 `i < length` 而不是 `<=`）；`for...in` 走对象的**键**、`for...of` 走**值**（数组上优先用它）；`while` 先判后跑、`do...while` 跑完再判所以**至少执行一次**。

课件原文见 [Lecture_06_JS.pptx](<../../../raw/Lecture_06_JS.pptx>)。本篇覆盖 §4 Statements 中 The for Loop、for...in and for...of、while and do...while 三页。

## 一、`for`：括号里三段

`for` 的骨架是固定的，括号里用分号隔成三段，**顺序不能换**：

```js
for (初始化; 条件; 更新) {
  循环体
}
```

| 段 | 干什么 | 执行几次 |
|---|---|---|
| 初始化 | 声明计数器、给初值 | **只执行一次**（进循环之前） |
| 条件 | 求值，为真才进循环体 | **每轮开头都判断** |
| 更新 | 改计数器 | **每轮结尾执行一次** |

一行执行顺序：`初始化 → 判断条件 →（真）跑循环体 → 更新 → 判断条件 →（真）跑循环体 → …`

### 走数组：条件写 `i < length`

课件给的例子：

```js
const cars = ["BMW", "Volvo", "Saab"];
let text = "";
for (let i = 0; i < cars.length; i++) {
  text += cars[i] + "<br>";
}
document.getElementById("demo").innerHTML = text;
```

数组 3 项，下标 0/1/2，跑 3 轮：

| 轮次 | `i` | 判断 `i < 3` | 跑不跑 | 加上什么 |
|---|---|---|---|---|
| 1 | 0 | `true` | ✅ | `"BMW<br>"` |
| 2 | 1 | `true` | ✅ | `"Volvo<br>"` |
| 3 | 2 | `true` | ✅ | `"Saab<br>"` |
| 4 | 3 | `false` | ❌ 停 | —— |

结果 `text` 是 `"BMW<br>Volvo<br>Saab<br>"`，页面上三行。

> [!warning] 条件必须是 `i < length`，永远不是 `i <= length`
> ```js
> for (let i = 0; i <= cars.length; i++) { ... }   // ❌ 多跑一轮
> ```
> 长度 3 时下标只有 0、1、2。多跑的那一轮去取 `cars[3]`——**越界不报错**，只会给 `undefined`，于是页面上凭空多出一行 **`undefined`**。这就是 off-by-one（差一错误）：`length` 是"有几个"，最大下标是 `length - 1`（见 [[数组与空值]]）。

> [!warning] 计数器用 `let`，别用 `var`
> 课件点名了：*Declare the counter with let — it is scoped to the body, which is what you want*。`let i` 的 `i` **只活在这个 `for` 语句内部**，循环结束就没了，不会污染外面。用 `var` 时 `i` 会一直留在作用域里，同一个函数里写第二个循环就得换个名字。

## 二、`for...in` 与 `for...of`

两个长得很像，但**取到的东西完全不同**：

| | `for...in` | `for...of` |
|---|---|---|
| 遍历什么 | 对象的**键**（key） | **值**（item） |
| 例子对象 `{ fname: "John", age: 25 }` | 依次拿到 `"fname"`、`"age"` | 依次拿到 `"John"`、`25` |
| 数组上 | 拿到 `"0"`、`"1"`… ——**下标，而且是字符串** | 拿到 `"BMW"`、`"Volvo"`… |
| 适合 | 对象的键名（枚举字段） | 数组、可迭代对象的值 |

课件的代码：

```js
// keys of an object
const person = { fname: "John", age: 25 };
let txt = "";
for (let key in person) {
  txt += person[key] + " ";
}
```

走一遍：`key` 先是 `"fname"`，`person[key]` 取到 `"John"`，`txt` 变 `"John "`；下一轮 `key` 是 `"age"`，加上 `"25 "`，最终 `txt` 是 `"John 25 "`。

注意 `person[key]` 里的方括号是**变量取值**（键是运行时才知道的字符串），不是写死的 `person.fname`。

> [!warning] 数组上别用 `for...in`
> ```js
> const cars = ["BMW", "Volvo", "Saab"];
> for (let i in cars) { ... }   // i 是 "0"、"1"、"2" ——字符串！
> ```
> `for...in` 在数组上给的是**下标，而且是字符串不是数字**。于是 `cars[i + 1]` 实际在做 `"0" + 1` = `"01"` 这种拼接，取出来是 `undefined`；`i` 拿去参与任何数字计算也全是拼接结果。课件的说法是 *rarely what you want*——**数组上一律用 `for...of`**。

`for...of` 的形状一样，直接拿值：

```js
for (let car of cars) {
  txt += car + "<br>";        // BMW<br>Volvo<br>Saab<br>
}
```

**哪个用哪个**：

| 你要什么 | 用 |
|---|---|
| 数组 / 列表里的每一项 | `for...of`（或 `for`，要下标时） |
| 对象的字段名 | `for...in` |
| 对象的字段值 | `for...in` + `obj[key]`，或 `for...of` 配 `Object.entries()` |

## 三、`while` 与 `do...while`

区别只有一个，但后果很实在：**条件什么时候判断**。

| | `while` | `do...while` |
|---|---|---|
| 条件在 | **循环体之前** | **循环体之后** |
| 循环体至少跑几次 | **0 次**（初始条件为假就一次都不跑） | **1 次**（先跑再判断） |
| 形状 | 先 `while (条件) {` | 先 `do {`，`}` 后面跟 `while (条件);` |

课件的对照例子：

```js
let i = 0;
while (i < 5) {
  text += "The number is " + i + "<br>";
  i++;
}

let j = 0;
do {
  text += "The number is " + j + "<br>";
  j++;
} while (j < 5);
```

两段都输出 0 到 4，因为开始时 `i` 和 `j` 都是 0、条件都成立。**区别在初始条件为假时才显出来**——把条件改成 `j < 0`：`while` 那一版一次都不跑，`do...while` 那一版**仍然跑一次**（先加了 `The number is 0` 才检查）。

> [!warning] 忘了写 `i++` 就永远不会停
> 课件的原话：*Forget the step and it never ends — `i++` inside the block is not optional*。`while` 的条件在每轮开头重新求值，只要条件还成立就一直跑。条件不随循环体改变 → 死循环 → 页面卡死只能刷新。**写完 `while` 先扫一眼：循环体里有没有让条件朝"不成立"走的那个步骤。** 这也是为什么两段代码里 `i++` 都要放在**花括号里面**、紧挨着使用 `i` 的地方。

## 四、选哪个循环

课件给的规则只有一句，但很好用：

| 你知道什么 | 用 | 例子 |
|---|---|---|
| **知道要跑几次**（有数组、有计数） | `for` | 遍历 `cars` 的每一项 |
| **只知道条件**，跑几次不确定 | `while` | 一直找，直到某张图加载完 |
| 条件可能初始就为假、但**必须至少做一次** | `do...while` | 先做一次再问"还要继续吗" |
| 要数组的值 | `for...of` | 逐项处理 |
| 要对象的键 | `for...in` | 枚举字段 |

一句话记忆：**数得清用 `for`，只认条件用 `while`。**

## 五、写进示例站

```js
const cars = ["BMW", "Volvo", "Saab"];
const person = { fname: "John", age: 25 };

let text = "";
for (let i = 0; i < cars.length; i++) {
  text += cars[i] + "<br>";            // 三行：BMW / Volvo / Saab
}

for (let car of cars) {
  text += car + " ";                   // BMW Volvo Saab
}

for (let key in person) {
  text += person[key] + " ";           // John 25
}

let i = 0;
while (i < 3) {                        // 注意步长写在里面
  text += "n" + i + " ";
  i++;
}                                     // n0 n1 n2

const demo = document.getElementById("demo");
if (demo) {
  demo.innerHTML = text;
}
```
