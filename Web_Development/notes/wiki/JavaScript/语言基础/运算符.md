# 运算符 · Arithmetic and Assignment Operators

> **一句话**：**数字相加，文本相接**——`+` 遇到字符串就变成拼接，所以 `5 + 5` 是 `10` 而 `"5" + 5` 是 `"55"`；课件给的自查办法是：结果不对时，用 `typeof` 看看刚才进去的是什么。

课件原文见 [Lecture_06_JS.pptx](<../../../raw/Lecture_06_JS.pptx>)。§2 *Syntax* 的 "Arithmetic and Assignment Operators" 与 "String Operators" 两页。

## 一、算术运算符

| 运算符 | 含义 | 例子 | 结果 |
|---|---|---|---|
| `+` | 加法（addition） | `5 + 6` | `11` |
| `-` | 减法（subtraction） | `5 - 6` | `-1` |
| `*` | 乘法（multiplication） | `5 * 6` | `30` |
| `/` | 除法（division） | `a / b` | 商 |
| `%` | 求余（remainder） | `5 % 6` | `5` |
| `++` | 加一（increment by one） | `x++` | 相当于 `x = x + 1` |

`%` 的用途不限于取余：它还能判断奇偶（`n % 2 === 0` 是偶数）、取循环步进（`i = i + 1` 可以写成 `i += 1`，见 [[循环语句]]）。

## 二、赋值运算符

| 运算符 | 含义 | 例子 | 等价于 |
|---|---|---|---|
| `=` | 赋值（assign） | `x = 5` | 把 `5` 存进 `x` |
| `+=` | 加上，再存（add, then store） | `x += 5` | `x = x + 5` |
| `-=` | 减去，再存 | `x -= 5` | `x = x - 5` |
| `*=` | 乘上，再存 | `x *= 5` | `x = x * 5` |
| `/=` | 除去，再存 | `x /= 5` | `x = x / 5` |

`=` 是**赋值**不是比较，这一点和 `==` / `===` 正好相反（见 [[比较与typeof]]）。

## 三、字符串运算符

**`+` 也会连接文本**——课件的定性是 *`+` joins strings*：把两个字符串加起来，会把它们**粘起来**。

```js
var txt1 = "John";
var txt2 = "Doe";
var txt3 = txt1 + " " + txt2;   // "John Doe"

var a = 5 + 5;                // 10   —— 两个数字：相加
var b = "5" + 5;              // "55"  —— 字符串打头：拼接
var c = "Hello" + 5;          // "Hello5"
```

课件把这条规则压成一句：**Numbers add, strings join**（数字相加，字符串相接）。判断标准不是操作符，而是**参与运算的东西里有没有字符串**。

> [!warning] `"5" + 2` 的结果是 `"52"`，不是 `7`
> 字符串的优先权来自它的**位置**，不是它的内容：
> ```js
> "5" + 2     // "52"  —— 左边是字符串，整行变拼接
> 2 + "5"     // "25"  —— 同理，右边是字符串也是拼接
> ```
> `"5"` **长得**像数字，但它**是字符串**。课件在讲 `"5" + 5` 时用了一个词：*surprises you*（让你意外）。两个都像数字的写法凑在一起，最容易在这里翻车。

### 顺序决定结果

拼接是**从左到右**依次完成的，所以**同样的数字换个位置就换一个答案**：

```js
16 + 4 + "Volvo"   // "20Volvo"  —— 16+4 先算成 20，再和字符串粘
"Volvo" + 16 + 4   // "Volvo164" —— 一步都不算数，全程拼接
```

### 从表单拿到的值

表单和 `prompt` 拿回来的东西**一定是字符串**。所以：

```js
var age = "25";        // 从输入框来的
var next = age + 1;    // "251" —— 不是 26
```

要算数得先**转成数字**，用 `Number(...)`：

```js
var next = Number(age) + 1;   // 26
```

`Number` 转换不了的输入（比如空串、非数字文本）会得到 `NaN`，处理它属于错误处理的范围（见 [[错误处理]]）。字符串本身的性质见 [[字符串与数字]]。

### 遇到意外结果怎么办

课件给的自查动作只有一句：**Check with `typeof`**——如果一个结果让你意外，就用 `typeof` 看看刚才送进去的是什么。这是本课反复出现的一个习惯，见 [[比较与typeof]]。

```js
typeof 5 + 5      // "number"  —— 进去的 5 是数字，所以是相加
typeof "5" + 5    // "string"  —— 进去的 "5" 是字符串，所以是拼接
```
