# 语句与标识符 · Statements, Keywords and Identifiers

> **一句话**：JavaScript 的全部语法就是「**一串按顺序执行的语句**」——每条以关键字（keyword）起头、给你创建的东西起名字用标识符（identifier），两条语句之间用分号分开。

课件原文见 [Lecture_06_JS.pptx](<../../../raw/Lecture_06_JS.pptx>)。§2 *Syntax* 的 "Statements"、"Code Blocks, Keywords & Identifiers"、"Comments" 三页。

## 一、语句

**语句（statement）就是一条指令**。一个程序是语句的列表，浏览器**从上往下、一条接一条**地跑。

| 规则 | 说明 |
|---|---|
| **一条语句一个分号** | 分号把语句分开，也让你的意图明确 |
| **一行写多条是合法的** | `a = 5; b = 6;` 可以，但**一行一条更好读** |
| **空白是自由的** | 空格和换行会被忽略——**唯一例外是字符串内部** |

课件的完整例子：

```js
var a, b, c;        // 声明三个变量
a = 5;              // 赋值
b = 6;
c = a + b;          // 11
a = 5; b = 6; c = a + b;   // 同一行写三条：合法，但别这么写
```

**"空白是自由的"有个例外**，这一点要单独记住：字符串**内部**的空格和换行是内容的一部分，不是排版。

## 二、代码块

**花括号 `{ }` 把若干语句捆成一个块**（block）——函数体、`if` 的分支、`for` 的循环体都是一个块。块不只是排版好看，它还**划定了变量的作用域**：在块里声明的 `let` / `const` 出块就没了（见 [[变量与声明]]）。

## 三、关键字

**关键字（keyword）是语言的保留字**，每个都代表一个固定动作，课件点名的这一批覆盖了日常代码的绝大部分：

| 关键字 | 干什么 |
|---|---|
| `if` / `else` | 条件分支 |
| `for` / `while` | 重复执行 |
| `return` | 从函数里交回一个值 |
| `function` | 定义一个函数 |
| `var` / `let` / `const` | 声明变量 |
| `switch` | 多分支选择 |
| `break` | 跳出循环或 `switch` |
| `try` / `catch` | 捕获错误 |

> **保留字（reserved words）不能当标识符用**——这是硬规定，课件的措辞是 *A keyword can never be used as an identifier*。所以不能写 `var if = 3`。完整的保留字集合还包括 `class`、`do`、`continue`、`default`、`delete`、`in`、`instanceof`、`new`、`this`、`throw`、`typeof`、`void`、`with`、`yield`、`debugger`、`export`、`import`、`extends`、`super` 等。

## 四、标识符与命名

**标识符（identifier）就是你起的名字**——变量名、函数名、参数名都是标识符。

课件给的构成规则：

| 规则 | 说明 |
|---|---|
| 可用字符 | 字母、数字、`_`、`$` |
| 开头限制 | **不能以数字开头** |
| 大小写 | **全程区分大小写**（case sensitive） |

大小写敏感的后果，课件用两行并排展示：

```js
lastName = "Doe";      // 驼峰写法
lastname = "Peterson";  // 全小写 —— 这是另一个变量
```

> [!warning] `lastName` 和 `lastname` 是两个变量
> 这两行**互不相干**：JavaScript **全程区分大小写**，所以它们是两个各自独立的变量（严格模式下给未声明的变量赋值还会直接报错，见 [[作用域与严格模式]]）。课件专门把这两行并排放在一页上，就是提醒这件事——拼错大小写**不会报错**，只会得到一个你不认识的新变量。

### 命名约定

课件给的两条约定（convention，不是语法规则，但全世界的 JS 代码都这么写）：

| 用途 | 约定 | 例子 |
|---|---|---|
| **变量名、函数名** | **camelCase** 驼峰 | `lastName`、`carName`、`getElementById` |
| **永不改的常量** | **UPPER_CASE** 全大写下划线 | `MAX_USERS`、`API_KEY` |

在 [[变量与声明]] 里，`const` 声明的那些"绑一次就不改"的东西，正好对应 `UPPER_CASE` 这一档。

## 五、注释

| 形式 | 作用范围 |
|---|---|
| `// 单行` | 从 `//` 到**这一行结束**都被忽略 |
| `/* 多行 */` | 跨**任意多行**都可以 |

课件对注释的两条要求：

- **说"为什么"，不说"做了什么"**——代码本身已经说了做什么，注释应该说不出代码本身的原因。
- **注释掉用来测试**——找 bug 时可以先把一行注掉，**但找到之后要删掉**。

```js
// Change the heading
document.getElementById("myH")
.innerHTML = "My First Page";

/* The next line changes
the paragraph as well */
document.getElementById("myP")
.innerHTML = "My first paragraph.";
```

> **关于 `demo`**：课件的例子里结果都写进 `document.getElementById("demo")`。本库约定它是"示例站"（假想的课程主页）`main` 区里的 `<div id="demo"></div>`，课堂演示的输出框，详见 [[课程场景与阅读约定]]。
