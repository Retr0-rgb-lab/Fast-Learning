# 数组与空值 · Arrays, undefined & null

> **一句话**：布尔只有 `true` / `false` 两个值、数组下标从 0 开始且 `typeof` 把数组报成 `"object"`；而"什么都没有"在 JavaScript 里有**三个不同的东西**——`undefined`（引擎给）、`""`（还是文本）、`null`（你自己给的），混用它们是最常见的 bug 来源。

课件原文见 [Lecture_06_JS.pptx](<../../../raw/Lecture_06_JS.pptx>)。本篇覆盖 §3 Data Types 中 Booleans and Arrays、undefined/Empty/null 两页：布尔与数组的基本操作、`typeof` 对数组的不诚实，以及三种"空"的区别。

## 一、布尔：只有两个值

布尔（boolean）**只有** `true` 和 `false` 两个取值，没有第三种。它在 JavaScript 里最主要的来源是**每一次比较的结果**：

```js
var isReady = true;
5 > 3            // true
5 > 9            // false
"BMW" === "BMW"  // true
```

反过来，**所有非布尔值都能在条件里当布尔用**（truthiness 转换）。这也是为什么"用哪个值表示'没有'"会出事——`0`、`""`、`null`、`undefined` 在条件里全部等价于 `false`：

```js
if (count) { ... }   // count 是 0 时不进；count 是 1 时进
```

判断条件怎么落实、怎么被 `if` 消费，见 [[条件语句]]。

## 二、数组：有序的一串

数组（array）用**方括号**装，元素之间用**逗号**分隔，顺序就是写下来的顺序：

```js
var cars = ["Saab", "Volvo", "BMW"];
```

取第 0 个、下标从零：

> [!warning] 下标从 0 开始，不是从 1
> ```js
> cars[0]     // "Saab"   —— 第一个
> cars[1]     // "Volvo"  —— 第二个
> cars[2]     // "BMW"    —— 第三个
> cars[3]     // undefined —— 越界了
> ```
> 第一个元素的下标是 **0**，不是 1。所以"最后一个"不是 `cars[cars.length]`，而是 `cars[cars.length - 1]`——**长度是"有几个"，下标是"第几个"，差一个**。

长度 `length` 和字符串一样是**属性，不加括号**：

```js
cars.length                  // 3 —— 一共有几个
cars[cars.length - 1]        // "BMW" —— 最后一个
```

| 想要 | 写法 |
|---|---|
| 第一个 | `cars[0]` |
| 最后一个 | `cars[cars.length - 1]` |
| 倒数第二个 | `cars[cars.length - 2]` |
| 越界了 | `undefined`（不报错，这是 JavaScript 的宽松之处，也是坑） |

> [!warning] 越界不报错，只给 `undefined`
> `cars[99]` 不会抛异常，直接给你 `undefined`。写循环时如果下标条件写错（多走一步），症状是**页面上多出一行 `undefined`**，而不是报错——所以循环边界要特别小心，见 [[循环语句]]。

### 数组的 `typeof` 会说谎

```js
typeof cars        // "object"
```

数组在 `typeof` 面前和普通对象、乃至 `null` 是**同一个答案**。所以想知道"这到底是不是数组"，得用诚实的测试：

```js
Array.isArray(cars)     // true
```

| 写法 | 对 `[1,2,3]` 的结果 | 可靠吗 |
|---|---|---|
| `typeof cars === "object"` | `true` | ❌ 普通对象也是 `true` |
| `Array.isArray(cars)` | `true` | ✅ 只有数组是 `true` |

## 三、"什么都没有"的三种东西

这是本节的核心。JavaScript 有三个值都表示某种程度的"空"，但它们**产生方式不同、类型不同、意义不同**：

| | `undefined` | `""`（空字符串） | `null` |
|---|---|---|---|
| 谁产生的 | 引擎：声明了但从没赋值 | 你写的：就是零个字符 | 你写的：明确表示"这里没有" |
| 意思 | "**还没有**东西" | "有一段文本，长度 0" | "**故意**不给值" |
| `typeof` | `"undefined"` | `"string"` | `"object"` |
| 在 `if` 里 | 假 | 假 | 假 |
| 引擎会主动给你吗 | 会 | 不会 | **永远不会** |

分开看：

### `undefined`——引擎的"还没有"

```js
var car;              // undefined
```

声明了 `car`，但从来没赋值。变量一诞生就是 `undefined`。它的含义是"**这里还没放东西**"，是一句关于**状态**的话。查一个可能还没被赋值的变量、或者读一个对象上不存在的属性，得到的都是它（见 [[对象与属性]]）。

### `""`——它还是文本，而且有类型

```js
car = "";            // "" , typeof "string"
```

空字符串**不是"没有值"，它就是一个值**：长度为 0 的字符串。它的种类明确是 `string`，`typeof` 会老老实实回答 `"string"`。所以：

| 表达式 | 结果 |
|---|---|
| `typeof ""` | `"string"` |
| `"" === ""` | `true` |
| `"" == undefined` | `false`（`==` 会把 `""` 转成 0，两边都是 0，**竟然相等**） |

最后一行是真正的坑：`==` 那种"我帮你换算"的宽松比较会把 `""` 和 `undefined` 判成一样，`===` 不会。**这就是为什么本课一直用 `===`**（见 [[比较与typeof]]）。

### `null`——你自己给的"没有"

```js
var person = { firstName: "John" };
person = null;       // null, typeof "object"
```

`null` 是**故意**的：你明确说"这里没有对象"。课件强调它和 `undefined` 的分工——**`undefined` 是引擎给的，`null` 永远不会由引擎自动产生，只有你自己赋值时才会有**。代码里看到 `null`，一定是某个人写的。

> [!warning] `typeof null` 是 `"object"`，这是语言的一个历史遗留
> ```js
> typeof null        // "object"  ← 不是 "null"！
> ```
> 原因：语言最早版本里，值的内部表示用了一个"标记位"来区分对象和原始值，后来标记位被换成了别的机制，但 `typeof` 的这段判断逻辑**留了下来**以便兼容已经写好的代码。课件称之为 *a leftover from the first version of the language, kept for compatibility*。
>
> **要记住的结论**：判断"是不是 `null`"**不能靠 `typeof`**，只能直接比：
> ```js
> person === null      // ✅
> typeof person === "null"    // ❌ 永远是 false
> ```

## 四、写进示例站

```js
var isReady = true;
var cars = ["Saab", "Volvo", "BMW"];

var car;                        // undefined
car = "";                       // "" , typeof "string"
var person = { firstName: "John" };
person = null;                  // null , typeof "object"

const demo = document.getElementById("demo");
if (demo) {
  demo.innerHTML =
    "first: " + cars[0] + "<br>" +                    // first: Saab
    "count: " + cars.length + "<br>" +                 // count: 3
    "last: " + cars[cars.length - 1] + "<br>" +       // last: BMW
    "isArray: " + Array.isArray(cars) + "<br>" +       // isArray: true
    "typeof person: " + typeof person;                 // typeof person: object
}
```
