# 脚本放在哪里 · Where Does the Script Go

> **一句话**：外链一个 `.js` 文件是**专业写法**；而**放错位置会让脚本根本跑不起来**——写在 `<head>` 里的代码执行时页面还不存在，够不到任何元素。

课件原文见 [Lecture_06_JS.pptx](<../../../raw/Lecture_06_JS.pptx>)。§1 *Introduction* 的 "Where Does the Script Go?" 一页。

## 一、三种放法

| 放法 | 写法 | 特点 |
|---|---|---|
| **行内**（inline） | 代码直接夹在 `<script>` 和 `</script>` 之间 | 就在页面里，单文件看得到；换页面要复制一遍 |
| **外链**（external file） | `<script src="myScript.js"></script>` | **可复用**，而且浏览器会**缓存**它 |
| **位置**（head 还是 body） | 同一段代码放 `<head>` 里或 `<body>` 末尾 | **位置决定运行时页面上已经有什么** |

课件把外链说成默认选择，理由就两条：**能复用**（同一个文件被多页引用，改一次全生效）、**能被缓存**（第二次打开同一页不重复下载）。

## 二、位置为什么决定成败

这是本页唯一的硬规则，也是最常见的"我代码明明没错却不执行"：

> **A script in the head runs before the body is parsed; at the end of the body the tree is ready.**
> （放在 `<head>` 里的脚本在 body 被解析之前就执行了；放在 `<body>` 末尾时，整棵树已经就绪。）

浏览器是**从上往下读 HTML、边读边建树**的。`<head>` 在 `<body>` 前面，所以 `<head>` 里的 `<script>` 一读完立刻执行——那一刻 `<body>` 里的元素**还不存在**：

```html
<head>
  <script>
    // 这一行执行时，页面上还没有 <div id="demo">
    document.getElementById("demo").innerHTML = "My First JavaScript";
    // 结果：demo 是 null，给 null 赋值会抛错
  </script>
</head>
```

> [!warning] 在 `<head>` 里跑 DOM 代码必然失败
> 症状是控制台报 `Cannot set properties of null`。原因不是语法错，而是**执行的时机早于元素的存在**。这不是"偶发"，是必然——顺序是确定的。

两条正确写法：

```html
<!-- ① 放在 </body> 之前：整棵树已就绪，脚本可以放心找元素 -->
<body>
  <p>页面内容</p>
  <script>
    document.getElementById("demo").innerHTML = "My First JavaScript";
  </script>
</body>
```

```html
<!-- ② 保留在 <head>，但加 defer：下载可以并行，执行推迟到解析完成之后 -->
<head>
  <script src="myScript.js" defer></script>
</head>
```

`defer` 的取舍：**`defer` 保持"标签写在 head 里"的好习惯**（源码结构统一），同时把**执行**推迟到 body 解析完之后。它不阻止下载，所以比裸外链更快开始拉文件。

## 三、多个脚本文件

课件明确说多个文件没问题——**一个文件一个 `<script>` 标签**，但有两个后果要记住：

| 事实 | 含义 |
|---|---|
| **按出现的顺序执行** | `a.js` 写在 `b.js` 前面，`a.js` 就先跑完 |
| **共享同一个全局作用域** | `a.js` 里用 `var` 声明的变量，`b.js` 里能直接读到（前提是它声明得足够早） |

第二条是**能用的**，也是**容易出事的**：它意味着两个文件名不相关的文件会互相影响。声明变量时用块级作用域（`let` / `const` 包在自己的函数或块里）能把这个共享面收窄，详见 [[作用域与严格模式]]。

## 四、怎么选

| 场景 | 选择 |
|---|---|
| 真实项目里的任何代码 | **外链 `.js` + `defer`**（或放 `</body>` 前） |
| 只为演示一两行 | 行内 `<script>` 可以 |
| 依赖某个元素才能跑 | 必须 `defer` 或放 body 末尾 |
| 依赖另一个脚本的结果 | 放在那**后面** |

> **关于 `demo`**：课件例子都往 `document.getElementById("demo")` 写结果。本库约定它是"示例站"`main` 区里的 `<div id="demo"></div>`，课堂演示的输出框。真实项目里先查后写（确认不是 `null` 再改）的写法见 [[课程场景与阅读约定]]。
