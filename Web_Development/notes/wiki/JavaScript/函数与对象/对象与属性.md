# 对象与属性 · Objects and Properties

> **一句话**：对象是**一袋带名字的值**，用 `{ }` 装起来；属性两种读法（点号 / 方括号），**任何**值都能当属性 —— 而对象是**引用**，两个名字可以指着同一个对象，改一处两边都变。

课件原文见 [Lecture_06_JS.pptx](<../../../raw/Lecture_06_JS.pptx>)。本篇覆盖 §6 Objects 的 Objects — Properties 与 Primitives and Objects 两页：对象的形状、两种访问方式、属性可以是什么，以及对象与原始值在"赋值时发生什么"上的根本差别。

## 一、一袋带名字的值

课件的定义：*A bag of named values — pairs of key and data inside curly braces.*

```js
const person = {
  firstname: "John",
  lastname: "Doe",
  age: 50
};
```

三个**键值对**放在花括号里。`firstname` 是键，`"John"` 是数据。

它和数组的区别在形状：数组是**有序的一列**（用 `[]`，靠下标找），对象是**一堆带名字的抽屉**（用 `{}`，靠键找）。

| | 数组 Array | 对象 Object |
|---|---|---|
| 形状 | `["a", "b"]` | `{ k: "v" }` |
| 怎么找元素 | 下标 `arr[0]` | 键名 `obj.k` |
| 有序吗 | 严格有序 | 不承诺顺序 |

## 二、两种读法

课件给了两条路：*`person.firstname`, or `person["firstname"]` **when the key is computed**.*

```js
person.firstname;      // "John"
person["lastname"];    // "Doe"
```

**什么时候用哪个**：

| 写法 | 什么时候用 |
|---|---|
| **点号** `person.firstname` | 键名是**固定写死的**标识符 |
| **方括号** `person["lastname"]` | 键名是**算出来的**、或者含特殊字符 |

```js
const key = "age";
person[key]              // ✅ 50 —— 键是变量，必须用方括号
person.age               // ✅ 50 —— 键写死了，点号更清楚
person["first-name"]     // 含连字符，点号语法解析不了，只能方括号
```

> [!warning] 课件那句 `when the key is computed` 是分界线
> 键名写成字面量时，两种写法**都能跑**，但点号更可读。
> 一旦键名放进变量里，方括号就是**唯一**能用的写法 —— 写成 `person.key` 会被当成
> "取名叫 `key` 的那个属性"，而不是"取 key 这个变量指向的属性"。

## 三、任何值都能当属性

课件这句 *Any value can be a property — strings, numbers, arrays — even functions.*

```js
const config = {
  name: "COMP3421",              // 字符串
  credits: 3,                    // 数字
  tags: ["web", "frontend"],     // 数组
  enrolled: true,                // 布尔
  onOpen: function () { }        // 函数 —— 这就是"方法"
};
```

**函数存进属性里，就成了方法（method）。** 这是从"数据"到"行为"的一步，单独讲在 [[方法与this]]。

## 四、对象是引用

这一条是本篇和 [[原始值与引用值]] 的共同结论，也是对象最容易出意外的地方。

课件：*An object is a reference — **two names can point at the same object, and both see a change**.*

```js
const a = { n: 1 };
const b = a;            // 不是复制一份，是又给同一个对象起了个名字

b.n = 99;
console.log(a.n);       // 99  —— a 也变了
```

`b = a` 做的事是"让 `b` 也指向 `a` 指的那个对象"，**不是把内容拷一份给 `b`**。所以两边看到的是同一个东西的两次改动。

对比原始值：字符串、数字、布尔在赋值时是**复制**，改 `b` 不会影响 `a`。这个差别在 [[原始值与引用值]] 里有完整推导。

> [!warning] 函数参数是同一个道理
> 把一个对象传给函数，函数内部改它属性，外面那个对象同样会变 ——
> 因为传的是引用而不是副本。参数与"复制"的差别见 [[参数与默认值]]。
