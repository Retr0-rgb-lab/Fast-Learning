# 伪类与伪元素 · Pseudo-classes & Pseudo-elements

> **一句话**：**`:` 是状态，`::` 是部分**——伪类描述元素"此刻处在什么状态或位置"，伪元素描述"元素内部的哪一块"；两者都**不往 HTML 里加任何钩子**。

课件原文见 [Lecture_04_CSS.pptx](<../../raw/Lecture_04_CSS.pptx>)。本篇覆盖 Week 4 "Selectors" 一节的后半：状态伪类与 **LVHA 顺序**、结构伪类与 `nth-child` / `nth-of-type` 的关键差异、伪类速查表，以及五种伪元素。

## 一、伪类：元素的特殊状态

**伪类（pseudo-class，写作 `:`）定义元素的某种特殊状态。**

### 状态类

| 伪类 | 触发条件 |
|---|---|
| `:link` | 尚未访问过的链接 |
| `:visited` | 已经访问过的链接 |
| `:hover` | 鼠标悬在上面 |
| `:focus` | 键盘焦点在上面 |
| `:active` | 正被按下的那一刻 |

```css
a:link     { color: #1E4FA8; }
a:visited  { color: #6B4FA8; }
a:hover    { color: #D9534F; }
a:active   { color: #B26A00; }
input:focus { outline: 2px solid #1E4FA8; }
/* no JavaScript involved */
```

### 顺序：L V H A

课件给出的规则是：**Link, Visited, Hover, Active——最后一个赢。**

```css
/* 正确：hover 写在 visited 之后 */
a:visited { color: #6B4FA8; }
a:hover   { color: #D9534F; }

/* 失效：hover 被后面的 visited 压过 */
a:hover   { color: #D9534F; }
a:visited { color: #6B4FA8; }
```

原因在层叠：这几条**权重完全相同**（都是 `0,1,1` 那个量级：一个元素 + 一个 class 位），所以**平手时后写的赢**——见 [[层叠与优先级]]。指针停在已访问过的链接上时，两条规则都匹配，谁写在后面谁生效。

课件还有一句：**States are free styling — CSS already knows the mouse is there**（状态样式是白送的，CSS 本来就知道鼠标在哪）——**不涉及任何 JavaScript**。

### 结构类

| 伪类 | 含义 |
|---|---|
| `:first-child` / `:last-child` | 父元素的**第一个 / 最后一个子元素** |
| `:nth-child(n)` | 第 n 个子元素——**数的是所有兄弟，不管标签** |
| `:nth-of-type(n)` | 第 n 个**同类型**的兄弟 |
| `:not(selector)` | 除了括号里那个之外的**全部** |
| `:checked` | 被勾选 / 已切换的表单控件 |
| `:disabled` | 被禁用的表单控件 |

## 二、`nth-child` vs `nth-of-type`：本篇最关键的一处

课件给的例子，`.feed` 的**五个子元素**依次是 `h3  p  figure  p  p`：

```html
<div class="feed">
  <h3>Title</h3>
  <p>first</p>
  <figure>…</figure>
  <p>second</p>
  <p>third</p>
</div>
```

```css
/* .feed's 5 children:  h3  p  figure  p  p  */
/* EVERY sibling counts -> "2" = child 2, a <p> */
.feed p:nth-child(2)   { background: #CFE0F8; }
/* only <p> counts -> "2" = 2nd <p> = child 4 */
.feed p:nth-of-type(2) { background: #FFE08A; }
```

把两个数字换成位置看：

| 选择器 | 数的是 | 命中的是 |
|---|---|---|
| `.feed p:nth-child(2)` | **所有**兄弟 | 第 2 个孩子 = 那个 `h3` 之后的**第一个 `<p>`** |
| `.feed p:nth-of-type(2)` | **只有 `<p>`** | 第 2 个 `<p>` = **第 4 个孩子** |

| 子元素序号 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 标签 | `h3` | `p` | `figure` | `p` | `p` |
| `p:nth-child(2)` | — | ✅ | — | — | — |
| `p:nth-of-type(2)` | — | — | — | ✅ | — |

**同一个数字 `2`，选中了两个不同的段落。** 课件的结论是一句要紧的话：*Same number, two different paragraphs — and with mixed tags, one of them can match nothing at all*（同一个数字，两个不同的段落；标签混着排时，其中一个甚至可能什么也不匹配）。

最后半句值得展开：如果 `.feed` 里的 `figure` 不是 `<p>` 而是别的标签，那 `p:nth-of-type(5)` 就会落空——因为**只有 3 个 `<p>`**，写第 5 个永远匹配不到。

### 另外两个结构伪类

```css
.feed > :first-child   { color: #1E4FA8; }  /* 第一个子元素 */
.feed > :last-child    { color: #1E4FA8; }  /* 最后一个子元素 */
.notes p:not(.intro)   { color: #4A5568; }  /* 除了 .intro 以外的所有 p */
input:checked + label  { font-weight: bold; }
```

`:not()` 是排除，`input:checked + label` 是**相邻兄弟 + 状态伪类**的组合（复选框选中时把它旁边的文字加粗），组合器见 [[组合选择器]]，表单控件见 [[表单与输入]]。

## 三、伪类速查表

| 选择器 | 例子 | 选中什么 |
|---|---|---|
| `:hover` · `:focus` | `a:hover` | 指针在上面，或键盘焦点在上面 |
| `:link` · `:visited` | `a:visited` | 未访问 / 已访问的链接 |
| `:first-child` · `:last-child` | `li:first-child` | 父元素的第一个 / 最后一个子元素 |
| `:nth-child(n)` | `li:nth-child(2n)` | 第 n 个子元素——数字、奇数、偶数或 `2n+1` |
| `:not(selector)` | `p:not(.intro)` | **所有不匹配**的 |
| `:checked` · `:disabled` | `input:checked` | 已勾选 / 已切换关闭的表单控件 |
| `:empty` · `:target` · `:lang(en)` | `p:empty` | 无子元素 · URL 哈希指向的目标 · 某种语言 |

## 四、伪元素：元素的一部分

**伪元素（pseudo-element，写作 `::`）针对元素内部的一部分。**

| 伪元素 | 作用 |
|---|---|
| `::first-letter` | 段落**第一个字符**——首字下沉（drop cap） |
| `::first-line` | 段落**第一行**，随窗口宽度变化 |
| `::before` | 插在元素**自身内容之前**的内容 |
| `::after` | 同理，但在**另一端**——一个元素可以两个都有 |
| `::selection` | 读者用鼠标**选中**的文字 |

```css
p::first-letter { color: red; font-size: xx-large; }
p::first-line   { color: red; font-variant: small-caps; }
h3::before      { content: url("smiley.gif"); }
h3::after       { content: url("smiley.gif"); }
::selection     { color: red; background: yellow; }
/* :: is a part of an element, : is a state */
/* no content, no ::before / ::after */
```

`::first-line` 的妙处在于它**跟着窗口宽度变**——窗口一换行，"第一行"就是新的一行，不需要任何脚本。

## 五、三条要记住的规则

> [!important] `:` 是状态，`::` 是部分
> `a:hover`（一个状态）用**一个**冒号；`p::first-line`（一个部分）用**两个**冒号。这不是随意的——它把"改整个元素"和"改元素的一块"在视觉上就分开了。

> [!tip] 伪类**永远不会**往 HTML 里加钩子
> 课件那句原话：*A pseudo-class selects a state or a position — never an extra hook in the HTML.*
> 对比一下 class：`.center` 需要 HTML 里真的写 `class="center"`；而 `:hover` 完全不需要 HTML 配合——鼠标悬上去，CSS 自己去问。属性选择器也读的是**已存在**的属性（见 [[属性选择器]]）。

> [!warning] `::before` / `::after` **必须给 `content`**
> 课件的注释写得很直白：*no content, no ::before / ::after*。这两个伪元素是**凭空生成**的内容盒，没有 `content` 值就没有东西可生成，整条规则等于没写。

## 六、易错点

- LVHA 顺序写反，hover 效果"在已访问链接上失灵"。
- 以为 `p:nth-child(2)` 是"第二个段落"——它是**第二个孩子**。
- 用 `nth-child` 配合会变动的列表内容：标签插一个，序号全乱，`nth-of-type` 通常更稳。
- `::before` 忘了 `content`。
- 拿伪类当钩子用：想在 JS 里 `querySelector` 到它，选不中——它不是 HTML 里的东西。
