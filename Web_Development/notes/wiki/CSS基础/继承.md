# 继承 · Inheritance

> **一句话**：父元素上设的属性会**交给子元素**——`color`、`font-*`、`text-align` 这类文本属性一路流下去，`padding` / `margin` / `border` / `width` / `background` 这类**盒属性留在原地**，所以只在父元素上设一次就够。

课件原文见 [Lecture_03_CSS.pptx](<../../raw/Lecture_03_CSS.pptx>)。本篇覆盖 Week 3 的 "Inheritance" 一节：继承的定义、哪些属性会流下去、子元素覆盖父元素、哪些属性不继承，以及"在父元素上设一次"这条实践。

## 一、什么是继承

课件的定义只有一句，拆开就是两半：

> **父元素上设的属性被交给它的子元素；自己没有设任何东西的子元素，就用父元素的值。**

关键词是**"自己没有设"**——子元素不必做任何事，只要不开口，就吃父元素那份。

## 二、什么会流下去

**文本、字体、颜色类属性会继承**：

| 属性 | 效果 |
|---|---|
| `color` | 整块文字同色 |
| `font-family` | 整块同字体 |
| `font-size` | 整块同字号 |
| `text-align` | 整块同一对齐 |

```html
<div style="color: #1E4FA8;">
  <h1>Title</h1>
  <p>All blue.</p>
</div>
```

```html
<div style="color: red;">
  this heading and paragraph are red
  …only the <div> was styled. The color flowed down to its children automatically.
</div>
```

**只写了一个 `div`，标题和段落却都变红了。** 这就是课件那句 "*the color flowed down to its children automatically*"。

## 三、子元素一旦自己声明，父元素的就在这里停下

> 在子元素上声明这个属性，**子元素的值赢**，父元素的值到此为止。

```html
<div style="color: #1E4FA8;">
  <h1>Title</h1>            <!-- 继承 Primary -->
  <p style="color: #D9534F;">This one is Alert.</p>  <!-- 自己声明 → 赢 -->
</div>
```

注意这里的"赢"是**继承的规则**，和"优先级（specificity）的规则"是两件事：这一层只看"你有没有自己声明"，还没走到比权重，权重是 Week 4 的 [[层叠与优先级]]。

## 四、什么**不**会流下去

课件专门给了一条注记：

> **盒属性（box properties）不继承**：`padding`、`margin`、`border`、`width`，以及 `background`。

| 流下去（继承） | 留在原地（不继承） |
|---|---|
| `color` | `margin` |
| `font` | `padding` |
| `text-align` | `border` |

课件那句对照原文是：**color、font 和 text-align 继承；margin、padding 和 border 不继承。**

为什么这样设计是合理的：`margin: 20px` 如果会继承，一个深到三层的列表会把每一层都撑开 20px；盒子的间距和尺寸属于**这一个盒子自己的形状**，让它传给子元素只会制造意料之外的空间。文字是"内容"的一部分，盒子是"布局"的一部分——所以分界线正好画在这里。

## 五、实践：只设一次

课件给的结论是 **Set it once**——把声明放在父元素上，里面每个子元素都继承。

```css
/* 写在 main 上，页面上每个 h1 h2 p 都吃到 */
main {
  color: #1E4FA8;
  font-family: Arial, sans-serif;
  text-align: left;
}
```

对照手写版（不推荐）：

```html
<h2 style="color: #1E4FA8; font-family: Arial, sans-serif;">…</h2>
<h3 style="color: #1E4FA8; font-family: Arial, sans-serif;">…</h3>
<p  style="color: #1E4FA8; font-family: Arial, sans-serif;">…</p>
```

同样的结果，一份 vs 三份。维护成本差在"改颜色"的那一刻——三份就是三处改动，漏一处颜色就不齐了。

## 六、继承是 CSS 变量能生效的原因

Week 4 讲变量时会看到这样一段代码：

```css
/* site-wide colours */
:root {
  --blue: #1E4FA8;
  --navy: #0E3F8C;
}
h1 {  /* one per line */
  color: var(--blue);
}
```

`--blue` 定义在 `:root`（也就是 `<html>`）上，全站却都能用——**变量用的就是继承这套机制**，不是另一套规则。

这条连接很重要，因为它澄清了一个常见误解：**变量不是"继承的例外"，它和普通属性走同一条路。** 变量本身的定义、`var()`、作用域与主题切换见 [[CSS变量]]；Week 3 说过"同一个色值不要写两遍"，那里的解法就是它。

## 七、易错点

- 指望 `margin` / `padding` 从父元素流下来——它们**不继承**，只能一层层写。
- 以为"不继承"意味着子元素被硬套了一个值：不是，子元素用的是自己的初始值或别的规则给的值。
- 在子元素上多此一举地重复父元素已经给过的文本属性——白写一份，还多一个要维护的地方。
