# 文本与字体 · Text & Font

> **一句话**：文本属性管"这段字长什么样"（对齐、装饰、大小写、间距、方向、阴影），字体属性管"用什么字、什么字号"——两者都写在一批**可被继承**的属性里，`font` 简写只是把它们打包成一行。

课件原文见 [Lecture_03_CSS.pptx](<../../raw/Lecture_03_CSS.pptx>)。本篇覆盖 Week 3 的 "Text" 与 "Font" 两节：文本属性总表、字体属性总表、`font-family` 的回退栈、`font` 简写的顺序，以及 `@font-face` 和 Google Fonts。

## 一、文本属性

### 对齐、装饰、大小写

| 属性 | 取值 | 作用 |
|---|---|---|
| `color` | 任意颜色 | 文字本身的颜色 |
| `text-align` | `left`、`right`、`center`、`justify` | 行的对齐方式 |
| `text-decoration` | `none`、`underline`、`overline`、`line-through` | 装饰线 |
| `text-transform` | `uppercase`、`lowercase`、`capitalize` | 大小写转换（只影响显示） |

```html
<p style="text-align: center; text-decoration: none; text-transform: uppercase;">
```

`text-transform` 改的是**显示出来的大小写**，不动原文——大写化之后屏幕阅读器读到的仍是原字。

### 间距

| 属性 | 作用 |
|---|---|
| `text-indent` | 缩进段落**第一行** |
| `letter-spacing` | **字符**之间的间距 |
| `word-spacing` | **词**之间的间距 |
| `line-height` | **行**与行之间的间距——**常常不带单位** |

```html
<p style="text-indent: 50px;">
<h1 style="letter-spacing: 3px;">
<p style="word-spacing: 10px;">
<p style="line-height: 1.8;">
<!-- line-height: 1.8 = 1.8 x the font size -->
```

`line-height` 不带单位时是**倍数**，乘以字号。`1.8` 就是 1.8 倍字号——这样写的好处是改字号时行距自动跟着走。课件对这一组的判断是：**间距就是排版，它让文字可读或者拥挤。**

### 方向、空白、对齐、阴影

| 属性 | 取值 | 作用 |
|---|---|---|
| `direction` | `ltr`、`rtl` | 左到右 / 右到左 |
| `white-space` | `normal`、`nowrap`、`pre` | 空白怎么处理：`normal` 会折叠多余空格，`pre` 原样保留 |
| `vertical-align` | `baseline`、`top`、`middle`、`bottom` | **行内元素**的垂直对齐 |
| `text-shadow` | 偏移 · 偏移 · 模糊 · 颜色 | 文字背后的阴影 |

```html
<p style="direction: rtl; text-shadow: 1px 1px 2px #999;">
```

`text-shadow` 的四个值是 **x 偏移 · y 偏移 · 模糊 · 颜色**：

```css
text-shadow: 4px 4px 8px rgba(0, 0, 0, 0.4)
```

注意 `vertical-align` 管的是**行内元素**彼此之间的对齐，不是给块级元素定位用的。`direction: rtl` 会让阿拉伯文从右往左读，文字对齐方式也随之镜像。

## 二、字体属性总表

| 属性 | 设置什么 | 例子 |
|---|---|---|
| `font-family` | 字体（typeface），**带回退** | `font-family: Georgia, serif;` |
| `font-size` | 文字大小 | `font-size: 16px;` |
| `font-style` | `italic` / `normal` / `oblique` | `font-style: italic;` |
| `font-weight` | `bold` / `normal` / `100`–`900` | `font-weight: bold;` |
| `font-variant` | `small-caps` 或 `normal` | `font-variant: small-caps;` |
| `font` | 以上全部，**一行写完** | `font: italic bold 12px Georgia;` |

课件明说 `font` 是**简写（shorthand）**：它把 style、weight、size、family 打包进一条声明。

## 三、`font-family`：回退栈

```html
<p style="font-family: 'Times New Roman', serif;">
<h1 style="font-family: Arial, sans-serif;">
<code style="font-family: 'Courier New', monospace;">
<!-- browser uses the first font it has -->
```

| 概念 | 含义 |
|---|---|
| 回退栈（fallback stack） | 列好几个名字，**从左到右**依次尝试 |
| 通用族（generic families） | `serif`、`sans-serif`、`monospace`——最后的安全网 |
| 多词字体名要加引号 | `"Times New Roman"` 必须引号，否则 `New Roman` 会被当成两个词 |

浏览器用**它有的第一个**；第一个缺了就退到下一个，再下一个。栈尾那个通用族保证总有东西可渲染。

## 四、`font-size` 与默认值

| 类别 | 单位 |
|---|---|
| 绝对 | `px` —— 固定大小 |
| 相对 | `em`、`rem`、`%` —— 随上下文缩放 |
| 视口 | `vw` —— 连视口都能定字号 |

```html
<p style="font-size: 16px;">
<h1 style="font-size: 2em;">
<h2 style="font-size: 1.5rem;">
<h1 style="font-size: 10vw;">
<!-- em and rem keep text scalable for everyone -->
```

**浏览器默认 `16px`，所以 `1em = 16px`。** 课件的结论是：相对字号让用户（和他们的浏览器）能缩放文字，这是一条**可访问性上的收获**。相关机制见 [[长度与单位]]。

## 五、`font` 简写：顺序不能换

**顺序是：style → weight → size → family**。其中 **size 和 family 是必填的**，其余可选。

```html
<!-- 简写：省行数 -->
<p style="font: 15px Arial, sans-serif;">
<p style="font: italic bold 12px Georgia, serif;">

<!-- 长写：同一个效果，但更好调试 -->
<p style="font-style: italic;
font-weight: bold;
font-size: 12px;
font-family: Georgia, serif;">
```

课件的取舍很实在：**简写省行数，长写更好调试——两个都要会。** 排查到底是哪个属性不对时，长写能把嫌疑摊开成几行。

另外三个可以随便组合，任意两三个可以同时写：

```css
p {
  font-style: italic;
  font-weight: 700;
  font-variant: small-caps;
}
```

`font-variant: small-caps` 是"**全大写但用较小字号**"的排版效果。

## 六、Web 字体

### `@font-face`：给字体文件起个名字

```css
@font-face {
  font-family: myFirstFont;
  src: url(sansation_light.woff);
}
<h1 style="font-family: 'myFirstFont';">Hello</h1>
<!-- the browser fetches the file once, then caches it -->
```

| 部件 | 作用 |
|---|---|
| `@font-face` | 定义你自己的字体，**让一个文件获得一个名字** |
| `font-family` | 你给这个字体起的名字 |
| `src: url(…)` | `.woff` / `.ttf` 文件在服务器上的位置 |
| 按需下载 | 文件**第一次被用到时**才下载，之后进缓存 |

一句总结：给字体文件起一次名字，之后任何地方都能用这个名字。首次下载的代价见 [[性能与可扩展性]]。

### Google Fonts：它替你包好了 `@font-face`

```html
<!-- in <head> -->
<link href="https://fonts.googleapis.com/css2?family=Roboto&display=swap"
rel="stylesheet">

<!-- anywhere in the body -->
<h1 style="font-family: 'Roboto', sans-serif;">Hello</h1>
```

**用 `<link>` 加载一次，再用 `font-family` 按名字用。** 默认情况下系统只有 Arial、Georgia、Times 这些，想要更花的字体就靠 web 字体。

## 七、易错点

- `font-family` 里带空格的名字不加引号。
- `line-height` 写成像素值后，字号一改行距就不匹配了——**优先用倍数**。
- `font` 简写把 size 和 family 写成可选项，或调换它们的顺序。
- `text-transform: uppercase` 只是显示层的大写，**可访问性上不能替代真的大写**。
- 用 `px` 定正文字号，等于把用户缩放文字的能力拿掉。
