# 样式声明与内联 · Styling with the style Attribute

> **一句话**：CSS 全部的语法只有一句型 `属性: 值;`，学会它就能手写整页样式——而 `style` 属性一次只能管住一个元素，这既是它最简单的地方，也正是它的天花板。

课件原文见 [Lecture_03_CSS.pptx](<../../raw/Lecture_03_CSS.pptx>)。本篇覆盖 Week 3 的 "Styling the Web" 一节：`style` 属性的位置、`property: value` 句型的四个组成部分，以及「一次一个元素」这件事为什么是内联样式的极限。

## 一、样式挂在标签上：`style` 属性

`style` 可以写在**任何一个 HTML 标签**上，值就是一串声明：

```html
<h1 style="color: blue;">Hello</h1>
<p style="color: green; font-size: 18px;">
This is a paragraph.</p>
<!-- style = one or more  property: value; -->
```

三件事一次性说清：

| 位置 | 作用 |
|---|---|
| `style="…"` 属性值 | 一串声明，属性值和 CSS 写法完全一样 |
| 贴在标签上 | 样式就长在元素自己身上（inline，内联） |
| 一个标签一份 | 每个元素只带着自己那几条声明，不会共用 |

> [!tip] 为什么 `style` 里的写法和 `.css` 文件里一样
> 因为它们用的是同一套语法。`style` 属性里那条 `color: blue;`，和样式表里 `h1 { color: blue; }` 里的 `color: blue;` 是同一个东西，只是装在不同的壳里。壳的差别带来的后果，见 [[CSS引入方式]]。

## 二、唯一的句型：property 与 value

课件把一句样式拆成四个部件，全部例子都来自 `<p style="color: blue; font-size: 18px;">`：

```html
<p style="color: blue; font-size: 18px;">
```

| 部件 | 例子 | 它是什么 |
|---|---|---|
| Property（属性） | `color` | 要改什么 |
| Value（值） | `blue` | 把它设成什么 |
| Declaration（声明） | `color: blue;` | 冒号两侧凑成的一个完整对子 |
| Separator（分隔符） | `;` | 把多个声明串起来 |

课件的原话把这句型的重要性讲得很直白：**学会这一个句型，你已经能手工给整页做样式了。**

> [!important] 整门课的语法地基
> Week 3 的后半段（颜色、长度、文本、字体、继承）没有任何新语法，只是在往这四个部件里填不同的属性名和值。Week 4 才引入规则块 `selector { … }` 这一层外壳——见 [[规则结构与选择器分类]]。

## 三、极限：一次一个元素

`style` 属性的定义性限制不是缺点，而是它的边界：

- 样式长在**元素自己**身上 → 别的元素拿不到；
- 想让第二个元素同款 → 只能把整串再抄一遍；
- 想改 → 抄过几处就改几处。

课件在 Week 3 的收尾页把这条写成了本节的结论：*the style attribute styles one element at a time — that is its limit*（`style` 属性一次只给一个元素上样式，这就是它的极限）。

所以 Week 3 用 `style` 只是**认识语法**的脚手架，不是推荐写法。真正要复用的写法在 Week 4：把声明搬进样式表，用**选择器**（selector）一次点名一堆元素。

## 四、写在示例站上

全库共用的假想课程主页（示例站）顶部就是一个 `h1`。用本篇的句型，它是这样被上色的：

```html
<header>
  <h1 style="color: #1E4FA8;">COMP3421 Web Application Design and Development</h1>
  <p style="color: green; font-size: 18px;">Week 3 — Styling the Web</p>
</header>
```

换成样式表写法，页面结构一字不动：

```css
h1 { color: #1E4FA8; }
p  { color: green; font-size: 18px; }
```

`#1E4FA8` 是课程调色板里的 Primary，约定见 [[课程场景与阅读约定]]。两种写法的差别就是本篇与 [[CSS引入方式]] 的差别：**一个贴在元素上，一个点得到元素。**

## 五、易错点

- **属性和值之间必须是冒号**，`color blue;` 不是声明，是无效写法。
- **多条声明之间用分号**，少了分号，后一条会被当成上一条的值的一部分。
- **一次只改一个元素** 是写法本身的限制，不是你写得不够勤快——需要影响多个元素就必须换写法（[[CSS引入方式]]）。
- `style` 是一个普通的 HTML 属性，认识它有助于理解 CSS 是怎么被挂到文档上的，见 [[属性]] 与 [[元素与标签语法]]。
