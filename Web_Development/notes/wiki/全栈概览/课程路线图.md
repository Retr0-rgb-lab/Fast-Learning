## 四、Week 13 结束时会什么

课件给的定义句是：**"You will be able to build a complete web application — and explain every layer of it."**（能建出一个完整的 Web 应用，**并且解释它的每一层**。）六项能力原文如下：

| # | 能力 | 课件的说明 |
|---|---|---|
| 1 | **Design the stack** 设计技术栈 | 选定前端、后端、数据库，**并给出理由** |
| 2 | **Build the front-end** 建前端 | 语义化 HTML、**现代 CSS**、可交互的 JavaScript |
| 3 | **Build the back-end** 建后端 | **Node.js + Express REST API**，并接上数据库 |
| 4 | **Connect them** 把两端接起来 | **fetch、JSON，以及把 HTTP 用对** |
| 5 | **Ship it** 上线 | **部署到云端，拿一个真实 URL** |
| 6 | **Make it fast** 变快 | 缓存、CDN 与性能基本功 |

课件还给了一句收尾：**"Your final project proves all of it — see the course overview for details."**（期末项目会证明上面每一条，细节见课程概览。）

> [!important] 六项里最容易被跳过的是第 1 项
> "Choose front-end, back-end, database — **and justify it**" 这一条**要的是理由**。而理由只能从 Week 1 的那张全景图里找依据：客户端数量是**一对多**，所以服务器端要非阻塞；两端唯一的共同语言是 HTTP，所以选型不能自说自话。整个学期的技术选型练习，都是在给这一条攒论证材料。

## 五、Week 1 的五句总结

课件最后一页给了五句 Key Takeaways，全文列在下面，作为全课程的收口：

1. **The web is three layers — browser, server, database — talking HTTP.**（Web 就是浏览器、服务器、数据库三层在说 HTTP。）
2. **Front-end is HTML (structure) + CSS (presentation) + JS (behaviour).**（前端 = HTML 管结构 + CSS 管表现 + JS 管行为。）
3. **Back-end is Node.js + Express + a database — the same JavaScript.**（后端 = Node.js + Express + 一个数据库，**还是同一种 JavaScript**。）
4. **A real website is many distributed services, each scaling on its own.**（真实网站是许多分布式服务，**各自独立扩容**。）
5. **This semester you build every layer and ship a real app.**（这学期你要建起每一层，并上线一个真实应用。）

课件对下一讲的指路是：**Next week: HTML — structure, DevTools, and forms**（下一周：HTML——结构、DevTools 与表单）。
