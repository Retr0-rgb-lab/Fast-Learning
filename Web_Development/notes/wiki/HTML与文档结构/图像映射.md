# 图像映射 · Image Maps

> **一句话**：图像映射就是"在一张图上圈出几个可点区域"——`usemap` 挂上 `<map>`，`<map>` 里每个 `<area>` 用**图片文件自身的像素坐标**圈一块并挂一个 `href`，**所以绝不能用 CSS 改这张图的大小**。

课件原文见 [Lecture_02_HTML.pptx](<../../raw/Lecture_02_HTML.pptx>)。本篇覆盖课件的 "Image Maps"、"Image Maps — Shapes & Coords" 和 "Picking the Numbers" 三部分。课件的完整示例是一张 `workplace.jpg`，尺寸 **400 × 379 px**。

## 一、为什么需要它

课件的定义是：**Clickable areas — different actions depending on where you click**（可点区域——点不同的地方做不同的事）。

> [!note] 今天用得少，但课件要求会
> 现在做响应式导航几乎都用真正的按钮叠在图上，图像映射已经退居示范用途。但它是理解"**图像也可以承载一组链接**"的标准案例，而且它引入的那套坐标系在 [[SVG矢量图形]] 那里还会再遇到一次。

## 二、三个部分怎么接起来

| 角色 | 写法 | 课件的说法 |
|---|---|---|
| `<img>` | `usemap="#workmap"` | 把图**连到一个 `<map name="…">`** |
| `<map>` | `<map name="workmap">` | 装所有可点区域的容器 |
| `<area>` | `shape` + `coords` + `href` | **一个可点区域**，带形状、坐标和链接 |

完整例子（课件原样）：

```html
<img src="workplace.jpg" alt="Workplace"
     usemap="#workmap" width="400"
     height="379">
<map name="workmap">
  <area shape="rect" coords="34,44,270,350"
        alt="Computer" href="computer.html">
  <area shape="rect" coords="290,172,333,250"
        alt="Phone" href="phone.html">
  <area shape="circle" coords="337,300,44"
        alt="Cup of coffee" href="coffee.html">
</map>
```

三步读法：

1. `<img>` 上的 `usemap="#workmap"` 指向后面那个 map 的 **name**（`#` 表示"同名"）。
2. `<map name="workmap">` 的名字必须和上面那个 `#workmap` 一致。
3. 三个 `<area>` 各带一个 `href`——**each region is its own link**（每个区域都是自己的链接）。课件的说明：点电脑、手机或咖啡，各去各自的页面。

## 三、四种形状与它们的坐标格式

课件给了一张明确的对照表：

| `shape` | `coords` 格式 | 读法 | 课件的例子 |
|---|---|---|---|
| **`rect`** | `x1,y1,x2,y2` | **两个对角**：先左上，再右下 | `coords="34,44,270,350"` |
| **`circle`** | `cx,cy,r` | **圆心 + 半径**（半径单位是像素） | `coords="337,300,44"` |
| **`poly`** | `x1,y1,x2,y2,…` | **顶点清单**，按顺序列出每个角 | `coords="84,24,146,24,84,88"` |
| **`default`** | 无 | **覆盖整张图**的一个兜底区域 | — |

课件的坐标总则：**Coordinates are x,y pairs in pixels, measured from the image's top-left corner**（坐标是像素单位的 x,y 对，从图片的左上角量起）。

```html
<!-- computer — a rectangle -->
<area shape="rect" coords="34,44,270,350"
      alt="Computer" href="computer.html">
<!-- phone — another rectangle -->
<area shape="rect" coords="290,172,333,250"
      alt="Phone" href="phone.html">
<!-- coffee — a circle -->
<area shape="circle" coords="337,300,44"
      alt="Cup of coffee" href="coffee.html">
<!-- irregular — list every corner -->
<area shape="poly" coords="84,24,146,24,84,88">
```

`poly` 那行只有三个坐标对，也就是三个顶点——**浏览器负责把点连起来并闭合**。

## 四、这些数字怎么定

课件单独用一页讲"Picking the Numbers"，是整门课里最需要动手试的地方。

### 1. (0,0) 是左上角的那一个像素

**The image is a grid: x grows to the right, y grows down.**

关键的一句：**Coords are positions on the image file — not on the page**（坐标是**图片文件上**的位置，**不是页面上的**）。这个区分决定了下面所有的注意事项。

### 2. 量真实的图片

课件给的样例文件是 **workplace.jpg，400 × 379 px**。它建议：在 Preview / 编辑器里打开它，或者在浏览器里悬停它——**你读到的数字就是这些像素位置**。

所以 `x` 的合法范围是 0–400，`y` 的合法范围是 0–379。上面示例里的 `coords="337,300,44"`，圆心 (337,300) 落在图内，半径 44 意味着它从 x=293 伸到 x=381、y 从 256 到 344——**都在图内**。

### 3. 按形状读数

| 形状 | 怎么读（课件原话） |
|---|---|
| `rect` | 读**一个**左上角的 x,y 对，和**一个**右下角的 x,y 对 → `(34,44)–(270,350)` 把电脑圈住 |
| `circle` | 读**杯子的正中** `(337,300)`，然后**向外一个一个像素量到它的边** → 半径是 44 |
| `poly` | **沿着轮廓走一圈**，按顺序列出每个角：`x1,y1, x2,y2, x3,y3, …`，浏览器连点并闭合 |

### 4. 先测，再调

> **Test, then tune. Click every region once. If a hit misses, adjust one number and reload.**
> （先测再调。每个区域都点一次。哪一下没打中，就改一个数字再刷新。）

这是唯一可靠的办法——**没有工具能替你算出这些数，只有试。**

> [!warning] 绝对不要用 CSS 改这张图的大小
> 课件的原话是：**Never resize the `<img>` with CSS — coords are fixed to the file's own pixels.**
>
> 原因就在上面第 1 条：坐标属于**图片文件**，而 CSS 缩放的是**显示盒子**。一旦你在 CSS 里写了 `width: 200px`（而文件本身是 400px 宽），图被压到一半大，但坐标仍按 400px 计算——**点击位置整体错位**。要改尺寸，就在 `<img>` 的 `width` / `height` 属性上改，**并且同时重算所有坐标**。
