# 表单与输入 · Forms & Inputs

> **一句话**：表单是**收用户输入的那道门**——`<form action="…">` 决定数据送到哪、`method` 决定数据走 URL 还是走请求体，而 `type` 决定了浏览器免费给你哪种控件。

课件原文见 [Lecture_02_HTML.pptx](<../../raw/Lecture_02_HTML.pptx>)。本篇覆盖课件的 "Why Forms?"、"The `<form>` Element"、"Input Attributes"、"Input Types" 和 "Inputs in Action" 五部分。

## 一、为什么需要表单

课件给了四条理由：

| 课件的说法 | 展开 |
|---|---|
| **The doorway for input**（输入的大门） | 每一个登录、搜索、结账都是一个表单 |
| **Submit to a server**（提交给服务器） | 表单数据**作为一个 HTTP 请求发出**（课件注明：Week 9） |
| **Many control types**（多种控件类型） | 文本、邮箱、密码、日期、复选框、单选…… |
| **Label everything**（给每个控件加标签） | 可访问的表单**给每个控件都配标签** |

```html
<form action="/submit" method="post">…</form>
```

> [!note] "HTTP 请求"这一句点到为止
> 课件在表单这页只说了"数据作为一个 HTTP 请求发出"这一句，并把 HTTP 标为 **Week 9** 的内容。本库目前只有 Week 1 概览层级的那一页，讲请求与响应结构的是 [[HTTP与URL]]。**那篇是概览，不是 Week 9 的正式内容**——想要 `?key=value` 到底怎么编码，得等 Week 9 的课件进 `notes/raw/`。
> 同样，课件在完整表单那页留了一句 **Week 11: an Express route will receive this form's fields**（一条 Express 路由会收到这个表单的字段），对应的 [[后端技术栈]] 目前也只是 Week 1 的概览层级。

## 二、`<form>` 的三个属性

| 属性 | 课件的说法 |
|---|---|
| **`action`** | 数据**送到哪里**——那个 URL，**必需** |
| `method="get"` | 数据**放进 URL**（`?key=value`）——用于**简短、非敏感**的查询 |
| `method="post"` | 数据**放进请求体**（request body）——用于**任何敏感或较长**的内容 |
| `target` | 结果**在哪里打开**——`_blank`、`_top`，或同一窗口 |
| （提交按钮） | **触发这次发送** |

### `get` 还是 `post`

这是本篇最需要判断力的一处：

| | `get` | `post` |
|---|---|---|
| 数据放哪 | **URL 里**（`?key=value`） | **请求体里** |
| 适合 | 短、非敏感的查询 | **敏感或长**的内容 |
| 直观后果 | 数据出现在地址栏里，**可以被收藏、被复制、被看见** | 不暴露在地址栏 |

例子里 `action="/submit" method="post"`，即"把数据 POST 到 `/submit` 这个地址"。

```html
<form action="/submit" method="post">
  <label>Name: <input name="name"></label>
  <label>Email: <input type="email"></label>
  <button type="submit">Send</button>
</form>
```

> [!warning] 密码不能用 `get`
> 上表里"数据出现在地址栏里，**可以被看见**"这一条就是原因。课件写的是"任何敏感或较长"用 `post`——**密码当然属于敏感**。这条判断不需要犹豫。

## 三、`input` 的属性

| 属性 | 课件的说法 |
|---|---|
| `type` | 哪种控件——text、email、password、checkbox…… |
| `name` | **服务器收到这个字段时用的键**（the key the server receives for this field） |
| `id` | 一个**唯一标识**——与 `<label for="…">` 配对 |
| `value` | 字段的当前值，或**预填的默认值** |
| `placeholder` | 灰色提示文字——**不能替代 label** |
| `readonly` / `disabled` | 只读 / 完全不可用 |
| `required` | 提交前**必须填** |

```html
<input type="email" name="email"
       id="em"
       placeholder="you@polyu.edu.hk"
       required>
<input type="text" value="locked" readonly>
```

三个最容易被混的：

- **`name`** 是**给服务器看的**键（表单提交时 `?name=…` 里的那个名字）。
- **`id`** 是**给页面看的**唯一标识（`<label for>` 找的是它）。
- **`value`** 是**内容本身**（`value="locked"` 就是这个框里的字）。

`readonly` 和 `disabled` 也有区别：前者**值还在、能被选中复制、能提交**，只是改不了；后者是**完全失活**。

> [!note] `placeholder` 那一行已经预告了下一篇
> 课件在这里就写了 "not a substitute for a label"，并在表单可访问性那一页把它列为一条独立规则 **Placeholder ≠ label — hints vanish; labels stay**（提示会消失，标签会留下）。这条完整展开在 [[表单验证与可访问性]]。

## 四、input 类型全表

课件给的这张表是本篇最有实用价值的一段——**每种类型浏览器都免费附带一套行为**。

| `type` | 控件 | 课件的说法 |
|---|---|---|
| `text` | 单行文本 | Single-line text |
| `password` | 掩码文本 | Masked text（输入被遮住） |
| `email` | 邮箱框 | **With built-in format validation**（自带格式校验） |
| `url` | 地址框 | For web addresses |
| `number` | 数字框 | Numeric input |
| `date` | 日期框 | 带一个**日历选择器**（calendar picker） |
| `range` | 滑块 | A slider |
| `color` | 颜色选择器 | A colour picker |
| `checkbox` | 复选框 | Tick boxes——**可多选** |
| `radio` | 单选框 | Mutually-exclusive choices——**互斥** |
| `submit` | 提交按钮 | Send the form |
| `reset` | 重置按钮 | Clear its values |
| `file` | 文件上传 | Upload a file |

```html
<input type="text">
<input type="password">
<input type="email">
<input type="number">
<input type="date">
<input type="checkbox"> Remember me
<input type="file">
```

`checkbox` 与 `radio` 的差别是这一组里最实用的一条：**复选框可以同时勾多个，单选框一组里只能选一个。**

课件的结论句：**The type tells the browser what kind of input**（`type` 告诉浏览器这是哪种输入），并补了一句 **Dozens of types — the browser gives each one free behaviour**（类型有几十种，而浏览器给每一种免费附赠行为）。

### 实际写起来

```html
<input type="text" name="username">
<input type="password" name="pw">
<input type="email" placeholder="you@polyu.edu.hk">
<input type="number" min="0" max="100">
<input type="date">
<input type="checkbox"> Remember me
```

注意 `type="number"` 带着 `min="0" max="100"`——这两个限制属性和 `type` 是**分开**的：类型决定用什么控件，`min` / `max` 决定允许的值。
