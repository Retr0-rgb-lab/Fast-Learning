# 文本语义 · Text Meaning

> **一句话**：`<h1>`–`<h6>` 讲的是**层级**而不是字号，`<strong>` / `<em>` 讲的是**意义**而不是粗体斜体——课件反复强调的那句是 "Mark meaning, not just appearance"。

课件原文见 [Lecture_02_HTML.pptx](<../../raw/Lecture_02_HTML.pptx>)。本篇覆盖课件的 "Headings & Paragraphs" 与 "Text Meaning (Not Just Looks)" 两部分。

## 一、标题与段落

| 标签 | 课件的说法 |
|---|---|
| `<h1>`–`<h6>` | **六级**标题，h1 最大、h6 最小 |
| One `h1` per page | 每页**一个 h1**，它是主标题；其余级别用来表达**层级** |
| `<p>` | 一段正文（a paragraph of body text） |
| Whitespace collapses | **空白折叠**：多余的空格和换行会被忽略——要换行请用标签 |

```html
<h1>Main title</h1>
<h2>Section</h2>
<h3>Sub-section</h3>
<p>A paragraph of body text…</p>
<!-- one h1 per page, then h2, h3… -->
```

### 层级，不是大小

h1 最大 h6 最小的说法很容易被误读成"**级别只决定字号**"。课件紧接着给的那句才是关键：**use levels for hierarchy**（用级别表达层级）。

也就是说，`<h3>` 看起来比 `<h1>` 小，**但真正的信息是"这一节比上一节深了一层"**。这个层级本身是内容，与它最终显示成多大无关。

课件还说明了谁在依赖这个层级：**screen readers and search engines rely on them**（屏幕阅读器和搜索引擎都依赖标题结构）。

> [!important] 屏幕阅读器怎么用标题
> 屏幕阅读器可以让用户**只听标题**来通读一整页——这叫用标题跳转。用户听到的将是"标题层级 1：Main title，标题层级 2：Section，标题层级 3：Sub-section"。**如果层级乱写，这个导航就废了**：一串 h2 h2 h2 读起来像平级，而实际上它们是主从关系。

### 空白折叠

```html
<p>Hello
     world</p>
```

换行和连续空格在页面上都只渲染成**一个空格**。想真正换一行，必须用标签（`<br>`）——这正是下一节的内容。

> [!tip] 为什么这条规则值得知道
> 有人会在 HTML 里用一长串空格或回车来"排版"。空白折叠会让这些全部失效，结果看起来是"代码明明这么写了却不生效"。**HTML 源文件的换行和缩进只对你自己可见**，对渲染结果几乎没影响。

## 二、文本意义（不只是外观）

课件这一节的标题直接叫 **"Text Meaning (Not Just Looks)"**，副标题是 **"Mark meaning, not just appearance"**。它给了六组：

| 标签 | 语义 | 课件的建议 | 例子 |
|---|---|---|---|
| `<strong>` / `<b>` | 强调重要性（strong importance） | **要意义就用 `<strong>`** | `This is <strong>important</strong>` |
| `<em>` / `<i>` | 强调（emphasis） | **要意义就用 `<em>`** | `and <em>emphasised</em>` |
| `<mark>` | 高亮的文本（highlighted text） | — | — |
| `<sub>` / `<sup>` | 下标 / 上标 | — | `H<sub>2</sub>O`、`x<sup>2</sup>` |
| `<br>` | 换行（**void element**，无结束标签） | — | — |
| `<hr>` | 主题分隔（thematic break）——一条水平线 | — | — |

### 为什么 `<b>` 和 `<strong>` 要分开

两个标签**渲染出来一样**（都加粗），但课件只让 `<strong>` 承载意义。同样的道理适用于 `<i>` 和 `<em>`。

这条规则的实际后果是：**`<b>` 留给"只是想要个粗体"的情况，而"这句话很重要"要写 `<strong>`。** 一旦搜索引擎、屏幕阅读器、以及未来任何读取这份标记的程序要判断哪句话是重点，它们只会认语义标签。

`H<sub>2</sub>O` 和 `x<sup>2</sup>` 是课件给的两个标准例子——**下标上标是数学写法的一部分，不是样式**，所以它们是文本语义而不是 CSS 效果。

### `<br>` 和 `<hr>` 的分工

| 标签 | 做什么 | 属于哪一类 |
|---|---|---|
| `<br>` | 行内**换行** | **void element**（无结束标签） |
| `<hr>` | 块之间的**主题分隔**（一条横线） | 课件在同一组里列出 |

`<br>` 被写成 void element 这一点，和 [[元素与标签语法]] 里的空元素规则是同一条：没有内容，所以没有结束标签。

## 三、把这些合起来

一个把标题层级、段落、意义标签都用上的小例子（照着示例站的结构写）：

```html
<h1>COMP3421 Web Application Design and Development</h1>

<h2>Course Description</h2>
<p>This is a <strong>13-week</strong> course covering the <em>full stack</em>:
  HTML, CSS, JavaScript and a Node.js backend.</p>
<p>Water formula: H<sub>2</sub>O &nbsp;— squared: x<sup>2</sup><br>Second line of the same paragraph.</p>
<hr>

<h3>Prerequisites</h3>
<p>Students should be comfortable writing <mark>plain text files</mark>.</p>
```

- 只有一个 `<h1>`，之后是 h2、h3，层级连续。
- `13-week` 用 `<strong>`，`full stack` 用 `<em>`。
- `H<sub>2</sub>O`、`x<sup>2</sup>` 是标准的上下标写法。
- 换行靠 `<br>`，源文件里的换行和缩进不起作用（空白折叠）。
- 一条 `<hr>` 把"课程介绍"和"先修要求"在主题上分开。
