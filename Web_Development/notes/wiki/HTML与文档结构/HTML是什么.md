# HTML是什么 · What Is HTML?

> **一句话**：HTML（HyperText Markup Language，超文本标记语言）只负责**说清页面上"有什么"**，长什么样是 CSS 的事——它是每个网页底下那副骨架。

课件原文见 [Lecture_02_HTML.pptx](<../../raw/Lecture_02_HTML.pptx>)。本篇覆盖课件的 "What Is HTML?" 与 "Brief History of HTML" 两部分：HTML 的定义、它与 CSS 的分工边界，以及 1989–2025 的发展时间线。

## 一、它是什么

课件的定义只有一句，但这句话是整门课的起点：**HTML 是每一个网页所用的语言，它给页面结构（structure）和意义（meaning）**。

课件把这句话拆成四层，每一层都在划边界：

| 课件的说法 | 含义 |
|---|---|
| **Structure, not looks**（结构，不是外观） | HTML 说**页面上有什么**，CSS 说**它长什么样** |
| **Rendered by the browser**（由浏览器渲染） | 浏览器读 HTML，然后把它画到屏幕上 |
| **The skeleton**（骨架） | 你用过的每一个页面，底下都是 HTML |
| HyperText Markup Language | 标记语言——用标记把内容标出结构 |

注意 "Markup"（标记）这个词：HTML 不是编程语言，它不计算、不判断分支，它只是**给内容贴标签**，告诉浏览器"这段是标题""这段是链接"。

最小的一个例子，课件给的就是这一句：

```html
<p>This is a paragraph of text.</p>
```

<p> 标签告诉浏览器：这里是一段正文。于是这段文字在页面上会占据一整块、有行间距、与前后内容分开——**这些结果没有一个是写出来的，全是这个标签的语义带来的**。

> [!important] "结构而非外观"是一条分工线，不是偏见
> HTML 不负责颜色、字号、间距。同一份 HTML 配上不同的 CSS 文件，可以是黑色文字，也可以是蓝色大字加粗。**HTML 那部分不变。** 这条线一旦模糊，后面所有 CSS 的学习都会变得没有意义。

### 示例站上的体现

本库全篇共用的那个假想课程主页（「示例站」，设定见 [[课程场景与阅读约定]]）：它顶部有 `header` + `nav`，中间是 `main`（课程表格 + 报名表单 + 配图），底部是 `footer`。**这些"哪一块是哪一块"的信息，全部由 HTML 提供**；而主色 `#1E4FA8`、行距、圆角，是 CSS 之后加上去的。本篇之后的所有例子，都可以回到这个页面上跑。

## 二、为什么它由浏览器渲染

课件这一层值得单独说一句，因为它解释了"HTML 到底是给谁看的"。

HTML 是一份**纯文本**文件。你双击它，浏览器读到的就是那些尖括号和文字。浏览器内置一个 HTML 解析器，把文本变成屏幕上的像素。所以：

1. **写 HTML 只需要两样东西**：一个纯文本编辑器 + 一个浏览器。课件明确说 Notepad（PC）/ TextEdit（Mac）就够，VS Code 更好（有语法高亮和代码补全）。
2. **保存成 `.html` 就行**：扩展名告诉浏览器"这是个网页"。
3. **存成 `index.html`，双击，浏览器立刻渲染出来。**
4. **看到效果的方式是 编辑 → 保存 → 刷新**（live preview）。

> [!tip] 不用装任何东西
> 课件在这页的结论句是："You need only a text editor and a browser." 没有框架、没有构建工具、没有服务器。HTML 的门槛低到可以马上开始，这是它能作为 Web 第一课的原因。

## 三、简短发展史

课件给了一条时间线，每个节点只有一句定性：

| 年份 | 节点 | 课件的说法 |
|---|---|---|
| **1989** | Invented（发明） | Tim Berners-Lee 创造 Web |
| **1997** | HTML 4.01 | 为早期 Web 标准化（Standardised） |
| **2008** | HTML5 draft | 第一个公开草案出现（First public draft appears） |
| **2014** | W3C Recommendation | HTML5 定稿（finalised） |
| **2025** | Living standard（活标准） | 持续改进（Continuously improved） |

课件对这条线的总结是：**HTML 从简单的文本格式演进成了一个活标准（living standard），而且它仍在演进。**

"Living standard" 这个词值得停一下：它不是"某年定稿然后冻结"的东西，而是**一直在改的**。所以 2008 和 2014 之间隔了六年（草案到定稿），也说明这件事的节奏比"发布一个版本"要慢。

> [!note] 1989 那个名字
> Tim Berners-Lee 在 1989 年造的是 Web（连同第一版 HTML 和第一台浏览器）。课件把"发明"归在这一年，是把"Web 诞生"和"HTML 诞生"当作同一个起点事件来讲。
