## 四、两个需要预设的场景（明确交代）

课程原话只点到为止的地方，本知识库为了让笔记能读得通，**预设了下面两件事**。它们不是课件原文，是为了让例子自洽而做的约定，在此声明：

### 场景 A：贯穿全库的示例页面

课件在讲每个属性时会用"看这个例子"，但**例子本身在课件里只是一张截图**。为了避免笔记出现"如上图所示"这种断链，本库统一设定：

> 全库共用**一个假想的课程主页**作为例子载体，称为「示例站」。它是一张典型的课程介绍页：顶部 `header` + 导航 `nav` + `main`（课程表格 + 报名表单 + 配图）+ `footer`。

凡是笔记里出现"示例站""这个课程主页"，指的都是它。各篇笔记会用它来跑具体代码（改一个 `color`、加一条 `margin`），**代码和结果都写全在本篇内**，不靠回忆。

### 场景 B：课程调色板

CSS I（Week 3）明确给出了一套课件自己的配色。**这套色值是课件原文**，本库把它当作全库的颜色锚点，这样跨篇的颜色例子能对上：

| 名称 | 色值 | 用途 |
|---|---|---|
| Navy | `#0E3F8C` | 深色底、页脚 |
| Primary | `#1E4FA8` | **主色**——正文标题、链接、强调 |
| Mid | `#3D7BD9` | 次级强调、hover |
| Pale | `#9DC0EE` | 浅底、区块背景 |
| Sky | `#B9CDEE` | 更浅的分隔 |
| Gold | `#FFC107` | 提示、高亮 |
| Alert | `#D9534F` | 错误、警告 |

> 课件里另有几处用了另一组十六进制值（`#185fa5`、`#2e7d32`、`#d9534f` 等，见层叠那几页），那是**讲"规则互相竞争"时随手配的对比色**，不是调色板成员。笔记里出现这类值时，会标明它们只是示意。

## 五、示例站地址怎么用

课件每页底部都印着同一个地址：

```
tagsysx.github.io/comp3421/
```

它是课程配套的**在线示例站**，每页课件的示例都对应站内一个可实时编辑的页面。笔记里出现的 `editor.html?example=html/lists` 这类路径，就是**站内某个示例的定位串**，作用等同于"翻到课件这页看那个演示"。

它**不是**本知识库自建的东西，也不需要联网就能读笔记 —— 笔记已经把每段代码和预期结果写全。留这个路径只是为了让你想去现场看时知道去哪儿。

## 六、目录与命名规则

这几条是硬约定，改动前请先读：

- **目录名一律不带数字。** 现有的 `敏捷开发`、`系统建模` 这样的主题名，永远不带编号。理由：数字会诱使人重排（"1. 需求 2. 设计"），而重排会让旧笔记里的双链和记忆一起作废。Obsidian 的双链**按文件名解析、不按路径**，所以目录不带数字就不会有"改名要改一堆链接"的问题。
- **按主题分目录，不按讲次分。** Week 3 的颜色和 Week 5 的变量是同一条线索，就该挨着放，而不是按"第几周"隔开。
- **文件名不带数字、不带 `Lecture_` 前缀。** 课件叫 `Lecture_03_CSS.pptx`，笔记叫 `颜色表示法.md`。
- **目录名用中文**，与本 vault 其余课程（`敏捷开发` / `系统建模` / `需求工程`）保持一致。

## 七、每篇笔记的固定结构

为了复习时能一眼认出结构，所有笔记统一如下：

```markdown
---
tags: [WD, <主题>, <若干关键词>]
course: COMP3421
lecture: L03
---

# 标题 · English

> **一句话**：<把整篇的核心结论压成一句>

课件原文见 [Lecture_03_CSS.pptx](<../../raw/Lecture_03_CSS.pptx>)。<出处说明>

<正文：概念 → 表格 → 代码 → 易错点>

## 关联

- <关系类型> → [[目标笔记]]（<为什么连>）
```

- **frontmatter**：`tags` 首项固定为 `WD`（本 vault 中 `WD` = Web Development）。`lecture` 用课件编号（L01–L05 / T01）。
- **"一句话"**：整篇的结论先给出来，再展开。
- **正文自足**：不写"见课件第 X 页"。例子要么写全，要么换成通用例子。这是本 vault 的既有原则（见 `Software_Engineering/log.md`）。
- **`## 关联` 段**：反向连接。每条写清**关系类型**和**为什么连**，不是只丢一串链接名。跨主题的长连接不写在这里，集中在 [[index|MOC]] 的连接表里。

## 八、怎么复习

1. **按主题走** → 打开 [[index]]，选一个主题目录。
2. **零散翻** → 直接打开 `notes/wiki/<主题>/` 下任意一篇，每篇末尾的 `## 关联` 就是它的邻居。
3. **查原文** → 笔记顶部的出处行指向 `notes/raw/` 里的对应 PPTX。
4. **看连接** → [[index]] 末尾的「跨主题连接表」，那里放的是跨越目录、单独值得记的线索。
