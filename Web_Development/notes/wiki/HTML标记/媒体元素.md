# 媒体元素 · Audio & Video

> **一句话**：`<audio>` 和 `<video>` 各只靠**一个 `controls` 属性**就换来一整套播放条，格式兼容靠**多写几个 `<source>` 让浏览器挑第一个能放的**，再写一句**回退文字**兜底。

课件原文见 [Lecture_02_HTML.pptx](<../../raw/Lecture_02_HTML.pptx>)。本篇覆盖课件的 "Audio" 与 "Video" 两页（课件这两页归在 "Media & Accessibility" 名下）。

## 一、音频 `<audio>`

| 机制 | 课件的说法 |
|---|---|
| `controls` | **显示播放 / 暂停 / 音量按钮** |
| `<source>` | 多种格式——**浏览器播放它支持的第一个** |
| 回退文字（fallback text） | **不支持音频时显示**的内容 |
| **No plugins** | HTML5 音频**原生播放——不再需要 Flash** |

```html
<audio controls>
  <source src="song.mp3" type="audio/mpeg" />
  <source src="song.ogg" type="audio/ogg" />
  Your browser does not support audio.
</audio>
```

### 三件事分开看

**1. `controls` 是整个元素里最重要的那个属性。** 不写它，音频元素是**静默的**——页面上什么都不出现，用户没法控制。有了它，播放、暂停、音量三组按钮由**浏览器自己画**。

**2. `<source>` 写几条都行。** 课件的两个例子是 `song.mp3` 和 `song.ogg`——同一个音频的两种格式。浏览器的规则是：**从上往下试，播放第一个它支持的**。所以顺序有意义，把最通用/最优的放前面。

**3. 回退文字放在最后。** 课件例子里那句 `Your browser does not support audio.` 是**元素的文本内容**——只有当前面两条 source 都失败时才显示。

> [!important] "No plugins" 是 HTML5 相对 Flash 的全部意义
> 课件原话：**HTML5 audio plays natively — no Flash needed**（HTML5 音频原生播放——不需要 Flash）。
>
> 课件给这一页下的结论是：**Audio plays in the browser — no third-party plugin required**（音频在浏览器里播——不需要任何第三方插件）。
>
> 这一点值得和 [[HTML是什么]] 那篇合起来看：HTML 的价值不只在于"结构"，还在于它把一批原本需要插件的能力**收进了标准**。

## 二、视频 `<video>`

| 机制 | 课件的说法 |
|---|---|
| `controls` | 播放、暂停、**音量**和**全屏**（fullscreen） |
| `width` / `height` | **播放器盒子**的尺寸 |
| `<source>` | **多试几种格式**，以获得跨浏览器支持 |
| 回退文字 | **视频放不了时显示** |

```html
<video width="320" controls>
  <source src="movie.mp4" type="video/mp4" />
  <source src="movie.ogg" type="video/ogg" />
  Your browser does not support video.
</video>
```

课件的结论句：**Embedded video, straight from markup — no plugin**（视频直接从标记里嵌进去——无插件）。

### 音频与视频的差异

| | `<audio>` | `<video>` |
|---|---|---|
| `controls` 带来 | 播放 / 暂停 / 音量 | 播放 / 暂停 / 音量 / **全屏** |
| `width` / `height` | 课件**没提** | **有**，控制播放器盒子大小 |
| `<source>` 的理由 | 多种格式 | 多种格式，课件明说是为了 **cross-browser support** |
| 都有回退文字 | 是 | 是 |

> [!warning] `width` 要和高度一起考虑
> 课件给的是 `<video width="320" controls>`，只有宽度。这和 [[链接与图像]] 里"`width` / `height` 成对写以避免 layout shift"的建议方向一致：**播放器盒子的宽高比最好确定下来**，否则视频加载完可能把页面内容顶一下。视频的默认宽高比浏览器是知道的，但自己写清楚更保险。

## 三、把两者放在一起看

| 共同做法 | 具体写法 |
|---|---|
| 加一个 `controls` | 让浏览器画出播放器 |
| 列多个 `<source>` | 第一个能播的胜出 |
| 末尾写回退文字 | 都不行时给一句话 |
| 不写任何插件声明 | 全部原生 |

三个元素的角色其实和 `<img>` 一致：**`<img>` 是媒体的一种（静态图），`<picture>` 是它的响应式版本，`<audio>` / `<video>` 是另外两种媒体。** 都是 void 元素或自成一体的元素，来源都写在 `src` / `srcset` 上。
