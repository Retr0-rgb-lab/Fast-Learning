# 阴影 · box-shadow

> **一句话**：`box-shadow` 五个值 —— **offset-x · offset-y · blur · spread · colour** —— 一个声明同时能给出**高度感**、**焦点环**和**凹陷感**；但阴影只画**暗色**，两条三道柔和的比一道生硬的更好看。

课件原文见 [Lecture_05_CSS.pptx](<../../../raw/Lecture_05_CSS.pptx>)。本篇覆盖其中「Miscellaneous」一节的阴影部分：box-shadow 一页与 Shadow Recipes 一页。

## 一、五个值

```
offset-x  ·  offset-y  ·  blur  ·  spread  ·  colour
   X         Y          模糊    扩散      颜色
```

```css
/* x  y  blur  spread  colour */
.card {
  box-shadow: 0 6px 16px 0 rgba(0,0,0,.18);
}
```

| 值 | 作用 | 记法 |
|---|---|---|
| `offset-x` | 水平偏移 | 正数向右 |
| `offset-y` | 垂直偏移 | **正数向下** —— 光从上方来，影子在下方 |
| `blur` | 模糊半径 | 0 = 完全不模糊，影子边缘硬 |
| `spread` | 扩散半径 | **放大或缩小整个影子** |
| `colour` | 颜色 | 用带 alpha 的颜色几乎总是更好 |

> [!tip] 阴影要带 alpha
> `rgba(0,0,0,.18)` 比 `#000` 好，原因是 alpha 让影子在浅色和深色背景上都能融进去。纯黑不透明会得到一块脏斑。alpha 的其他用法见 [[透明度与叠加层]]。

## 二、`spread`：焦点环就是它

`spread` 让影子在各个方向上**长大**或**缩小**。课件点名的用法是：**焦点环（focus ring）是一个没有模糊的 spread**。

```css
/* 焦点环：只有 spread，没有 blur，没有 offset */
.card:focus-visible {
  box-shadow: 0 0 0 3px #3D7BD9;
}
```

拆开看这三个数字：

| 值 | 是什么 | 为什么这样 |
|---|---|---|
| 第一个 `0` | offset-x | 水平不偏移 |
| 第二个 `0` | offset-y | 垂直不偏移 —— 所以它是**均匀向外**的一圈 |
| 第三个 `0` | **blur = 0** | **不模糊** —— 环才有清晰的边 |
| `3px` | **spread** | 往外长 3px |
| `#3D7BD9` | 颜色 | 课程调色板的 Mid |

> [!important] 焦点环和「阴影」是两种不同的东西
> 阴影模拟光，offset 的方向**有物理含义**（下方有影 = 光从上来）。焦点环是一个**提示**，它必须**四面一样厚**，所以 offset 要 `0 0`、blur 要 `0`，厚度全部交给 spread。用 `0 6px 16px` 那种阴影当焦点环，环会一边厚一边薄 —— 看着像卡片浮起来了，而不是「这里被选中了」。

## 三、`inset`：按进去

`inset` 把影子**翻到盒子里面**，得到「被压进页面」的效果。

```css
/* inset = 盒子内部的阴影 */
.pressed {
  box-shadow: inset 0 2px 6px rgba(0,0,0,.35);
}
```

| 用法 | 配方 | 感觉 |
|---|---|---|
| 抬起 | `0 6px 16px …` | 盒子浮在页面上方 |
| 压下 | `inset 0 2px 6px …` | 盒子陷进页面里 |

> [!warning] `inset` 和「高光」不是一回事
> 真实材质的高光是**亮**的。这里得到的只是「内阴影」—— 一个边缘变暗的凹面，视觉上被读成凹陷。它足够便宜好用，但别把它当成真正的光照模拟。

## 四、多个阴影：逗号分隔，按顺序叠

`box-shadow` 可以写几个，用**逗号分隔**，它们**按写下的顺序叠**（第一条在最上面）。

```css
/* 两道阴影：先一道环，再在下面加高度 */
.ring {
  box-shadow: 0 0 0 3px #3D7BD9,
              0 8px 20px #0003;
}
```

这是本篇最实用的一个配方 —— **「环 + 深度」两段式**：

| 段 | 值 | 作用 |
|---|---|---|
| 第一段 | `0 0 0 3px #3D7BD9` | 焦点环：均匀、不模糊 |
| 第二段 | `0 8px 20px #0003` | 高度感：向下偏移 + 大模糊 |

> [!tip] 顺序为什么重要
> 环写在前面就压在高度感上面。写反了的话，那道偏移的阴影会盖在环的边缘上，环看起来发虚。**环永远写在第一条。**

## 五、五个配方

课件 Shadow Recipes 一页：

| 配方 | 写法 | 说明 |
|---|---|---|
| 轻微高度感 | `0 1px 3px rgba(0,0,0,.12)` | 静置状态的一张小卡片 |
| 悬停时抬起 | 加大 blur、加上几像素 offset | 配合 `transition` 最出彩 |
| 焦点环 | `0 0 0 3px` | 只有 spread，无 blur 无 offset |
| 按下 | `inset 0 2px 6px` | 盒子看起来被压进页面 |
| 照片上的文字 | 白色字下面垫一道柔和的暗影 | 保证白字在图上可读 |

跑在示例站（见 [[课程场景与阅读约定]]）的课程卡片上，课程调色板的中蓝做环：

```css
.card {
  background: #fff;
  border-radius: 10px;
  padding: 20px;
  box-shadow: 0 1px 3px rgba(0,0,0,.12);
  transition: box-shadow 0.2s ease, transform 0.2s ease;
}
.card:hover {
  box-shadow: 0 10px 20px -6px rgba(0,0,0,.25);
  transform: translateY(-4px);
}
.card:focus-visible {
  box-shadow: 0 0 0 3px #3D7BD9,
              0 10px 20px -6px rgba(0,0,0,.25);
}
```

照片上的白字那一款，用的是纯黑的柔和一层：

```css
figcaption {
  color: #fff;
  background: rgba(0,0,0,.55);
  padding: 8px;
}
```

> [!important] 「垫一层暗」正是 scrim 的思路
> 让白字压在照片上还能读，靠的是**给字底下加一层半透明的暗色**。这和视频播放器上的字幕条、弹窗背后的遮罩是同一个手法 —— 为什么它们存在，唯一的理由就是对比度，见 [[对比度与可读性]]。

## 六、一条审美规则

> **One dark shadow only — Two or three soft ones read better than one hard one.**

只画**暗色**阴影；两三条**柔和**的比一条**生硬**的好看。

意思是：

- 不要用纯黑、零模糊的硬边影子（`box-shadow: 4px 4px 0 #000`）—— 那是像素游戏的做法。
- 宁可叠两三层大 blur、低 alpha 的，也比一层硬边好看。
- 阴影不要用亮色。亮色阴影是另一个效果，也确实存在，但**不是这里说的高度感**。

## 七、`text-shadow` 的例外

课件在这一页的末尾给了一句需要特别记住的对照：

> **box-shadow takes a spread and inset; text-shadow takes neither.**

| | `box-shadow` | `text-shadow` |
|---|---|---|
| offset-x / offset-y | ✅ | ✅ |
| blur | ✅ | ✅ |
| **spread** | ✅ | ❌ **不支持** |
| **inset** | ✅ | ❌ **不支持** |

| 声明 | 能用 spread / inset 吗 |
|---|---|
| `box-shadow: 0 0 0 3px #3D7BD9;` | ✅ spread 有效 |
| `text-shadow: 0 0 0 3px #3D7BD9;` | ❌ 第三个值是 blur，不是 spread |

> [!warning] 一条写错就完全没反应的声明
> 给 `text-shadow` 写 `text-shadow: 0 0 0 2px #000`，浏览器不会警告你 —— 它把那三个零读成「两个 offset 都是 0，模糊半径 0」，于是**什么都没发生**。想要文字的描边效果得另找办法（常见做法是叠一层偏移的同色文字）。

## 关联

- 抬起来要配缓动 → [[过渡transition]]（「悬停抬起」是 shadow + transform + transition 三件套，缓动让高度变化有惯性）
- 照片上垫暗色 → [[透明度与叠加层]]（`rgba()` 的 alpha 在这里是 scrim 的底座）
- 白字压照片的可读性 → [[对比度与可读性]]（那层暗影存在的唯一理由就是对比度）
- 环要压住谁 → [[层叠顺序与z-index]]（z-index 管盒子之间的先后；多道阴影管盒子**自己**的上下两层）
- 颜色值怎么写 → [[颜色表示法]]（`rgba()` 与 hex 的关系）
- 边框的另一半外观 → [[边框与圆角]]（描边走 `border`，投影走 `box-shadow`，两者常一起用）
