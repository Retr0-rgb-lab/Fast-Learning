# 简单选择器 · Simple Selectors

> **一句话**：元素选择器 `p`、id 选择器 `#para1`、class 选择器 `.center`、通配符 `*`——日常样式几乎全靠 **class**，id 留给 JavaScript 和页内链接，经验法则一句话：**用 class 上样式，用 id 寻址。**

课件原文见 [Lecture_04_CSS.pptx](<../../../raw/Lecture_04_CSS.pptx>)。本篇覆盖 Week 4 "Selectors" 一节的前半：四种简单选择器各自的写法与代价，class 与 id 的对照表，以及那条经验法则。

## 一、元素选择器（Element）

```css
/* every <p> element on the page */
p {
  text-align: center;
  color: #1E4FA8;
}
```

| 特点 | 说明 |
|---|---|
| 选谁 | 选**每一个**同名标签，页面上任何位置都算 |
| 需要的钩子 | **不需要额外钩子**——但也因此**没有例外**，没法只排除某几个 |
| 适合做什么 | 适合定**基调**：`body`、`h1`、`p`、`ul`——一次设好 |

课件称它为 **the blunt hook（钝钩子）**。好用就好在不需要 HTML 配合；不好用也在这：一旦某个 `p` 想例外，就只能给它加个 class 把它单独捞出来。

## 二、id 选择器（ID）

```css
/* the one element with id="para1" */
#para1 {
  text-align: center;
  color: #1E4FA8;
}
```
```html
<p id="para1">Only one element can carry this id.</p>
```

| 特点 | 说明 |
|---|---|
| 写法 | 一个**井号 `#`**，后接 HTML 里**原样书写**的 id |
| 唯一性 | 一个 id 在**一页里只对应一个元素** |
| HTML 侧 | 属性写作 `<p id="para1">` |
| 课件的评价 | **Strong but rigid**（强，但硬） |
| 建议 | **把 id 留给 JavaScript 和页内链接** |

"rigid" 指的是它的唯一性同时也是它的枷锁：一个 id 只能被一个元素用，而一个元素往往又需要好几个指向它的钩子。

## 三、class 选择器（Class）

```css
.center  { text-align: center; }
p.center { color: #1E4FA8; }
```
```html
<p class="center large">Two classes, one tag.</p>
<h2 class="center">Also centred.</h2>
```

| 特点 | 说明 |
|---|---|
| 写法 | 一个**句点 `.`**，后接 HTML 里的钩子：`<p class="center">` |
| 可复用 | 同一个钩子挂很多元素：`p` 和 `h2` 都能有 `class="center"` |
| 限定标签 | `p.center`——**只给带这个 class 的 `<p>`**，把标签摁住 |
| 不止一个 | `<p class="center large">`——**两个一起** |
| 课件的定位 | **The main hook**——大部分样式都靠它 |

`.center` 同时给了 `<p>` 和 `<h2>`；`p.center` 只给 `<p>`。这两个的区别就是"要全部"和"只要某类元素"。

## 四、通配符（Universal）

```css
* { color: blue; }

/* the classic reset */
* { margin: 0; padding: 0; }
*, *::before, *::after {
  box-sizing: border-box;
}
```

| 特点 | 说明 |
|---|---|
| 写法 | `*` 匹配页面上的**每一个元素** |
| 课件的评价 | **A very big brush**——一把很大的刷子 |
| 该干的事 | 它的经典岗位是**重置（reset）**，在别的样式之前先做 |
| 代价 | 通用规则是**应用得最慢**的一类（a universal rule is the slowest kind to apply） |

> [!tip] 那条经典重置里藏着盒模型的伏笔
> `* { margin: 0; padding: 0; }` 是清掉浏览器默认的外边距和内边距——因为**盒属性不继承**，每个元素都得自己清，见 [[继承]]。
> 紧跟着的 `box-sizing: border-box` 改变的是**"宽度指的是哪一层"**这个定义问题，属于盒模型，见 [[尺寸与盒模型计算]]。注意它连 `::before` 和 `::after` 一起带上，因为伪元素也会生成盒子。

`margin` / `padding` 是这里唯一被提到的两个属性——它们属于盒子的哪几层，见 [[盒模型五层]]。

## 五、class vs id

| `.class` | `#id` |
|---|---|
| **可复用**：很多元素可以共用一个 class | **唯一**：一页一个 id，一个元素 |
| **样式的钩子**：几乎所有样式都用 class | **JS 的钩子**：id 留给 JavaScript 和链接（`#hash`） |
| **一个元素可有多个**：`class="card big"` | 只有一个 |
| — | **过于具体**：用 id 做样式会让覆盖变得痛苦 |

课件最后那行经验法则，建议原样记住：

> **Rule of thumb: style with classes, address with ids.**
> 用 class 上样式，用 id 寻址。

`class` 和 `id` 都是 HTML 属性，定义在 [[属性]]。它们其实是**留给 CSS 和 JavaScript 的同一批钩子**，只是分工不同——这正是 MOC 里那条跨主题连接的由来。

## 六、写在示例站上

```css
/* 定基调：元素选择器，一次设好 */
body { font-family: sans-serif; color: #1E4FA8; }
h1   { font-size: 2em; }

/* 复用：class 挂到很多元素上 */
.note   { color: #4A5568; }
.center { text-align: center; }

/* 例外：从 body 上摘下来，单独处理 */
footer  { color: #B9CDEE; }

/* 绝不这样写：给页脚一个 id 纯粹为了上色 */
/* #footer { color: #B9CDEE; }  ← 覆盖它将无法下手 */
```

## 七、易错点

- 写 `#para1` 却忘了在 HTML 里写 `id="para1"`，或者大小写对不上——id 是**原样匹配**。
- 用 id 上样式：这条规则几乎无法被覆盖，除非动用 `!important`（见 [[层叠与优先级]]）。
- 把 class 选择器的**句点**写进 HTML：`class="center"` 里**不带点**，`.` 只属于 CSS 那边。
- 给每个元素都上 `* { }` 规则：它是应用最慢的一类。
