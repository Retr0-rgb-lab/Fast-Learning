# 属性选择器 · Attribute Selectors

> **一句话**：属性选择器不靠标签名、id 或 class，而是**直接问元素"你有没有这个属性、值是不是这样"**——后三种是位置测试：**开头是、结尾是、包含**。

课件原文见 [Lecture_04_CSS.pptx](<../../../raw/Lecture_04_CSS.pptx>)。本篇覆盖 Week 4 "Selectors" 一节的属性选择器：五种形式、不区分大小写的 `i` 标志，以及它们在真实链接上的用法。

## 一、五种形式

| 选择器 | 匹配 | 例子 |
|---|---|---|
| `[attr]` | **有**这个属性（不管值是什么） | `a[target]` |
| `[attr="v"]` | 值**正好是** v | `a[target="_blank"]` |
| `[attr^="v"]` | 值**以 v 开头**——前缀测试 | `a[href^="https"]` |
| `[attr$="v"]` | 值**以 v 结尾**——后缀测试 | `a[href$=".pdf"]` |
| `[attr*="v"]` | 值**任意位置包含** v——子串测试 | `a[href*="polyu"]` |

```css
a[target]           { }  /* has the attribute */
a[target="_blank"]  { }  /* exact value       */
a[href^="https"]    { }  /* begins with       */
a[href$=".pdf"]     { }  /* ends with         */
a[href*="polyu"]    { }  /* contains          */
a[href$=".pdf" i]   { }  /* ignore case       */
```

## 二、三个符号怎么记

课件给的口诀是：

> **`^=` `$=` `*=` 读作：starts with · ends with · contains。**

三个符号都是**位置测试**（the position tests），前两个形式的 `=`（`[attr="v"]`）则是**全等测试**——`a[target="_blank"]` 只匹配值恰好是 `_blank` 的，写成 `a[target^="_blank"]` 则是"以 `_blank` 开头"，两者范围完全不同。

| 想做的事 | 用哪个 |
|---|---|
| 属性存在即可 | `[attr]` |
| 值必须完全等于 | `[attr="v"]` |
| 以某段**开头** | `[attr^="v"]` |
| 以某段**结尾** | `[attr$="v"]` |
| 任意位置**含有** | `[attr*="v"]` |

## 三、`i` 标志：忽略大小写

在**右方括号之前**加一个 `i`：

```css
a[href$=".pdf" i] { }
```

不加 `i` 时 `HREF="x.PDF"` 的链接**匹配不上** `.pdf` 这个后缀；加了 `i` 就匹配。文件扩展名的大小写在现实世界里并不统一（`a.pdf`、`a.PDF`、`a.Pdf`），这类位置测试天然对大小写敏感，`i` 是必要的补丁。

## 四、实战：三种典型用法

### 1. 每一个 https 链接

```css
a[href^="https"] { }
```

`href` 以 `https` 开头——注意**包括**以 `https` 开头的**相对**地址，这类地址的写法在各浏览器里不统一，所以严格的实现还会再排除 `//` 开头的协议相对地址。

### 2. 每一个 PDF 链接

```css
a[href$=".pdf" i] {
  color: #D9534F;   /* Alert：提示这是一个文件 */
}
a[href$=".pdf" i]::after { content: " (PDF)"; }
```

课件常举的例子就是 `.pdf` 后缀——这是最不需要额外 HTML 钩子就能识别的一类链接。

### 3. 只挑出站链接

```css
a[href*="polyu"] { }
```

值里**包含** `polyu` 的链接——即指向外部站点的那些。站内链接不含这个子串，于是自动被排除在外。

> [!tip] 为什么这类写法比加 class 划算
> 判断"这个链接指向外部"这件事，**在 HTML 里没有现成的属性**。要么给每个外链都加 `class="external"`（要改 N 处，且新加链接的人会忘），要么用 `a[href^="http"]` 让 CSS **自己**问出来。属性选择器省掉的正是 [[简单选择器]] 里说的那种"每个元素都要手动加钩子"的工作。

## 五、写在示例站上

示例站（约定见 [[课程场景与阅读约定]]）的 `main` 里同时有站内导航链接、课表 PDF、以及一个指向 PolyU 主站的外部链接。给外部链接加个提示：

```css
/* 站外链接：提示读者会离开本站 */
a[href^="http"]:not([href*="comp3421"]) { }

/* PDF 下载：标出文件类型 */
a[href$=".pdf" i]::after {
  content: " ↓ PDF";
  color: #4A5568;
  font-size: 0.9em;
}

/* 已访问过、且指向站外的链接 */
a[href^="http"]:visited { color: #9DC0EE; }
```

`:not()` 是伪类，和属性选择器叠在一起用，详见 [[伪类与伪元素]]；`::after` 生成的内容和 `content` 的关系也在那里。

## 六、易错点

- 写 `[attr=v]` 漏了引号——多词值（`"Times New Roman"`）必须引号，单词虽能省略也别省。
- 记混三个符号：`^=` 是**开头**不是结尾，`$=` 是**结尾**不是开头。
- 忘了 `i` 标志，然后在 `.PDF` 链接上排查半天。
- 用 `a[href="…"]`（全等）去做前缀判断——它只匹配完全相同的那个 URL。
- 忘了给外链加 `rel`，本篇管的是样式，选 `rel` 的语义见 [[链接与图像]]。
