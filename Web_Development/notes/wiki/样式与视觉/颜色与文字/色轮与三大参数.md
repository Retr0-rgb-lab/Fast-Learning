# 色轮与三大参数 · The Colour Wheel, Hue / Saturation / Value

> **一句话**：任何颜色都能用**色相（角度）· 饱和度（半径）· 明度（高度）** 三根轴说完 —— 但**这套模型叫 HSV，而 CSS 里没有 `hsv()`**，CSS 写的第三根轴是 `hsl()` 的**明度（lightness）**。

课件原文见 [Tutorial_01_ColorTheory.pptx](<../../../raw/Tutorial_01_ColorTheory.pptx>)。本篇覆盖其中「The Colour Wheel」一节：从「From Spectrum to Wheel」到「Three Wheels, Three Primaries」。

## 一、色轮是把光谱弯成一个圈

可见光谱有两个**头尾相接**的端点，把它**弯起来让两端相接**，就得到色轮。

> [!tip] 色轮是**方便法**，不是物理
> 课件的原话：*「The wheel is a convenience, not physics — but it is the right tool for choosing colours.」*
>
> 波长和频率并不排成一个圈（红和紫在光谱上不是邻居，但色轮上它们挨着）。**色轮不是物理事实，但它是选颜色时对的工具** —— 它的价值在于让「相邻」「相反」这类关系一眼可见，这也正是 [[配色方案]] 全部七种方案的几何来源。

## 二、三个参数是一块三维的实体

课件给了这张图的核心比喻，一句顶一句：

> **Hue is the angle, saturation is the distance from the axis, value is the height.**

| 参数 | 在实体里是什么 |
|---|---|
| **Hue 色相** | 角度 |
| **Saturation 饱和度** | 离轴的距离（半径） |
| **Value 明度** | 高度 |

> [!important] 平面的色轮只是**一刀切下去**
> 课件：*「The flat wheel is the shaded top cap — one slice, taken at **value = 100%**.」* 那个画在纸上的圆盘，是这个立体在 **value = 100%** 处横切出来的**一个切片**。你在颜色选择器里看到的那个 S × V 方块，就是同一件事的另一种切法。
>
> 所以色轮**没有**丢掉明度信息，它只是**固定了明度**。

这套三参数的模型叫 **HSV**。课件在第一页就埋了一句伏笔：*「this trio is the HSV model — and its third channel, value, is not the one CSS writes.」*

## 三、色相 Hue —— 角度

| 要点 | 说明 |
|---|---|
| 范围 | **0° 到 360°**，绕着轮量 |
| 回答的问题 | 「**这是哪个颜色**」 |
| 不回答的 | 「有多亮」「有多艳」 |

| 类别 | 颜色 | 角度 |
|---|---|---|
| **三原色** Primary | Red | **0°** |
| | Green | **120°** |
| | Blue | **240°** |
| **三间色** Secondary | Yellow | **60°** |
| | Cyan | **180°** |
| | Magenta | **300°** |
| **三间色之下的六色** Tertiary | red-orange、yellow-green 等 | 夹在中间的那些 |

每一个间色由**两个原色**混出来。

> [!warning] 同一个轮子，两套名字
> 课件专门提醒：*「Red, yellow, blue is the **artist's** pigment wheel; CSS and your screen use **red, green, blue**.」*
>
> 画画的轮子是 **RBY**（红黄蓝），CSS 和屏幕的轮子是 **RGB**（红绿蓝）。看图时先确认自己在哪套轮子上 —— 这正是 [[色彩成因]] 里减色与加色之分在色轮上的延续。

## 四、饱和度 Saturation —— 离轴多远

| 要点 | 说明 |
|---|---|
| 另一个名字 | **chroma**（彩度） |
| 定义 | **离灰轴的距离** |
| 高饱和 | 鲜艳，坐在轮的**外圈**附近 |
| 低饱和 | 发闷、发淡 —— 更靠近灰 |
| 零饱和 | **achromatic（无彩）**：纯灰阶，**完全没有色相** |

课件一句话：*「Saturation is the dial that takes a colour from shouting to whispering.」*（饱和度是把颜色从「大声说话」调到「低声细语」的那个旋钮。）

## 五、明度 Value —— 有多亮

| 要点 | 说明 |
|---|---|
| 定义 | **亮度**（brightness） |
| 轴的两端 | **黑** → 该色相的**鲜艳形态** |

> [!important] 升高明度**永远不会带来白色**
> 课件：*「Raising value never brings white in.」* 这一点从 [[色彩成因]] 就该有预感 —— **白色不在光谱上**（它是「什么都不缺」时眼睛报告的结果），所以调不出一种「带点颜色、但亮到发白」的颜色。
>
> 课件给的结论：*「Those are the only two ends: **black**, and the **full-strength colour**.」* 一根轴只有这两头。

### 为什么它最重要

> **Value carries the contrast.** —— 两个明度相同的色相，是分不出来的。

这就是「一个页面能读到什么程度，只看它的明度给到多少」的原因。课件给了一个自己就能做的检查法：

> **眯起眼睛，或者把截图去饱和：如果页面还读得出来，明度就干得动它的活。**

（把页面转成灰度再看一遍，是排查配色最省事的办法之一，见 [[对比度与可读性]]。）

## 六、CSS 用的是哪一根轴

这是本篇最要紧、也最容易记错的一条。

| | 第三个通道 | 状态 |
|---|---|---|
| **HSV**（选色器） | **Value** | 建模用，**CSS 里不存在** |
| **HSL**（样式表） | **Lightness** | ✅ CSS 写这个 |
| **hwb()** | 白 / 黑 两个独立旋钮 | ✅ CSS 也写这个 |

课件的原话：

> **In a stylesheet you write `hsl()` or `hwb()`. There is no `hsv()` in CSS — that S × V square is the picker's, not the language's.**

翻译成人话：**那个饱和度 × 明度的方块，是颜色选择器的界面，不是 CSS 语言的界面。**

| 写法 | 存在吗 | 第三个通道是什么 |
|---|---|---|
| `hsv()` | ❌ **CSS 里没有这个函数** | — |
| `hsl(h, s%, l%)` | ✅ | **lightness** |
| `hwb(h, w%, b%)` | ✅ | 白度、黑度**分开两个旋钮** |

> [!important] 这解释了为什么 `hsl()` 是**设计用的记法**
> 在 `hsl()` 里改一个颜色深浅，**只需要动 lightness 那一个数字**；而在 RGB 里做同一件事，你得重算一遍通道。课件的 Rules Worth Remembering 一页把 `hsl()` 定为 *「the one for designing」*，理由正在这里。
>
> 四种写法、什么时候用哪一种，见 [[颜色表示法]]；`hwb()` 之外还有 alpha 一层，见 [[透明度与叠加层]]。
