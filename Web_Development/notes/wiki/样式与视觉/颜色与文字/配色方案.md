# 配色方案 · Colour Schemes

> **一句话**：七种方案是**同一个色轮上的七种取点几何**（一个点 / 两个对立点 / 三个邻居 / 三个均分 / 一个加两侧 / 一个矩形 / 对半切），**没有一条是规则** —— 它们只是起点，比例才是关键。

课件原文见 [Tutorial_01_ColorTheory.pptx](<../../../raw/Tutorial_01_ColorTheory.pptx>)。本篇覆盖其中「Building a Palette」一节：从「Seven Ways to Combine Hues」到「The Seven Schemes at a Glance」，以及「Designing with a Palette」里的 60 / 30 / 10 规则与扣分项。

> [!important] 先分清两套色值
> 本篇所有十六进制值都来自课件演示用的**方案色卡**（如 `#2665D1`、`#F0A422`），它们是**选点示例**。
> 而全库统一的**课程调色板**（Navy `#0E3F8C`、Primary `#1E4FA8`、Mid `#3D7BD9`、Pale `#9DC0EE`、Sky `#B9CDEE`、Gold `#FFC107`、Alert `#D9534F`）出自 Week 3 的 CSS I，见 [[课程场景与阅读约定]]。**两组不是同一套**，不要混着记。

## 一、先看几何：七种取点法

在读任何色卡之前，先把七种方案当成**同一个圆上的七种取点方式**：

| # | 方案 | 轮子上的形状 | 在轮子上怎么取 | 性格 | 什么时候用 |
|---|---|---|---|---|---|
| 1 | **单色** Monochromatic | 一个点，变体 | 同一个色相，改明度与饱和度 | 沉静、一致 | 想要克制、编辑感或企业感 |
| 2 | **互补色** Complementary | 两个，相隔 180° | 一个点加它的**正对面** | 对比最大、最有冲击力 | 必须有一样东西**跳出来** |
| 3 | **类似色** Analogous | 邻居 | 相邻的三个色相（一般 30° 内） | 和谐、自然 | 要平静的统一感，但不想单色那么平 |
| 4 | **三分色** Triadic | 三个，相隔 120° | 三个**均分**点 | 大胆，但比互补更平衡 | 要鲜明、有趣，而且你**有明确的层级** |
| 5 | **分裂互补** Split-complementary | 一个 + 两侧 | 一个主色 + 它互补色的**两个邻居** | 有劲，但更柔和 | 互补太冲、但你还想有冲击力 |
| 6 | **四角配色** Tetradic | 一个矩形 | **两对互补色**，四个色相 | 丰富，**难做** | 插画，或能撑起四色的活泼品牌 |
| 7 | **冷暖** Warm / Cool | 对半切 | 轮子的一半 | 深度与氛围 | 要**层次和情绪**，而不是要对比 |

课件把这七种统称为 *「Seven ways to combine hues」*，并给了一句总结：**Every scheme is a geometric rule for picking points on the same wheel.** —— 全部七种都只是**取点规则**。

> [!tip] 下面每种方案都按同一结构写
> **色卡值 → 性格 → 什么时候会出错 → 什么时候用**。第三项是这一篇最值钱的部分：七个方案能不能用对，看的不是"喜不喜欢"，而是"会不会失控"。

## 二、单色 Monochromatic

**色相只有一个，永远不变；明度和饱和度在变。**

```
#05255C  #0F3880  #2253A8  #477AD1  #8DB2F2
```

一个色相在**最暗的 shade 和最浅的 tint 之间**取五个点。

| 方面 | 课件的说法 |
|---|---|
| 几何 | 一个点，变体 |
| 性格 | **先天不可能打架**（nothing can clash）—— 所以是最安全的起点 |
| **什么时候出错** | **对比度是难点**：只有一个色相，对比只能**从明度来**，所以必须**去量**而不是想当然 |
| 什么时候用 | 克制、编辑感、企业形象 |

> [!warning] 单色方案不会冲突，**但这不等于它能读**
> 「不打架」和「看得清」是两件事。一个色相拉出五个深浅不同的蓝，**彼此**都好读，不代表**文字压在自己的背景上**也够读。每对颜色都要单独算，见 [[对比度与可读性]]。

## 三、互补色 Complementary

**两个色相，相隔 180°，正对面。**

```
#2665D1      #F0A422
（蓝）        （橙黄）
```

| 方面 | 课件的说法 |
|---|---|
| 几何 | 两个点，相隔 180° |
| 性格 | **对比最大** —— 互相把对方显得更亮、更突出 |
| **什么时候出错** | **两个都用满强度会互相抢、让眼睛疲劳** —— 课件的处方是 *「keep one for accents」*，**留一个当点缀** |
| 什么时候用 | 需要某个行动号召（call to action）**从页面上跳出来** |

> [!important] 互补色方案的成败全在「谁做主角」
> 它的能量全部来自「对撞」，而对撞的两边**一样强就会互相抵消**。正确做法是**一个主导 + 一个点缀**，不是两个都铺满。

## 四、类似色 Analogous

**色轮上挨着的几个色相。**

```
#2FC0D6  #2F96D6  #2F6CD6  #2F43D6  #452FD6
```

| 方面 | 课件的说法 |
|---|---|
| 几何 | 邻居；通常是**彼此 30° 以内**的三个色相 |
| 性格 | 和谐、自然，**读起来像一家人** —— 风光摄影里常见 |
| **什么时候出错** | **会变平**（go flat）：色相对比太少。处方是**选一个当主导**，其余当点缀 |
| 什么时候用 | 要平静与统一感，但**不想单色方案那么平** |

> [!tip] 怎么在「太平」和「太冲」之间找路
> 往互补色的方向挪半步就行 —— 那就是下一节的**分裂互补**。

## 五、三分色 Triadic

**三个色相，每两个之间均匀相隔 120°。**

```
#2769DB      #DB2769      #69DB27
（蓝）        （品红）      （绿）
```

| 方面 | 课件的说法 |
|---|---|
| 几何 | 三个点，每对相隔 120° —— **没有哪个色相在对称性上胜出** |
| 性格 | 大胆，但**比互补色平衡**，也**更好用**（更通用） |
| **什么时候出错** | **三个平等使用就会互相打起来** —— 课件的原话是「the eye has nowhere to land」（眼睛**没有落脚的点**）。处方：**一个主导 + 两个点缀** |
| 什么时候用 | 要鲜明、有玩心，而且**你已经有明确的层级** |

## 六、分裂互补 Split-Complementary

**一个主色，加上它互补色的两个邻居。**

```
#2C6CDB      #DB432C      #C4DB2C
（主色）      （互补色的两侧）  （互补色的两侧）
```

| 方面 | 课件的说法 |
|---|---|
| 几何 | **不是正对面** —— 取一个主色和**它互补色的那两个邻居** |
| 性格 | **有劲但更柔和** —— 拿到互补色**大部分的对比**，但**少了那份视觉上的震颤** |
| 什么时候出错 | 比互补色**更容易平衡**（三个色相留出了「主导 + 点缀」的空间），是**最不容易失手的强对比方案** |
| 什么时候用 | 互补色**太有攻击性**、但你仍然想要那份力道 |

> [!tip] 这是最实用的一档
> 需要对比、又怕打架时的默认值。它保留了互补的锋利，又用两个邻居替换掉了那个正面的对撞。

## 七、四角配色 Tetradic

**两对互补色 —— 轮子上的一个矩形，四个色相。**

```
#306FDB      #9D30DB
（蓝）        （紫）
#DB9D30      #6FDB30
（橙黄）      （绿）
```

| 方面 | 课件的说法 |
|---|---|
| 几何 | 轮子上的**矩形**，每一对相隔 180° |
| 性格 | 丰富，但**真的难** —— 课件说得很直接：四个色相，平衡是**确实困难**的 |
| **什么时候出错** | **层级不是可选项**（hierarchy is not optional）—— **没有**一个**明确的主导色**，整个配色**读作噪音** |
| 什么时候用 | 插画，或一个**撑得起四个颜色**的活泼品牌 |

> [!important] 四个色相不是「选四个好看的颜色」
> 每多一个色相，平衡的难度就上一个台阶。课件给四角配色下的判语是 *「rich, and easy to get wrong」*（丰富，而且**容易搞砸**）。
> 所以真正的要求不是审美，是**结构**：四个色相 + **一个压倒性的主导色** + 剩下的当配角。少了主导色，四个色相就是**四个中心**，读者一个也记不住。

## 八、冷暖 Warm / Cool

**把轮子对半切。**

```
暖（红 → 黄）：#E61C2C  #E65F1C  #E6A21C  #E6CB1C
冷（绿 → 紫）：#2CCDDB  #2C84DB  #2C2CDB  #752CDB
```

| 方面 | 课件的说法 |
|---|---|
| 几何 | 轮子的**一半**：暖从红走到黄，冷从绿走到紫 |
| 性格 | **暖色前进，冷色后退** —— 暖的元素显得更近、更活跃；冷的沉到后面 |
| 结构上的作用 | **冷背景 + 暖点缀，可以在不增加色相数量的情况下建立层级**（temperature as structure） |
| 什么时候用 | 要**深度与氛围**，而不是要对比 |

> [!tip] 冷暖是一种「不增加颜色数的层级」
> 别的方案要靠**多几个色相**来分主次，冷暖方案只要**换温度**就行 —— 背景是冷的，要突出的那一小块是暖的，主次立刻分明。这条思路在**去饱和之后依然成立**，见 [[对比度与可读性]]。

## 九、60 / 30 / 10

配色方案告诉你**取哪些点**，这个规则告诉你**各占多少面积**。

| 比例 | 角色 | 放在哪 |
|---|---|---|
| **60%** | **主导色** | 背景和大面积表面。**通常是最克制的那一个颜色** |
| **30%** | **次要色** | 支撑性的面板、卡片、标题 —— 一个**相关的色相** |
| **10%** | **点缀色** | 按钮、链接、**那个你想让人注意的唯一一处** |

> [!warning] 这是一条经验法则，不是公式
> 课件的原话：*「Not a law — a rule of thumb for proportions, not a formula. **What matters is that the proportions are deliberate.**」*
>
> 关键不在 60/30/10 这三个数字，而在**比例是刻意定的**。45/45/10 也可以，只要你知道自己在定什么。

把上面两种思路合起来写，就是课件那句总结：**先定比例，再定颜色。**

## 十、四个扣分项

| 扣分项 | 问题 | 怎么改 |
|---|---|---|
| **颜色太多** | 五个**权重相同**的色相读作噪音 —— 课件：*most good pages use two or three* | 砍到两三个，其余去掉 |
| **纯黑配纯白** | `#000` on `#fff` 是 **21:1** —— 课件说它 *harsh*（刺眼） | 用**很深的灰**配**米白**，比纯黑纯白好读 |
| **颜色当唯一信号** | 只有一道红边框、别的什么都没有 —— 这在 WCAG 1.4.1 的**最低一档**就不合格 | 加图标、加文字，见 [[对比度与可读性]] |
| **灰色不一致** | 六个**略有差别**的灰看起来就像做错了 | **挑两个**，反复用 |

## 十一、收尾

课件在七种方案的总表下面留了本节最该带走的一句：

> **None of these is a rule — they are starting points you then adjust.**

没有一条是规则。它们都是**你接着去调**的起点。定下来的应该是**比例**，剩下的是你的判断。
