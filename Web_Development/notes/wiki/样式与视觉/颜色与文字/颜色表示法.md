# 颜色表示法 · Colour — Four Ways to Write It

> **一句话**：同一个颜色有四种写法（named / hex / rgb() / hsl()），它们是**同一个数的四种记法**——设计时用 `hsl()`，从设计工具抄来的用 hex，同一个色值绝不要写两遍。

课件原文见 [Lecture_03_CSS.pptx](<../../../raw/Lecture_03_CSS.pptx>)。本篇覆盖 Week 3 的 "Colour" 一节：四种写法的总表、等价关系、四条要记住的规则、148 个命名颜色、课程调色板，以及 `color` 与 `background-color` 的分工。

## 一、四个部件，四种写法

`color` 这个属性后面可以跟四种东西，它们指的是同一个颜色：

| 写法 | 全称 | 例 | 说明 |
|---|---|---|---|
| Named | 命名颜色 | `red`、`blue`、`tomato` | 148 个词，但数量有限 |
| Hex | 十六进制 | `#1E4FA8` | **每个通道两个十六进制位** |
| RGB / RGBA | 红绿蓝 | `rgb(30, 79, 168)` | 带 alpha 就是 rgba()，负责透明 |
| HSL | 色相·饱和度·明度 | `hsl(218, 70%, 39%)` | 三个通道对应调色的三个动作 |

课件给出的等价式，四个写法说的是同一个蓝：

```
blue  =  #0000FF  =  rgb(0,0,255)  =  hsl(240,100%,50%)
```

Hex 和 `rgb()` 确实是**同一个数**：hex 每通道是 `00`–`FF`（0–255 的十六进制），`rgb()` 每通道是同一批数值的十进制写法。`#1E4FA8` → `1E` = 30、`4F` = 79、`A8` = 168，所以 `rgb(30, 79, 168)`。`hsl()` 则是另一套坐标，讲的是"这个颜色是什么样子"，见 [[色轮与三大参数]]。

```html
<p style="color: red;">
<p style="color: #1E4FA8;">
<p style="color: rgb(30, 79, 168);">
<p style="color: rgba(30, 79, 168, 0.5);">
<p style="color: hsl(218, 70%, 39%);">
<!-- all four spell the same colour -->
```

## 二、四条要记住的规则

| 规则 | 内容 |
|---|---|
| **设计时用 `hsl()`** | 改明度只是一个数字的改动，tint（提亮）或 shade（压暗）不用重算；从设计工具里抄色值时用 hex |
| **命名颜色留给原型** | 读起来清楚，但这个列表又短又随意，好几个名字共用一个值，而且一半在白底上过不了对比度 |
| **同一个颜色不要写两遍** | 同一个 hex 粘进二十条规则里，换品牌那天它们就开始漂移；先定义成 **CSS 变量**，再用变量 |
| **alpha 不是一种颜色** | `rgba()` 让背景透出来，这是 overlay 和 scrim 能成立的原因，它和"选哪个色相"是两件事 |

第三条在课件里直接给了写法：

```css
--brand: #1E4FA8;
color: var(--brand);
```

变量本身的机制见 [[CSS变量]]。第四条展开在 [[透明度与叠加层]]。

> [!warning] 课件里的另一组十六进制值
> Week 4 讲"规则互相竞争"时随手配过 `#185fa5`、`#2e7d32`、`#d9534f` 等对比色。那是演示用的颜色，**不是课程调色板的成员**，见 [[层叠与优先级]]。

## 三、148 个名字，只有 139 种颜色

命名颜色就是"给一个固定值起了个名字"，而**这些名字不构成任何体系**：

- 课件点名问的例子：`peru` 是什么颜色？`thistle` 呢？
- **`darkgray` 比 `gray` 浅**——按名字的直觉应该是反的。
- **`brown` 是一种深红色**。
- 148 个名字里只有 **139 种不同的颜色**：`aqua` 就是 `cyan`，`fuchsia` 就是 `magenta`，`gray` 本身还有两种拼法。

```css
/* 可以，但只能用来快速试 */
h3 { color: tomato; }
h4 { color: papayawhip; }
```

结论不是"别用命名颜色"，而是**别拿命名颜色当设计系统**。真正的色值要落到 hex 或 `hsl()` 上。

## 四、课程调色板

Week 3 的课件自己就用了一套配色，并且明确写了"**一套调色板，写成 hex，重复使用**"。本知识库把它当作全库的颜色锚点（约定见 [[课程场景与阅读约定]]）：

| 名称 | 色值 | 用途 |
|---|---|---|
| Navy | `#0E3F8C` | 深色底、页脚 |
| Primary | `#1E4FA8` | **主色**——正文标题、链接、强调 |
| Mid | `#3D7BD9` | 次级强调、hover |
| Pale | `#9DC0EE` | 浅底、区块背景 |
| Sky | `#B9CDEE` | 更浅的分隔 |
| Gold | `#FFC107` | 提示、高亮 |
| Alert | `#D9534F` | 错误、警告 |

课件对这个调色板下的判断是：**一致的配色是做干净设计里 90% 的事**。所以上面每个色值都该被写进 `:root` 里的变量，而不是散在规则中。

主色 Primary 的四种写法（同一色）：

```css
h1 { color: #1E4FA8; }
h1 { color: rgb(30, 79, 168); }
h1 { color: hsl(218, 70%, 39%); }
```

## 五、`color` 与 `background-color`

| 属性 | 管什么 |
|---|---|
| `color` | 文字本身的颜色——**前景**（foreground） |
| `background-color` | 内容背后的颜色——**背景** |
| 两者都在盒子上 | 文字坐在背景之上 |
| 对比度（contrast） | 两者要差得够开，字才读得下去 |

```html
<h1 style="color: white; background-color: #1E4FA8;">
```

课件没有给对比度的公式，只给了判断："足够不同，才读得清楚"。可量化的部分在 [[对比度与可读性]]，颜色的来路在 [[色彩成因]]。

## 六、易错点

- `rgb()` 里**不要写百分号**，`rgb(30, 79, 168)` 是十进制整数；`%` 是 HSL 通道的写法。
- 选 hsl() 时三个通道的含义是**色相 / 饱和度 / 明度**，不是 RGB，换算不是简单替换。
- 同一个 hex 不要在二十条规则里各写一遍——这一条规则在 Week 3 就说了，解法要到 [[CSS变量]] 才拿得到。
- 命名颜色里有一半在白底上过不了对比度，**能用不代表能用**。
