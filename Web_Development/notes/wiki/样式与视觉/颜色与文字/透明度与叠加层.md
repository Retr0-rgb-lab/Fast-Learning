# 透明度与叠加层 · Transparency & Overlays

> **一句话**：`rgba()` 的第四个通道只控制**这一个颜色**的透明程度，而 `opacity` 会把**整个元素连同文字**一起变淡——scrim 和 caption 这两种叠加层，全部建立在"半透明"这一件事上。

课件原文见 [Lecture_03_CSS.pptx](<../../../raw/Lecture_03_CSS.pptx>)。本篇覆盖 Week 3 "Colour" 一节最后的 Transparency & Overlays：`rgba()` 的 alpha、`opacity` 的作用范围，以及 overlay 的三种用途——tint、scrim、caption。

## 一、alpha：一个从 0 到 1 的通道

`rgba()` 在 `rgb()` 后面多了第四个值，就是 **alpha 通道（the a channel）**，它设定透明度：

| alpha | 含义 |
|---|---|
| `0` | clear，完全透明 |
| `1` | solid，完全不透明 |

```css
p { color: rgba(30, 79, 168, 0.5); }
```

> [!important] alpha 不是一种颜色
> 课件把这句话单独列为一条规则：alpha 让**背景透出来**，overlay 和 scrim 就是靠它成立的。它和"挑哪个色相"是分开的两件事——第四个通道不会改变红绿蓝三个通道的值，只是决定背景能透过来多少。

## 二、`opacity` 与 `rgba()` 的作用范围不同

| 写法 | 淡掉什么 |
|---|---|
| `rgba()` 的 alpha | **只有这一个颜色**——背景色变透明，里面的文字照旧 |
| `opacity` | **整个元素**，**文字也算在内**，一起变淡 |

这是本篇最容易记混的一条：把 `opacity` 调到 `0.5` 的一个 `<div>`，它上面的文字也变成半透明、并且透出它背后的东西；而给背景色加 alpha，文字的浓度不变。想让"底淡、字不淡"，要的是 alpha 不是 `opacity`。

## 三、Overlay：一层盖在内容上的半透明

课件给 overlay 的定义是**盖在内容之上的一层半透明层**，并点名了三种形态：tint（染色）、scrim、caption。下面两种是课件展开讲的。

### Scrim（遮罩）

> 一层**铺满整个屏幕的深色层**，位置在页面和对话框/菜单**之间**。

它同时干三件事：

| 它做的事 | 为什么需要 |
|---|---|
| Dim everything behind（压暗背后的一切） | 让下面的内容退到背景里 |
| Pulls the eye to the dialog（把视线拉向对话框） | 焦点不再分散 |
| Signals the page is locked（示意页面被锁住） | 直到你关掉它为止 |

这就是"遮罩"这个名字的来历：它把页面**锁**在对话框后面。实现上就是一层全屏的深色半透明层。

### Caption（图片说明条）

> 文字压在照片上，在一张**杂乱或明亮**的照片里会直接消失，所以说明文字要坐在一条**半透明条带**上——**保证这些字读得出来的是那条带子，不是文字自己**。

```html
<div style="background: rgba(0, 0, 0, 0.55); color: #fff; padding: 8px;">Caption</div>
```

拆开看这一行：背景 `rgba(0, 0, 0, 0.55)` 是一条 55% 不透明的黑色带子，压在图片上把杂乱的照片压暗；`color: #fff` 给文字一个亮底上的亮色；`padding: 8px` 让文字不贴在带子边缘。

## 四、为什么必须有那条带子

scrim 和 caption 存在的**唯一理由是对比度**：

- **scrim**：对话框里的文字要读得清，所以背后的一切必须先被压暗。压暗靠的就是一层不透明的深色，而不是"希望背景不复杂"。
- **caption**：照片的局部亮度不可控，靠文字自己找到对比是不现实的。**能控制的部分只有那条半透明带子**——它才是对比度的保证者。

> [!warning] 这是从"好看"到"能读"的转折
> 叠加层不是装饰层，是**可读性工程**。把背景调得刚好压得住文字，页面就从"看着不错"变成"读得下去"。具体怎么量化，见 [[对比度与可读性]]。

## 五、写在示例站上

示例站（约定见 [[课程场景与阅读约定]]）的 `main` 里有一张配图。图上的说明文字不要直接压在图上：

```html
<figure>
  <img src="campus.jpg" alt="PolyU campus">
  <figcaption style="background: rgba(0, 0, 0, 0.55); color: #fff; padding: 8px;">
    Week 3 作业：用四种写法给同一个颜色
  </figcaption>
</figure>
```

报名表单的提示条同理，Alert 色加 alpha 让它盖得住底图：

```css
.notice {
  background: rgba(217, 83, 79, 0.85);
  color: #fff;
  padding: 8px;
}
```

`#D9534F` 是课程调色板里的 Alert，色值出处见 [[颜色表示法]]。

## 六、易错点

- 把 `opacity` 当 alpha 用：文字会跟着一起变淡，底色反差消失。
- 第四个通道写成百分数（`rgba(0,0,0,55%)`）——本课用的是 `0`–`1` 的小数。
- scrim 只做"变暗"而没有"挡住"：它要传达的是**页面被锁住了**，不只是变暗。
