# 边框与圆角 · Border & Rounded Corners

> **一句话**：`border` 必须同时给齐**样式、宽度、颜色**三样才画得出线，而 `border-radius` 的几何本质是**在每个直角里内切一个圆，用弧线把那个角切掉**。

课件原文见 [Lecture_04_CSS.pptx](<../../../raw/Lecture_04_CSS.pptx>)。本篇覆盖其中「Border — Style」「Border — Width & Colour」「Border — Sides & the Number Order」「What a Rounded Corner Is」「Rounded Corners」「Elliptical Corners」「Outline」各页。

## 一、border 的三要素

一条边要画出来，需要三样东西**同时**在场：

```css
border: 3px solid #185fa5;
/*        ↑     ↑      ↑
        宽度   样式   颜色  —— 缺一不可 */
```

> [!warning] 唯一不能省的是 `border-style`
>
> 课件明确说：只写宽度和颜色而漏掉 `border-style`，**什么都不会被画出来**。`border-style` 是那句「you cannot leave out」。

### border-style 的取值

| 值 | 长相 | 典型用途 |
|---|---|---|
| `solid` | 一条均匀的实线 | **卡片、面板、输入框的首选** |
| `dashed` | 断续长线 | 拖放区 |
| `dotted` | 一串点 | 占位符 |
| `double` | 两条线夹一道缝 | 需要**大约 3px 以上**才看得出来 |
| `groove` / `ridge` | 看起来有凹槽 / 有凸起的边 | 浏览器替你画好的立体边 |
| `inset` / `outset` | 看起来陷进去 / 凸出来 | 同上 |
| `none` / `hidden` | 没有边 | 而且**不为一根边预留位置** |

> [!tip] `none` 与 `hidden` 的区别只在边「塌陷」的方式不同
>
> 课件把它们并列成「No border — and no room reserved for one」。写布局时它们的实际差别极小，但知道 `hidden` 是**彻底**不预留、`none` 在某些表格上下文里会保留一点空间就够了。

### 宽度与颜色

| 属性 | 写法 |
|---|---|
| `border-width` | `px` / `em` / `rem` 这类长度，或者关键字 `thin`、`medium`、`thick` |
| `border-color` | 任何你在 CSS 别处能写的颜色（见 [[颜色表示法]]） |

**关键字很粗**：`thin` / `medium` / `thick` 是**浏览器自己定的**，不可预测；长度值才可控。课件的建议是：要确定的效果就写长度。

```css
p.one   { border-style: solid; border-color: red; }
p.two   { border-style: solid; border-color: green; }
p.three { border-style: dotted; border-color: blue; }
p.w1    { border-style: solid; border-width: 5px; }
p.w2    { border-style: solid; border-width: medium; }
p.w3    { border-style: dotted; border-width: 2px; }
p.w4    { border-style: dotted; border-width: thick; }
```

### 数字的顺序：顺时针

| 数字个数 | 对应哪些边 | 例子 |
|---|---|---|
| 1 | 四条边 | `border-width: 4px;` |
| 2 | 先上下，再左右 | `border-width: 4px 12px;` |
| 3 | 上 · 左右 · 下 | `border-width: 4px 12px 20px;` |
| 4 | 上 · 右 · 下 · 左 | `border-width: 4px 12px 20px 8px;` |
| 只写一条 | 就是那一条 | `border-left-width: 4px;` |

**永远从顶部顺时针。** 同一个 1–4 顺序也管 `padding` 和 `margin` —— 学一次，用三处。

## 二、`border-radius` 的几何本质

这是整篇最值得慢下来想一遍的部分。课件用了「one corner, three steps」来拆解：**box → circle → arc**。

### 一个角是直角，圆角就是把它切掉

1. **一个角是直角** —— 两条边以 90 度相交。把它变圆，意思是**把这个方角切掉**。
2. **半径是圆的半径** —— `border-radius: r` 在角里画一个半径为 `r` 的圆。
3. **圆心距每条边各 `r`** —— 所以圆与两条边**相切**，弧线与边衔接处**没有接缝**。
4. **那个尖角在圆外面** —— 角的顶点到圆心的距离**大于 `r`**，所以它干脆消失了。

```
        ┌───────────────┐        ┌───────────────┐
        │               │        │  ╭───╮        │  ← 弧线就是新的角
        │               │   →    │  │   │        │
        │           r   │        │      · centre │  ← 圆心距每条边各 r
        │               │        │               │     所以与两条边相切、无接缝
        └───────────────┘        ╰───────────────╯
          被切掉的方角             剩下的就是圆弧本身
          r 宽 × r 高
```

课件那句收尾很精确：「**The centre sits r from each edge — that is why the arc meets them with no visible seam.**」以及「**The corner it cuts away is a square, r wide and r tall**」。

```css
.card { border-radius: 24px; }   /* 角变成一段半径 24px 的弧 */
```

### 四个常见取值

| 写法 | 效果 | 说明 |
|---|---|---|
| `12px` | **一个半径管所有角** | 最常用的写法 |
| `8px 24px 8px 24px` | 四个半径 | 同样是顺时针，**从左上角开始** |
| `50%` | 按**每条边**的百分比 | 正方形上 `50%` = 正圆 |
| `999px` | 会被**钳制到最短边的一半** | 扁盒子因此变成**胶囊（pill）** |

> [!tip] `999px` 为什么会自动变胶囊
>
> 圆角在几何上不能超过边长的一半，否则圆就切穿了。浏览器于是把过大的半径**钳制（clamp）**到最短边的一半 —— 写一个夸张的大数，就等于「给我能给的最多圆度」。课件的演示里每个盒子都是 144 × 144 CSS px，`border-radius: 0 / 12px / 24px / 999px` 一路排开，`999px` 那一格就是一个圆。

背景和内容会被**裁切**成与圆角一致 —— 所以一个圆角盒子的背景色会跟着变成圆的，不需要额外处理。

## 三、椭圆角

圆只是**特例**。一般情形是**内切于角的椭圆**，它同样只需要与两条边相切。

| 概念 | 含义 |
|---|---|
| 两个半径 | 水平半径 `rx` 与垂直半径 `ry`。**两者相等就退化成圆** |
| 斜杠 `/` | 分隔水平与垂直两组半径。斜杠前是横的，斜杠后是竖的 |
| 百分比 | **每个百分比各自量自己那条边** —— 横向取宽度的 50%，纵向取高度的 30% |

```css
.card { border-radius: 60px / 20px; }   /* 横 60px、竖 20px，一组管四个角 */
```

课件的演示：两个盒子都是 288 × 96 px，上面那个用单个半径转角，下面那个 `border-radius: 120px / 16px` —— **横向伸到 120px，纵向只有 16px**。

```css
.card { border-radius: 50% / 30%; }   /* 横跨宽度的 50%，纵深高度的 30% */
```

> [!tip] 亲手拖一拖
> 课件给了一个交互工具 `9elements.github.io/fancy-border-radius`（可拖动的控制柄），拖动时 `rx` 和 `ry` 会分家 —— 看一眼比读十遍更快。

## 四、别把 outline 记成 border

课件专门用一页区分 `outline`（轮廓线）和 `border`，因为两者的**代价完全不同**：

| | `border` | `outline` |
|---|---|---|
| 属于盒子吗 | **是** | **不是**，画在 border 外面 |
| 会不会推开邻居 | **会** | 不会，可以压住邻居 |
| 影响元素的总宽高吗 | 会 | **完全不影响** |
| 分四条边写吗 | 分（`border-top` 等） | **不分**，整圈是一个值 |
| 属性顺序 | style / colour / width | style / colour / width / offset / 简写 |

```css
outline: #4CAF50 solid 10px;
outline-offset: 8px;   /* 在 border 和 outline 之间加透明空间 */
```

`outline-offset` 填的是一段**透明**空间；给负值就把轮廓线拉到 border 上面去。

> [!important] 为什么这条区别值得记
> 描一个**焦点环（focus ring）**时，你并不想让元素变大、也不想推开旁边的东西 —— `outline` 正是干这个的。它和同样「画在外面」的 [[阴影]]（`box-shadow` 的 `inset` 与外阴影）放在一起看，就知道描边类效果各有各的账要算。
