# 盒模型五层 · The Box Model, Inside Out

> **一句话**：浏览器把页面上每一个元素都渲染成一个盒子，这个盒子从里到外是 content（内容）、padding（内边距）、border（边框）、margin（外边距）四层，背景（background）铺在底下并且**永远不画 margin**。

课件原文见 [Lecture_04_CSS.pptx](<../../../raw/Lecture_04_CSS.pptx>)。本篇覆盖其中「The Box Model」一节：从「Every Element on a Page」到「The Box in Code」以及末尾的 Box Model Cheatsheet。

## 一、每一个元素都是一个盒子

> **一句话先记住**：DOM 里的每一个元素、每一段文字、每一个 `<img>`，在渲染时都占一块矩形区域 —— 那块区域就是一个盒子。盒子不是你写出来的，是浏览器的默认行为。

### 用一条规则把整页变成自己的盒子图

在示例站（本库预设的一个假想课程主页：顶部 `header` + 导航 `nav` + `main`（课程表格 + 报名表单 + 配图）+ `footer`，见 [[课程场景与阅读约定]]）上，下面这条规则不给任何元素点名，却让整页的盒子全部现形：

```css
/* style.css */
* { border: 1px solid black; margin: 5px; }
```

它对上的文档是一个普通的多层结构：

```html
<!-- index.html — a plain, multi-level document -->
<body>
  <header>…</header>  <nav>…</nav>
  <main>
    <section>…</section>  <aside>…</aside>
  </main>
  <footer>…</footer>
</body>
```

| 声明 | 作用 | 为什么需要它 |
|---|---|---|
| `*`（universal selector，通配符） | 匹配每一个元素 | 不用一个一个元素地写名字 |
| `border: 1px solid black` | 一条看得见的边 | 盒子的边界本来是隐形的，边把它显出来 |
| `margin: 5px` | 边外面留出空隙 | 让相邻的盒子互不接触 |

结果：整页变成一张**自画像** —— 每个标签占了多大地方、谁套着谁、谁挨着谁，一眼可见。

> [!tip] 关键领悟
> 盒子**本来就在那里**。`border` 没有创造任何新东西，它只是让早就存在的东西变得可见。这就是为什么调试布局问题的第一步往往是「先给所有元素加一条边」。

## 二、五层，从里往外读

课件给的口诀是 **inside out**（从里往外）：

| 层 | 英文 | 在盒子的哪一侧 | 会被绘制吗 | 谁画它 |
|---|---|---|---|---|
| content | 内容 | 最里 | ✅ | 文字、图片本身 |
| padding | 内边距 | 边的**内侧** | ✅ **背景会画它** | 背景色 / 背景图 |
| border | 边框 | 边本身 | ✅ | `border` 声明 |
| margin | 外边距 | 边的**外侧** | ❌ **永不绘制** | 没有人画，它只是留白 |
| background | 背景 | content 与 padding 的**底下** | ✅ | `background-*` 属性 |

顺序记牢：**content → padding → border → margin**，背景垫在最下面。

### 最重要的一条规则

> [!important] 背景画 content 和 padding，**从不画 margin**
>
> 这解释了所有「我明明设了背景色，为什么还有一圈白的」的问题。**如果你能看见背景，那你看到的一定是 padding。** margin 永远是透明的、通透的。

## 三、鸡蛋的类比

课件给了一个鸡蛋模型（"Think of It Like an Egg"）：

| 盒子层 | 鸡蛋 | 说明 |
|---|---|---|
| content | **蛋黄（yolk）** | 真正有用的东西，页面上的文字 / 图片 |
| padding | **蛋白（albumen）** | 包着内容的一层，盒子内部的缓冲 |
| border | **蛋壳（shell）** | 那条硬边，一眼看得见的边界 |
| margin | **与下一个蛋之间的空隙** | 蛋壳之外**什么都不存在**，只有留给邻居的空气 |

蛋壳外不是另一种颜色，而是**空**。这一层是 margin，也是整个盒模型里唯一「不存在实体」的一层。

## 四、盒子的算术：一个 div 讲清全部

一条规则同时声明尺寸、边、缓冲、外边距：

```css
div {
  width: 300px;
  border: 25px solid green;
  padding: 25px;
  margin: 25px;
}
```

课件逐条解释：

| 声明 | 含义 |
|---|---|
| `width: 300px` | **300px 是内容区**的宽度 —— 不多不少，除非 `box-sizing` 另有说法 |
| `border: 25px solid green` | 25px 的实线绿色边，画在 padding 外一圈 |
| `padding: 25px` | 四边各 25px 的缓冲，在边**以内** |
| `margin: 25px` | 边**以外** 25px 的空地 —— 永不绘制 |

于是这四个数字在算术上是这样合起来的：

```
300px 内容 + 25px 边（左右各一） + 25px 缓冲（左右各一） = 400px 的盒子
                                                                       ↑ 盒子本身
                              外面另有 25px 的 margin                    ← 这一圈不画
```

写成笔记里最该记住的一句：**300px 的内容、25px 的边、25px 的缓冲 = 一个 400px 的盒子，外面还有 25px 的 margin。**

> [!warning] 这里的 400px 已经是「宽」了，height 方向同理
>
> 课件只给了横向的算式，但**纵向是同一套公式**：`高 + 上下 padding + 上下 border`。两个方向都算完，才是一个盒子在页面上真正占的地方。这笔算术为什么烦人、以及怎么用 `box-sizing: border-box` 一次性消掉它，见 [[尺寸与盒模型计算]]。

## 五、盒模型速查表

课件的 Box Model Cheatsheet 一页速查：

| 属性 | 干什么 | 例子 |
|---|---|---|
| `padding` | 边**以内**的空间 | `padding: 16px 24px;` |
| `border` | 边本身 —— 样式 + 宽度 + 颜色 | `border: 2px solid #185fa5;` |
| `border-radius` | 把角变圆 | `border-radius: 12px;` |
| `margin` | 边**以外**的空间 | `margin: 0 auto;` |
| `background` | content 与 padding 底下的颜色与图 | `background: #eef3fb;` |
| `box-sizing` | 声明的尺寸**算不算**内边距和边 | `box-sizing: border-box;` |

**1–4 个数字永远从顶部开始顺时针读**：top → right → bottom → left。同一条规则同时管住 `padding` 和 `margin`，学一次就够。

课件的 Key Takeaways 里对盒模型这一段的总结是：「Every element is a box — content, padding, border, margin, corners and background」以及「The background paints the box」。本篇的结论就是这两句的展开。
