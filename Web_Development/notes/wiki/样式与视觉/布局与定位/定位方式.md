# 定位方式 · The Five Position Values

> **一句话**：`position` 有五个值，区别只在两件事上 —— **相对什么定位**、**在不在文档流里**；而偏移量的规律只有一条：**正值把盒子推离属性名字所指的那条边**。

课件原文见 [Lecture_05_CSS.pptx](<../../../raw/Lecture_05_CSS.pptx>)。本篇覆盖其中「The Five Position Values」以及 `static` / `relative` / `absolute` / `fixed` / `sticky` 各页与偏移四页、「Position Cheatsheet」。

## 一、五值对照表

| 值 | 相对什么定位 | 在文档流里？ | 典型用途 |
|---|---|---|---|
| `static` | — | **在** | 正常布局 |
| `relative` | **它自己的正常位置** | **在**（保留原位） | 微小挪动、当锚点父级 |
| `absolute` | **最近的有定位（非 static）的祖先** | **不在** | 徽标、浮层、下拉菜单 |
| `fixed` | **视口（viewport）** | **不在** | 吸顶页头、回到顶部按钮 |
| `sticky` | **滚动位置 + 自己的容器** | **在** | 章节标题、表头 |

课件那句定义必须记住：**"In flow = it reserves its space; out of flow = others ignore it."**（在流里 = 它保留自己的位置；不在流里 = 别人当它不存在。）

```css
position: static | relative | absolute | fixed | sticky;
```

## 二、逐个拆开

### `static` —— 默认，你永远不会写它

| 特性 | 说明 |
|---|---|
| 默认值 | **每个元素都从这里出发**，你从不需要声明 |
| 偏移量 | **完全被忽略** —— `top` / `right` / `bottom` / `left` 写了也白写 |
| 文档流 | 照旧上 → 下、左 → 右 |
| 好处 | static 盒子**永远不会把周围的盒子挤开** |

```css
/* 默认 —— 你永远不写这一条 */
.box { position: static; }

/* 偏移量落在 static 上哪儿也不去 */
.box {
  top: 24px;
  left: 24px;
}
```

**写上去、然后从没用过。** 这是最常见的一处「以为写了、其实没生效」。

### `relative` —— 挪开，但位置照留

`position: relative` 的元素**相对它自己的正常位置**定位。设 `top/right/bottom/left` 会把它从正常位置上挪开，但 —— 课件的措辞很精确：

> **Other content will not be adjusted to fit into any gap left by the element.**（别的内容**不会**为了补它让出的空隙而调整。）

```css
/* 三个同样大小的盒子 */
div {
  display: inline-block;
  width: 300px;
  border: 3px solid black;
}
/* 中间那个：往右挪 30px */
div.relative {
  position: relative;
  left: 30px;
}
```

课件用 15 盒演示里的**第 7 号**说明：它往下往右挪了，但**第 8–12 号一动不动**，虚线框标出它仍然占着的那块位置。

> [!important] `relative` 的第二个身份
> 它是 **absolute 的锚点**。给父级写 `position: relative`，子级写 `position: absolute`，就能把子级钉在父级的任意一个角上 —— 这就是课件 Common pattern 那一条。

### `absolute` —— 出流，钉到祖先

| 特性 | 说明 |
|---|---|
| 文档流 | **被移除** —— 别的盒子**当它不存在**，会在它背后**合拢** |
| 锚点 | **最近的有定位（非 static）祖先** |
| 没有这样的祖先 | 锚到**文档**（页面）本身 |
| 常见组合 | 父级 `relative` + 子级 `absolute` |

```css
/* 父级当锚点 */
div.relative {
  position: relative;
  width: 400px;
  height: 200px;
}
/* 子级钉到角落 */
div.absolute {
  position: absolute;
  top: 80px;
  right: 0;
}
```

课件的演示：第 7 号盒子离开布局，**8–12 号在它后面合拢**，而 7 号本身钉在了 `position: relative` 那个容器的角上。**相对父级 + 绝对子级 = 把任何东西钉在任何角。**

> [!warning] 出流的代价：别人会补位
> 绝对定位的盒子**不再占位置**，所以它离开后原本给它的空隙会被填上。要预留这块地，就给容器留 `padding`（见 [[内外边距]]）。

### `fixed` —— 钉在视口上

| 特性 | 说明 |
|---|---|
| 锚点 | **视口**，**不是**文档 —— 它**无视滚动** |
| 适用 | 页头、回到顶部按钮 |
| 文档流 | **不在流里**，浮在内容之上，**不占位置** |
| 必做的一件事 | **给 `body` 加 padding**，否则它会盖住内容 |

```css
/* 钉在窗口上的一个盒子 */
div.fixed {
  position: fixed;
  bottom: 0;
  right: 0;
  width: 300px;
  height: 200px;
}
```

课件的演示：**文档已经滚动了，那根条子没动。**

> [!warning] `fixed` 唯一会咬人的地方
> 它的**「不占位置」**意味着被它盖住的区域**没有任何空隙被预留**。`position: fixed; top: 0` 的页头会盖住正文最上面那几行 —— 所以**必须**给 `body` 加相应的 `padding`。这是布局最常见的「内容被切掉」事故之一。

### `sticky` —— 两者的混合

| 阶段 | 行为 |
|---|---|
| 还在视野内 | 像 **`relative`** 一样跟着内容滚 |
| 撞到偏移位置 | 像 **`fixed`** 一样钉住 |
| 容器滚过去 | **它也就不再吸**了 |

```css
/* 一根吸顶的条 */
div.sticky {
  position: sticky;
  top: 0;
  padding: 5px;
  background-color: #cae8ca;
  border: 2px solid #4CAF50;
}
```

> [!warning] `sticky` 没有偏移量就完全不吸
> 课件的措辞：**"Without `top`, `right`, `bottom` or `left` it never sticks."** —— 只写 `position: sticky` 而不写 `top: 0`，它就永远只是普通内容。这是 sticky 最常见的失败原因。
>
> 另一条限制：**它只在自己的容器里移动**。父容器滚过去之后，sticky 就到头了。

## 三、偏移的规律：一条规则管住四个属性

> [!important] **正值把盒子推离「属性名字所指的那条边」。**

这一条是本篇最值得背下来的。四个属性各 40px：

| 声明 | 方向 | 记忆法 |
|---|---|---|
| `top: 40px` | **下** 40px | 离**上**边远一点 → 向下 |
| `bottom: 40px` | **上** 40px | 离**下**边远一点 → 向上 |
| `left: 40px` | **右** 40px | 离**左**边远一点 → 向右 |
| `right: 40px` | **左** 40px | 离**右**边远一点 → 向左 |

**加个负号就反过来**：`top: -40px` 上移、`bottom: -40px` 下移、`left: -40px` 左移、`right: -40px` 右移。

```css
/* 从盒子自己的位置量起 */
.box { position: relative; top: 40px;  }   /* +40 = 向下 */
.box { position: relative; top: -40px; }   /* -40 = 向上 */
.box { position: relative; left: 40px;  }  /* +40 = 向右 */
.box { position: relative; left: -40px; }  /* -40 = 向左 */
.box { position: relative; right: 40px; }  /* +40 = 向左 */
.box { position: relative; right: -40px; } /* -40 = 向右 */
.box { position: relative; bottom: 40px;  } /* +40 = 向上 */
.box { position: relative; bottom: -40px; } /* -40 = 向下 */
```

课件在四张偏移页的末尾各有一句总结，凑起来就是这张表：

- `top: 40px` drops the box 40px; `top: -40px` lifts it the same distance.
- `left: 40px` pushes the box 40px right; `left: -40px` pulls it left.
- `right: 40px` pushes the box 40px left — **the opposite edge, the opposite way**.
- `bottom: 40px` lifts the box 40px; `bottom: -40px` drops it.

**两组轴**：`top` / `bottom` 管上下，`left` / `right` 管左右。

> [!important] 上面这套讲的是 relative 盒子的行为
> 课件明确标注 **"Relative only"** —— 同一个 `top: 40px`，放在 `absolute` 盒子上是「离**包含块**的上边 40px」，含义完全不同。所以**偏移的方向规律要记在 relative 这条线上**，而绝对定位的偏移是**相对于锚定容器**的边来量的（因此 `top: 0` / `bottom: 0` 就有明确的「贴边」含义，sticky 也才需要 `top: 0` 才能吸）。
