## 全库主题地图

### 全栈概览 · The Big Picture（Week 1 · 6 篇）

- [[Web应用与客户端-服务器模型]] — **客户端—服务器模型**、双方唯一的共同语言是 HTTP
- [[三层架构]] — **浏览器 / 服务器 / 数据库**，两跳协议（HTTP 与 SQL）
- [[HTTP与URL]] — 请求与响应的**解剖结构**、URL 六个组成部分
- [[后端技术栈]] — Node.js → Express → REST/CRUD → WebSocket/SPA/部署（概览层）
- [[性能与可扩展性]] — 缓存、CDN、HTTP/2；大型网站的五层架构
- [[课程路线图]] — Week 1–13 每周建什么

### HTML与文档结构 · The Structure（Week 2 · 13 篇）

- [[HTML是什么]] — 结构而非外观、浏览器如何渲染、发展史与 living standard
- [[元素与标签语法]] — 元素的四部分、void 标签、嵌套逆序、完整文档骨架
- [[属性]] — `name="value"`，CSS 与 JavaScript 都要靠它**抓元素**
- [[文本语义]] — 标题层级、`<strong>`/`<em>` 的**语义**用法、空白折叠
- [[链接与图像]] — `href` 的各种形态、`alt` 必写、`<picture>` 响应式图像
- [[图像映射]] — `usemap` + `<area>`，三种形状的坐标读法与**不能 CSS 缩放**
- [[列表与表格]] — ul/ol/dl，表格只放数据
- [[表单与输入]] — `action` + `method`、input 的类型与属性
- [[表单验证与可访问性]] — `label for`、浏览器**免 JS** 的原生校验
- [[媒体元素]] — `controls`、`controls` 之外的 `<source>` 回退
- [[SVG矢量图形]] — 用标记描述图形、viewBox、path 命令
- [[容器与语义化]] — div vs span、block vs inline、语义化容器与 landmark
- [[DOM与开发者工具]] — HTML 变成**活的树**、Elements 与 Console

### 样式与视觉 · Styling（Week 3–5 + Tutorial 1 · 37 篇）

#### 颜色与文字（10）

- [[样式声明与内联]] — `property: value;` 这个模式，以及 `style` 属性的一次性
- [[颜色表示法]] — 命名 / hex / `rgb()` / `hsl()` **四种写法**，以及课程调色板
- [[透明度与叠加层]] — `rgba()` 的 alpha 与 `opacity`、scrim 与 caption
- [[长度与单位]] — 绝对单位、相对单位、**`em` vs `rem`**、视口单位
- [[文本与字体]] — `font-family` 回退栈、`font` 简写、`@font-face`
- [[继承]] — 文字属性流下去，**盒属性留在原地**
- [[色彩成因]] — **减色**（颜料）与**加色**（光），屏幕和打印机为什么对不上
- [[色轮与三大参数]] — 色相/饱和度/明度，**HSV 与 HSL 的第三个通道不一样**
- [[配色方案]] — **七种**在色轮上取点的几何规则，以及各自何时出错
- [[对比度与可读性]] — **对比度是算出来的数**、AA/AAA 阈值、颜色不能是唯一载体

#### 选择器与层叠（7）

- [[CSS引入方式]] — 内联样式的四个问题，**外链 / 内嵌 / 行内**
- [[规则结构与选择器分类]] — rule-set 的形状，**五类选择器**总表
- [[简单选择器]] — 元素、id、class、通配符；**class vs id**
- [[组合选择器]] — 分组、后代 `A B`、子代 `A > B`、兄弟 `A + B` / `A ~ B`
- [[属性选择器]] — `[attr]`、`^=`、`$=`、`*=`
- [[伪类与伪元素]] — 状态伪类（**LVHA 顺序**）、结构伪类、伪元素
- [[层叠与优先级]] — **来源顺序**、**优先级 (0,0,1) 计分**、`!important`

#### 盒模型（6）

- [[盒模型五层]] — **每个元素都是一个盒子**，content/padding/border/margin
- [[边框与圆角]] — border 的三要素、顺时针 1–4 值、`border-radius` 的几何本质
- [[内外边距]] — padding 会被绘制、margin 永不绘制、**margin collapsing**
- [[尺寸与盒模型计算]] — `width` 指什么由 `box-sizing` 决定、**margin 居中**
- [[背景与混合模式]] — 背景六属性与简写、`mix-blend-mode`
- [[图像精灵]] — 一张图多个画面、`background-position` 取格、`steps()` 播帧

#### 布局与定位（6）

- [[常规流]] — 不写任何 `position` 时浏览器做的事
- [[定位方式]] — **static / relative / absolute / fixed / sticky**、偏移的符号规律
- [[层叠顺序与z-index]] — 谁盖住谁、z-index 只在层叠上下文内比较
- [[Flexbox]] — **一根轴**上的布局
- [[Grid]] — **行列两维**布局
- [[响应式与媒体查询]] — viewport、流式布局、`@media`、**移动优先**

#### 动效与细节（8）

- [[变换transform]] — 移动/旋转/缩放，**不引起重排**
- [[过渡transition]] — 把状态突变变成渐变、计时函数、`transition: all` 的坑
- [[关键帧动画]] — `@keyframes` 配方 + `animation` 运行、多段停靠点、`steps()`
- [[动效与可访问性]] — `prefers-reduced-motion`：**去掉运动，不是去掉意思**
- [[CSS变量]] — `--name` 定义、`var()` 读取、主题切换
- [[阴影]] — `box-shadow` 五个值、focus ring 与 inset
- [[display与隐藏]] — 外部盒类型、**隐藏元素的三种方式对比**
- [[图标]] — 图标字体 / 内联 SVG / 图片文件，各自的代价

### JavaScript · JavaScript Basics（Week 6 · 36 篇）

#### 语言基础（12）

- [[JavaScript是什么]] — 第三根柱子、**引擎解释执行**、浏览器与 Node.js
- [[JavaScript与ECMAScript]] — 品牌 vs 标准、**ES6 = ES2015**、引擎才实现标准
- [[脚本放在哪里]] — `head` 里的脚本**跑在 body 存在之前**、多文件共享全局
- [[四种输出方式]] — `innerHTML` / `alert` / `console.log` / `document.write`
- [[语句与标识符]] — 语句与分号、关键字与保留字、`camelCase` 与 `UPPER_CASE`
- [[变量与声明]] — `=` 是赋值、**声明未赋值就是 `undefined`**、`var` 会逃出块
- [[运算符]] — 算术与赋值；**`+` 遇到字符串就变成拼接**
- [[比较与typeof]] — `==` 先转类型、`===` 不转；`typeof` 的八种返回与 `null` 例外
- [[类型系统]] — **动态类型**：类型属于数据，不属于变量
- [[字符串与数字]] — 只有一种数字类型、`length` 是属性、**浮点数不精确**
- [[数组与空值]] — 下标从 0、`undefined` vs `""` vs `null`
- [[原始值与引用值]] — 原始值**不可变、被复制**；对象**可变、被共享**

#### 控制流（5）

- [[条件语句]] — 真值判断、`else if` **第一个匹配的赢**、**永远写花括号**
- [[switch语句]] — 逐条比较、`break` 挡穿透、`default` 兜底
- [[循环语句]] — `for` 三段式、**`i < length` 不是 `<=`**、`for...in` vs `for...of`
- [[位运算符]] — 七种运算、`>>` 保符号位 vs `>>>` 补零
- [[错误处理]] — `try` / `catch` / `finally` / `throw`，以及课件 `check()` 的逐行拆解

#### 函数与对象（8）

- [[定义与调用]] — **调用时才执行**、**没有 `return` 就是 `undefined`**、`()` 才是调用
- [[参数与默认值]] — 参数 vs 实参、**不声明类型也不查个数**、默认值必须放最后
- [[函数表达式与自执行]] — 函数是值、**声明会提升而表达式不会**、IIFE 的括号
- [[函数即值]] — 回调就是"以后再调"；`addEventListener` / `setTimeout` 同一个想法
- [[作用域与严格模式]] — 三种作用域、**未声明赋值是 bug**、`"use strict"` 把静默错误变响亮
- [[对象与属性]] — 一袋带名字的值、两种读法、**对象是引用**
- [[方法与this]] — `this` 是**调用所在的那个对象**、箭头函数不绑定 `this`
- [[属性增删与访问器]] — 赋值即新增、`delete` 只删属性、getter 读时算 setter 写时算

#### 浏览器接口（11）

- [[DOM树]] — 标签变节点、**同一棵树 CSS 选它、脚本改它**
- [[查找元素]] — 五个方法、**live 集合 vs static 列表**、`null` 从哪来
- [[修改元素]] — `innerHTML` 解析标记 / `textContent` 只放纯文本、**先查 `null` 再改**
- [[增删元素]] — 五个方法，**新元素挂上去之前不可见**
- [[JavaScript改样式]] — 驼峰改名、`classList` 通常比内联好、`getComputedStyle`
- [[BOM与window]] — **没有标准但人人都有**、`window.` 可省略、视口尺寸会变
- [[screen与location]] — 四个对象分别管"在哪"和"什么机器"
- [[定时器与Cookie]] — `setTimeout` 一次 / `setInterval` 反复且**要留句柄**
- [[事件基础]] — 事件对象、两种监听方式、**事件会冒泡**
- [[事件处理与常见事件]] — 属性式 / 属性赋值 / `addEventListener` 的取舍
- [[事件监听器]] — **监听器会叠加**、移除要同一个引用、**事件委托**
