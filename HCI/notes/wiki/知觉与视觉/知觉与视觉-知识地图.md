# 知觉与视觉 · 知识地图

本目录只有一份课件（91 页），但它是整个 L02–L03 的**收口**：课件在这里把"人怎么被数据欺骗"讲透了，并且直接给出设计后果。

课件原文见 [Visuals Part 1](<../../raw/03 COMP3423 Visuals Part 1 2026 09 26.pdf>)。

## 一句话主线

> **3D 不是视网膜的属性，颜色不是光的属性，模式不是数据的属性。**
> 你看到的一切，都是大脑在原始数据上做了一连串操作之后**构造出来的解释**。

课件把这条主线拆成两个动作：

| 动作 | 输入 | 产出 | 笔记 |
|---|---|---|---|
| **物理接收** | 光 | 电信号 | [[视觉系统的物理接收]] |
| **解释** | 电信号 | 颜色 / 三维 / 模式 | [[颜色知觉]]、[[三维知觉是构造出来的]]、[[格式塔原则]] |

最后汇成 [[从数据到信息]] 那张"数据 → 信息"十一项清单。

## 详细笔记

**接收层**

- [[视觉系统的物理接收]] — 视网膜、视杆视锥、神经节细胞、亮度、图案滤波、Hermann 网格
- [[视角度量与大小恒常性]] — 视角度量公式，以及"巨人与侏儒"为什么反直觉
- [[颜色知觉]] — 色相 / 强度 / 饱和度、互补色与后像、色觉障碍比例

**解释层**

- [[三维知觉是构造出来的]] — 视网膜只有二维，七步造出三维；双眼与视交叉
- [[运动视差与光流]] — 狗与月亮、动的是哪趟车、月亮跟着你走
- [[格式塔原则]] — 相似 / 邻近 / 对称 / 连续 / 闭合 / 小面积 / 被包围，各带设计后果
- [[从数据到信息]] — 十一项转换 + "人会在没有模式的地方看见模式" + 彩票与大数据

## 复习路线

1. **先背那三句否定式**："3D 不是视网膜的属性 / 颜色不是光的属性 / 模式不是数据的属性"。整本课件是这三句的展开
2. **视角度量**是本域唯一要会推的公式，[[视角度量与大小恒常性]] 里有完整推导
3. **七条格式塔**按"相似→邻近→对称→连续→闭合→小面积→被包围"记，每条都配一个课件里的具体图，别只背名字
4. [[从数据到信息]] 的十一项清单和 [[视觉系统的物理接收]] 的接收层内容**高度重叠**，背一份就够，但要知道它们讲的是同一条链的上下两段
5. 课件最后那句必须记住：***"ALL computer analysis depends on human analysis!!"***

## 设计后果（每条原则都有落点）

课件反复从"人怎么被欺骗"推出"设计该怎么办"。复习时按这条链走，比背原则本身有用：

| 认知事实 | 设计后果 |
|---|---|
| 大脑会补全缺失（[[格式塔原则\|格式塔原则]]） | 缺失信息会被**自动编造**出来，提示必须说清"现在是什么状态" |
| 注意偏向"高"和"上"（[[从数据到信息\|从数据到信息]]） | 图表别指望用户均匀扫视，把要看的放高位 |
| 颜色是解释不是属性（[[颜色知觉\|颜色知觉]]） | 不能只靠颜色区分信息，8% 男性会失效 |
| 大小恒常性（[[视角度量与大小恒常性\|视角度量与大小恒常性]]） | 控件的**感知**大小 ≠ 像素大小，这正是 [[../运动与绩效/Fitts定律\|Fitts定律]] 里 $W$ 的隐患 |
