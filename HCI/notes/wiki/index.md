### 学科定位（6 篇 · L01）

回答"为什么要花力气做这件事"，以及"HCI 到底管到哪儿为止"。

- [[学科定位-知识地图]] — **本域 MOC**
- [[HCI-定义与学科边界]] — 四个版本的定义、SIGCHI 1992 的三层横条模型、**HCI ≠ 界面设计**
- [[可用性工程就是软件工程]] — 63% 项目超支、返工成本曲线、"早付一点还是晚付很多"
- [[可用性即销量]] — 评测媒体把关、用户没耐心，以及坏设计的代价
- [[人类与计算机的能力分工]] — 各自擅长什么，设计时该把什么交给谁
- [[HCI 的多学科性]] — 十个学科各自贡献什么，以及一个反直觉的越界例子

### 交互的历史（9 篇 · L01）

用三个问题串起整段历史：**用户的角色是什么 / 交互长什么样 / 人与机器是什么关系**。

- [[交互的历史-知识地图]] — **本域 MOC**
- [[交互方式的八个阶段]] — Batch → Timesharing → Networking → 图形 → PC → WWW → 泛在 → 社交机器人
- [[Memex 与超文本的预言]] — Vannevar Bush 1945
- [[Engelbart 与增强人类智力]] — Douglas Engelbart 1950s–1968
- [[Licklider 与人机共生]] — Licklider 1960 的三级目标与今天的脑机接口
- [[个人计算的预言者们]] — SketchPad 1963 / Dynabook 1969 / Computer Lib 1974
- [[Xerox PARC 与图形界面的商业化]] — Alto → Star 8010 → Lisa → Macintosh
- [[先驱者与定居者]] — 为什么 Star 和 Lisa 输了、Macintosh 赢了
- [[创新始于无效的实验]] — Maxwell、Hertz 与"诗人—科学家—go-getter—企业家"四段

### 人类信息加工（11 篇 · L02）

课件的**主干**，也是考试权重最大的一块。模型是"输入感知 → 吞吐（记忆 / 认知 / 情感）→ 输出反应"。

- [[人类信息加工-知识地图]] — **本域 MOC**
- [[人类信息处理器模型]] — 整个模型的骨架，后面所有笔记的挂靠点
- [[问题空间与目标状态]] — 问题 / 目标 / 子目标 / 问题空间，以及"够好了"
- [[问题解决的策略谱系]] — 七种策略 + 智能与创造性的分界线
- [[差异缩减与手段-目的分析]] — 一个送货问题的完整推演，以及它对**技术选型**的影响
- [[正向推理与反向推理]] — 什么时候允许推、什么时候必须去验
- [[类比推理]] — 特征 / 类别 / 关系三件套，含斧头与啄木鸟的完整拆解
- [[随机试错与新手困境]] — 新手为什么会在菜单里乱点
- [[问题表征的三个层级]] — 表层 / 结构 / 符号，同一个"冰融化"能长出三族解法
- [[两种心智模型]] — 逻辑理性主义 vs 联想经验主义，43 个积木那个数法
- [[创造性与深度学习]] — 分类器的"错"为什么在创造力里不算错

### 知觉与视觉（8 篇 · L03）

课件的核心结论只有一句：**你看见的不是数据，是大脑构造出来的解释**。

- [[知觉与视觉-知识地图]] — **本域 MOC**
- [[视觉系统的物理接收]] — 视网膜、视杆视锥、神经节细胞、视角度量、亮度
- [[视角度量与大小恒常性]] — 视角度量公式，以及"巨人与侏儒"
- [[颜色知觉]] — 色相/强度/饱和度、互补色与后像、色觉障碍
- [[三维知觉是构造出来的]] — 视网膜上只有二维，三维由七步操作造出来
- [[运动视差与光流]] — 狗与月亮、动的是哪趟车、月亮跟着你走
- [[格式塔原则]] — 相似 / 邻近 / 对称 / 连续 / 闭合 / 小面积 / 被包围
- [[从数据到信息]] — 十一步转换，以及"人会在没有模式的地方看见模式"

### 运动与绩效（4 篇 · L02）

输出侧只有一件事：**把人当成一条有带宽的通道来算**。

- [[运动与绩效-知识地图]] — **本域 MOC**
- [[Fitts定律]] — $T=a+b\log_2(2D/W)$，以及那个对数到底在说什么
- [[难度指数与绩效指数]] — ID 属于任务，IP 属于设备；鼠标为什么接近最优
- [[反应时与行为时间尺度]] — 反应时 vs 反应执行时间，三种刺激的量级

课件里最容易被当成闲笔、其实最该记住的部分：**同一个"效率"在不同的组织和文化里是不同的东西**。

- [[情境与文化-知识地图]] — **本域 MOC**
- [[界面背后的组织与文化]] — 三个学生案例：医疗平板、祖父母的药提醒、跨区支持团队

## 整理原则

- **目录不带数字**，按概念轴划分，便于长期扩展
- **场景不预设**：任何例子都从零完整解释——样本是什么、任务是什么、每一步在做什么。**不写"如上例所示"这种依赖前文的省略。** 课件里的瑞穗证券、AA965、Three Mile Island、送货车、象人椅、斑点狗，全部按此重写
- **每篇自足**：不引用"课件第几页的例子"而不解释它；课件页码只作溯源标注，不是理解的前提
- **术语中英对照**，便于对照课件和英文考卷
- **每篇都有 `domain` 字段**，单域归本域目录
- **frontmatter 溯源**：`course` / `lecture` / `source` 直链 `notes/raw/` 里的对应 PDF
- 每篇末尾有 `## 相关笔记`（4–8 条，每条附一句关系说明），**双向可达**
- 标记了若干**常见错误**（`> [!warning]` callout）
