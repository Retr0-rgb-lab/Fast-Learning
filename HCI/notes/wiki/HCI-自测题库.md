# HCI-自测题库

三种题混排：**课件原题**（照搬英文原句 + 中文，标了正确答案与出处）、**概念题**（自己出，答案是本库的一篇笔记）、**连线题**（把两个域的概念对上，用来检验跨域连接是否真的记住了）。

课件原题只有两道 —— 这两道的题型分类（`Insight` / `Knowledge`）本身就是重要信息：**这门课不只考记忆，还考"两个概念为什么相关"。**

## 一、课件原题（照搬）

### Q1 · Insight 类

> **How is Fitts' Law related to the fat-finger syndrome (i.e., Japanese stock broker)?**
> Fitts 定律和"胖手指综合征"（即那位日本证券经纪人）有什么关系？

| 选项 | 内容 |
|---|---|
| A | 压力会拉低表现 |
| B | Fitts 考虑的是指针与界面控件之间的**宽度比** |
| C | 胖手指误差的**对数分布**与鼠标指针的分布不同 |
| D | **A 与 B 都对** |

**✅ 答案 D。** 课件给的解析原文：

> *"Fitts: The wider an interface widget and the closer it is to the pointer, the easier to hit it — particularly when the pointer is wide as well (fat finger). So it's about the **pointer-to-target width ratio**, not target width alone. And yes, people make more errors under stress."*

**三个必抓点**：

1. 决定难度的是**指针宽度与目标宽度之比**，不是目标宽度单独 —— 因为指针自己也有宽度
2. 压力确实会拉低表现（所以这是 A）
3. 选项 C 是**干扰项**：公式里的对数来自"难度按 log 增长"，**不是**说胖手指和鼠标有各自不同的误差分布

→ [[Fitts定律]]、[[难度指数与绩效指数]]、[[可用性即销量]]

### Q2 · Knowledge 类

> **When can you consider a problem to be 'well-defined'?**
> 什么时候可以说一个问题是"良定义"（well-defined）的？

| 选项 | 内容 |
|---|---|
| A | 当目标分解能把复杂问题拆成小的那些（通过确定子目标） |
| B | 当在有多种表征的问题状态里做出了结构化决策 |
| C | **当所提供的数据、动作、策略、目标状态被完整指定，可以表示成一个问题空间时** |
| D | 当在结构层，关注点落在结构与过程的变化（工作单元及其动作）上 |

**✅ 答案 C。** 课件原文定义：

> *"well-defined problem: full specification of the provided data, actions, strategies, and goal states, which can be represented in a problem space"*

**三个干扰项为什么错**（这是这道题真正的考点）：

- **A** 混淆了两件事：目标分解是**解决**良定义问题的手段，不是它成立的**条件**。分解能做完不代表问题良定义
- **B** 方向反了：结构化决策对应**良定义**问题，不是良定义的判据
- **D** 只是 [[问题表征的三个层级]]里的一层，把某一层的特征当成了整体定义

课件紧接着给的正面例子是 Arduino 的 PLC 蓝图 —— 完整规格，用起来"像照着图纸干活一样顺手"。

→ [[问题空间与目标状态]]、[[问题解决的策略谱系]]
