## 模型总图

整块内容挂在一个模型上。**先记住这张图，再往里填细节**：

```
                    输入：感知 Input: perception
        视觉 · 听觉 · 触觉（各自分物理接收层与解释层）
                              │
                              ▼
        ┌────────── 吞吐 Throughput: processing ──────────┐
        │  记忆 Memory（感觉记忆 / 短时 / 长时）            │
        │  认知加工 Cognitive processing（问题解决）        │
        │  情感加工 Affective processing（目标 · 相关 · 效价）│
        └──────────────────────────────────────────────────┘
                              │
                              ▼
                    输出：反应 Output: response
        运动 Motor（速度-准确权衡）· 绩效评估 · 用户评价
```

**本目录只讲中间那块"认知加工"以及它前后的接口。** 感知归 [[../知觉与视觉/知觉与视觉-知识地图|知觉与视觉]]，运动归 [[../运动与绩效/运动与绩效-知识地图|运动与绩效]]。

## 认知加工的两条主线

课件在这一块同时推进两条线，容易混，复习时分开记：

| 主线 | 问的问题 | 相关笔记 |
|---|---|---|
| **A · 怎么解** | 一个问题摆在面前，人会**用哪种策略**解 | [[问题空间与目标状态]] → [[问题解决的策略谱系]] → 下面四篇分述 |
| **B · 怎么看** | 同一个问题被**怎么表述**，就会长出哪一族解法 | [[问题表征的三个层级]]、[[两种心智模型]] |

两条线的交点是 [[创造性与深度学习]]：A 线末尾的"创造性问题解决"和 B 线末尾的"创造性思维"其实是同一件事的两面。

## 复习路线

1. **默画那张模型图**。三段（输入 / 吞吐 / 输出）+ 吞吐里的三块（记忆 / 认知 / 情感）。这一关过不了，后面都不用看
2. **背下七种策略的顺序**：规则跟随 → 差异缩减 → 手段-目的分析 → 正向/反向推理 → 类比 → 随机试错 → 创造性。见 [[问题解决的策略谱系]]
3. **能完整推出送货那个例子的 28 与 16 两个答案**（[[差异缩减与手段-目的分析]]），这是课件唯一一处反复讲的完整推导
4. **记住那条主线**：*represent a problem either way, begs its solution*。这是 [[问题表征的三个层级]] 的全部要点，也是最容易考"Insight"题的出处
5. 最后一节 Human-generated summary 里的三句结论要能复述：感知/记忆/问题解决/反应"less stable but more adaptive"、输入会**整合成一个整体**、记忆**随时间改变且依赖情境**
