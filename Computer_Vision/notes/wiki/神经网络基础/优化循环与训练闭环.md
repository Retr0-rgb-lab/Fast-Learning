# 优化循环与训练闭环

> [!info] 定位
> 对应 PyTorch 官方教程 *Learn the Basics* 的 *Optimization* 章(https://pytorch.org/tutorials/beginner/basics/optimization_tutorial.html)。到此训练的完整闭环已经齐了：**前向 → 损失 → 反向 → 更新参数**，按 epoch 循环，每轮后测试评估。

## 完整代码骨架

```python
learning_rate = 1e-3
batch_size = 64
epochs = 5

model = NeuralNetwork().to(device)
loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=learning_rate)

for t in range(epochs):                 # 外层：epoch
    print(f"Epoch {t+1}\n---------------")
    train_loop(train_dataloader, model, loss_fn, optimizer)
    test_loop(test_dataloader, model, loss_fn)
```

每个 epoch 分两段：

- **train_loop**：`pred = model(X)` → `loss = loss_fn(pred, y)` → `zero_grad → backward → step`（**更新参数**）
- **test_loop**：`model.eval()` + `torch.no_grad()`，只算 accuracy 和平均 loss，**不更新参数**

三连的细节见 [[Autograd 自动微分]] 和 [[梯度累加与 zero_grad]]；模式切换见 [[model.train 与 model.eval]]。

## loss function / criterion / loss

- **loss function（损失函数）**：可调用对象（如 `nn.CrossEntropyLoss()`），衡量"预测和真实值差多少"；PyTorch 文档常叫 **criterion**，同一个意思
- **loss**：它算出来的那个标量，是反向传播的起点
- 关键性质：必须对参数**可微**，优化器才能靠梯度更新权重
- 输入是 `loss_fn(pred, y)`（预测 + 标签），间接依赖全部权重；`X, y` 是已知条件，**不进优化器**

## 只写 forward，不写 backward

`nn.Module` 里**只要定义 `forward`**：里面用的都是现成算子（`nn.Linear`、ReLU），autograd 会按计算图自动求导。训练时调用的是 **`loss.backward()`**，不是 `model.backward()`。

只有自定义、库里没有梯度的运算，才需要实现 `torch.autograd.Function` 的 `forward` + `backward` 再包进 `nn.Module`（进阶）。

## 教学版闭环 vs 生产级流水线

作为 **PyTorch 参数优化闭环**是完整、可跑通的；作为完整 MLOps 训练系统还不完整：

- 测试集直接当验证集，没有独立 val split
- 没有 checkpoint 保存、scheduler、early stopping（保存在官方教程 *Save & Load* 章:https://pytorch.org/tutorials/beginner/basics/saveloadrun_tutorial.html）
- `zero_grad()` 放在 `step()` 之后也能跑（教程写法），本质是"下次 backward 前清掉"；更常见的写法是循环开头先 `zero_grad()`

## 练习任务：不看教程默写训练闭环（约 1–2 小时）

> [!tip] 不要背代码
> 闭环就那 5 步，抄 3 遍没用；从空白文件写，靠完成任务来掌握。

**目标**：空白脚本写通 FashionMNIST 训练闭环，再做 3 个对照实验。

**约束**：`nn.Module` 只写 `forward`；训练用 `loss.backward()`，不要自己写 backward。

**交付**：

1. DataLoader → 模型 → `CrossEntropyLoss` + `SGD` → train loop + test loop，跑 5 个 epoch
2. 每个 epoch 打印 train loss、test loss、test accuracy
3. 对照实验（每次只改一项）：
   - `lr`：`1e-1` vs `1e-3`
   - 优化器：`SGD` vs `Adam`
   - 网络多一层 `Linear`+`ReLU`
4. 记下：哪组 test acc 最高、哪组 loss 炸了或几乎不动
5. （加分）`torch.save(model.state_dict(), ...)`，新开进程 load 后对 1 张图做预测

**过关标准**：不看文档能默写 train 那 5 行，并能解释"关掉 `zero_grad` 会怎样"。
