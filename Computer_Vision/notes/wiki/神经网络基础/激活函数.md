# 激活函数

**激活函数为网络引入非线性**。没有它，多少层 `Linear` 叠在一起都等价于一层线性变换，学不了复杂模式。

## 为什么线性叠不出非线性

`Linear` 做的是 $y = xW^T + b$，是线性变换。两层直接连起来：

$$
W_2(W_1 x + b_1) + b_2 = (W_2 W_1)x + \cdots
$$

还是一个线性层（一条直线/超平面），再深也白搭。对 Fashion-MNIST 这类非线性分类任务，必须插入激活函数，网络才能学出**弯曲的决策边界**。

## 折线直觉

激活函数像在层与层之间"折一下"：每一段是直线，但折起来就能近似曲线。成百上千个带折点的神经元叠在一起，整体看起来就像平滑的非线性——很多 ReLU 拼在一起会把输入空间切成许多小直线块，块够多时就能逼近任意弯曲的关系。

## 放在哪里

- **隐藏层**：夹在 `Linear` 之间，如 `Linear → ReLU → Linear`
- **输出层按任务选**：
  - 多分类 → 输出 logits，训练交给 `CrossEntropyLoss`（内部含 softmax），见 [[Logits、Softmax 与 argmax]]
  - 二分类 → 输出层用 [[Sigmoid]]，见下面对比
  - **最后一层不要加 ReLU**，否则负分数被截成 0

## ReLU vs Sigmoid 对比

| | [[ReLU]] | [[Sigmoid]] |
| -- | -------- | ----------- |
| 输出范围 | $[0, +\infty)$ | $(0, 1)$ |
| 梯度 | 正区间恒为 1，不易梯度消失 | 两端饱和、导数趋近 0，深层易梯度消失 |
| 计算成本 | 比较 + 置零，很便宜 | 指数运算，更贵 |
| 输出是否以 0 为中心 | 否（全非负） | 否（全正） |
| 典型位置 | 隐藏层主力 | 二分类输出层经典 |

现代深度网络隐藏层更多用 ReLU、Leaky ReLU、GELU 或 SiLU。
