# 密度聚类

[[K-Means]] 假设每个簇围绕一个中心、形状近似"圆团"。密度聚类换了个问法：

> **哪些区域的点足够密，能连成一片？**

## DBSCAN

两个超参数：

- $\varepsilon$：邻域半径；
- `min_samples`：成为核心点所需的最小邻居数。

过程：

1. 某点在 $\varepsilon$ 邻域内样本数达到阈值 → **核心点**；
2. 从核心点向相连的稠密区域**扩张**成簇；
3. 远离所有稠密区的点直接标为**噪声**。

优势：

- **不必预先指定簇数**；
- 能发现**不规则形状**的簇；
- 有"噪声"出口，抗离群点。

## Mean-Shift

迭代爬山的过程：

1. 在每个候选位置附近取一个窗口；
2. 计算窗口内所有点的**均值**，把窗口中心向该均值**移动**；
3. 重复，直到收敛。

中心会"爬"向**数据密度峰值**。最终收敛到**同一峰值**的点构成一簇。**带宽（bandwidth）决定窗口大小**——所以簇数不用预设，但带宽要调。

## 什么时候谁更好

典型反例：**弯月形簇套着另一个弯月形簇**。

| 场景 | K-Means | DBSCAN |
| --- | --- | --- |
| 判断依据 | 到簇中心的距离 | 邻域内的密度 |
| 外层弯月 | 会被两个中心劈开 ❌ | 沿着密集弧连成一片 ✅ |
| 内层弯月 | 同上 ❌ | ✅ |

结论：簇形状不规则、簇数未知、且数据有噪声时，用密度聚类。

## 对照

| 对比项 | K-Means | DBSCAN / Mean-Shift |
| --- | --- | --- |
| 需预设簇数 | 必须 | 不需要 |
| 簇形状 | 近球形、大小相近 | 任意 |
| 噪声点 | 会被塞进某个簇 | DBSCAN 标为噪声 |
| 对参数敏感 | $K$（簇数） | $\varepsilon$、`min_samples`、带宽 |
| 簇内密度 | 不要求均匀 | **要求** |
| 计算量 | 约 $O(N\cdot K)$，便宜 | 邻域查询，$N$ 大时明显更贵 |

> [!warning] 密度聚类的隐藏假设
> 它把"稀疏"等同于"噪声"。如果数据本身密度差异很大（簇一大一小），DBSCAN 会把稀疏的大簇也吃掉。

## 一句话

> K-Means 问"离哪个中心近"，密度聚类问"哪里够密连得成片"。簇形状不规则时后者才靠谱。
