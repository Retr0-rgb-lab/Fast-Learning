# 特征提取 · 知识地图

本目录对应 **Lecture 4: Feature Extraction**。这一讲回答一个问题：**图像怎么变成数字，而且这串数字要经得起"换张图再比"的考验。**

课件原文见 [L4 Feature Extraction](<../../raw/L4-Lecture-Feature.extraction-v4.6.pdf>)。

## 阅读本目录的前提约定

本目录每篇笔记都遵守两条自我约束：

1. **场景不预设。** 任何例子（人像分组、LBP 的 3×3 邻域、SIFT 的金字塔……）都**从零完整解释**：样本是什么、任务是什么、每一步在做什么、为什么这么做。**不写"如上例所示"这种依赖前文的省略。**
2. **例子要么写全，要么改用通用例子。** 课件页码只作溯源标注，不是理解的前提 —— 单开一篇也能读懂。

## 全局 vs 局部：这一讲最该记住的分类轴

课件在 p29 / p34 / p43 / p85 反复画出同一棵分类树：

```text
图像特征提取算法
├── 全局特征 Global features ── 一张图压成"一个"向量
│   ├── 颜色特征 Color feature
│   │   ├── 颜色直方图 Color histogram   ← 课件细讲
│   │   └── 颜色矩 Color moment           ← 课后自学
│   ├── 纹理特征 Texture feature
│   │   ├── 灰度共生矩阵 GLCM            ← 课后自学
│   │   └── 局部二值模式 LBP             ← 课件细讲
│   └── 形状特征 Shape feature
│       └── 梯度直方图 HOG               ← 课后自学
└── 局部特征 Local features ── 一张图散成"多个"向量
    ├── 点特征 Point feature
    │   ├── SIFT                         ← 课件细讲（本目录重点）
    │   └── SURF                         ← 课后自学
    └── 局部二值模式 LBP
```

> [!warning] LBP 在树上出现两次，这不是笔误
> 课件把 LBP 同时列在 **纹理特征** 和 **局部特征** 下，因为它**兼有两种身份**：
> 作为纹理描述子时，一整张图统计出一个直方图，属于**全局**用法；
> 作为局部描述子时，逐点算出 0–255 的局部码，属于**局部**用法。
> 见 [[局部二值模式 LBP]]。

> [!note] 标"课后自学"的是课件自己没讲的
> p90 原文：`TODO: Study following concepts by yourself — 1. Mahalanobis Distance 2. Color Moment 3. HOG 4. SURF 5. The New Toy source code`。
> 这些在本目录**不展开**，只在此登记，以免误以为已经覆盖。
