# 交叉熵损失

衡量**真实标签分布 $p$ 和模型预测分布 $q$ 差多远**；预测越接近正确答案，损失越小：

$$
H(p,q) = -\sum_i p_i \log q_i
$$

分类任务里 $p$ 是 one-hot 标签（正确类为 1、其余为 0），公式塌缩成：**只惩罚"正确答案那一类的预测概率"**。它为什么长这样（信息论解释）见 [[交叉熵与信息熵]]。

## 二分类（BCE）

`binary_cross_entropy_with_logits`：先把模型输出 $z$（logits）变成概率，再算交叉熵。

1. Sigmoid 变概率 $\hat{y}\in(0,1)$（见 [[Sigmoid]]）：

$$
\hat{y} = \sigma(z) = \frac{1}{1+e^{-z}}
$$

2. 标签 $y\in\{0,1\}$，损失为：

$$
L = -\bigl[y\log\hat{y} + (1-y)\log(1-\hat{y})\bigr]
$$

含义很直白：

- 真实是 **1**：只看 $-\log\hat{y}$，$\hat{y}$ 越接近 1，loss 越接近 0
- 真实是 **0**：只看 $-\log(1-\hat{y})$，$\hat{y}$ 越接近 0，loss 越接近 0

数字例子（$y=1$）：$\hat{y}=0.9 \Rightarrow L=-\log 0.9\approx 0.105$；若 $\hat{y}=0.1 \Rightarrow L=-\log 0.1\approx 2.3$，错得很狠。

PyTorch 把 sigmoid 和 BCE 合在一起算（数值更稳），所以 `BCEWithLogitsLoss` 直接吃 **z 和 y**，不必自己先 sigmoid。

## 多分类

$C$ 类时，先 softmax 把 logits 变成概率（见 [[Logits、Softmax 与 argmax]]）：

$$
q_i = \frac{e^{z_i}}{\sum_j e^{z_j}}, \qquad L = -\log q_k
$$

k 是正确类别：**取正确类的概率，再取负对数**。正确类概率 0.99 → loss 很小；0.01 → loss 很大。

> [!warning] `nn.CrossEntropyLoss` = LogSoftmax + NLLLoss
> 输入应是 **logits**，不要先自己 softmax。

> [!note] 一批数据算的是什么
> 默认 `reduction='mean'`：先算批内每张图的 loss，再**平均**成一个标量，然后对这个标量 `backward()` **一次**。批内的"叠加"发生在 loss 函数内部，与 `.grad` 跨 batch 的累加是两回事——见 [[梯度累加与 zero_grad]]。

## 在训练中的位置

计算图上的 CE 节点：拿线性层输出 $z = xW+b$ 和标签 Y 算出标量 loss，`loss.backward()` 再把 $\partial L/\partial W$、$\partial L/\partial B$ 传回去（见 [[计算图与梯度跟踪]]、[[Autograd 自动微分]]）。

直觉：交叉熵在逼模型**把正确类的概率抬高**；它不是"导数等于 0 的解析解"，只是训练用的标量目标。
