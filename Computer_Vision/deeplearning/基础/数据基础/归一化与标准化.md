# 归一化与标准化

**把 Tensor 中的数值按统一规则缩放**，让模型更容易训练、收敛更稳定。常见两种，术语经常被混用：

## 两种方式

**1. 归一化（Min-Max，缩放到 [0,1]）**

图像像素原本 `0~255`，除以 255 变成 `0~1`：

```python
v2.ToDtype(torch.float32, scale=True)   # torchvision v2，scale=True 即除以 255
```

**2. 标准化（Z-score）**

$$
x' = \frac{x - \mu}{\sigma}
$$

先减均值 $\mu$，再除以标准差 $\sigma$，结果均值约 0、标准差约 1。严格说"标准化"指这种，但很多人把第一种也泛称为标准化。

## 图像按通道处理

图像 Tensor 常按 RGB 三个通道分别做，PyTorch 用 `Normalize(mean, std)`：

```python
output = (input - mean) / std
```

FashionMNIST 官方常用的均值/方差约为 `mean=[0.2860], std=[0.3530]`。

## 注意事项

- **Z-score 不防尾部**：离群点经 Z-score 后反而更夸张；要压极端值得用 clip、log 变换或鲁棒缩放（RobustScaler）
- PyTorch 官方教程 *Build the Basics*(https://pytorch.org/tutorials/beginner/basics/buildmodel_tutorial.html)只做到了 Min-Max 缩放到 [0,1]，**还没有做 Z-score**——目的只是"模型能算"的格式转换，不是完整特征工程
