# 池化（Pooling）

**池化**是 CNN 里一种"局部聚合 + 下采样"的操作：把特征图切成小窗口，每个窗口用一个固定规则合成一个数，从而把空间尺寸变小、通道数不变。

## 数学形式

设输入特征图为 $A\in\mathbb{R}^{H\times W\times C}$，窗口大小 $k\times k$、步长 $s$，输出 $P\in\mathbb{R}^{H'\times W'\times C}$：

$$
H'=\left\lfloor\frac{H-k}{s}\right\rfloor+1,\quad W'=\left\lfloor\frac{W-k}{s}\right\rfloor+1
$$

对每个通道 $c$ 和每个输出位置 $(i,j)$：

- **最大池化**：$P_{i,j,c}=\max\limits_{(u,v)\in\text{window}} A_{i\cdot s+u,\;j\cdot s+v,\;c}$
- **平均池化**：$P_{i,j,c}=\frac{1}{k^2}\sum\limits_{(u,v)\in\text{window}} A_{i\cdot s+u,\;j\cdot s+v,\;c}$

> [!note] 无可学习参数
> 池化只是确定性运算，不像卷积层有需要训练的权重。

## 池化的作用

| 作用 | 含义 |
| ---- | ---- |
| 降维提速 | 缩小高宽，减少后续层计算和参数 |
| 扩大感受野 | 让更高层神经元"看到"更大输入区域 |
| 平移不变性 | 小范围位置变化不太改变池化结果 |
| 抑制噪声 | 平均池化尤其平滑；最大池化突出最强响应 |

## 最大 vs 平均

- **最大池化（max pool）**：保留窗口内最强激活，强调"是否有某特征"
- **平均池化（avg pool）**：取窗口平均，常用于平滑；**全局平均池化（GAP）**常做分类前的聚合

## 反向传播

- **最大池化**：前向时**记录最大值位置**，反向时只把梯度传回该位置，其余为 0（"梯度只回到真正影响输出的那个像素"）
- **平均池化**：把上游梯度均匀分摊到窗口内所有位置（每个位置 $\frac{1}{k^2}$ 倍）

## 手算例子

$2\times2$ 输入 $A=\begin{bmatrix}3&1\\4&2\end{bmatrix}$，$2\times2$ max pool → $p=\max(3,1,4,2)=4$，输出 $1\times1$。

反向时若 $\frac{\partial L}{\partial P}=2$：最大值位置 $(1,0)$ 得到全部梯度 $2$，其余为 $0$：
$\frac{\partial L}{\partial A}=\begin{bmatrix}0&0\\2&0\end{bmatrix}$。

## `nn.MaxPool2d` / `nn.AvgPool2d`

```python
nn.MaxPool2d(kernel_size=2, stride=2)   # 2×2 窗口，步长 2 → 高宽折半
nn.AvgPool2d(kernel_size=2, stride=2)
```

参数语义和卷积层类似：`kernel_size`、`stride`、`padding`。现代网络里也常用**自适应池化** `nn.AdaptiveAvgPool2d(output_size)` 直接指定输出尺寸（如 `(1,1)` 做 GAP）。
