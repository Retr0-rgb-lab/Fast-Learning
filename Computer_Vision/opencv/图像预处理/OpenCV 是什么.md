# OpenCV 是什么

**OpenCV** = 开源计算机视觉库。覆盖从像素处理到传统视觉、视频分析、部分模型部署的整条视觉数据链路。

## 一句话区分

- **PyTorch**：搭建和训练神经网络的引擎
- **OpenCV**：让程序读取、处理、理解图像和视频的工具箱

## 5 大能力

1. **图像基础处理**：读写、显示、裁剪、缩放、旋转、翻转；颜色空间转换（BGR↔灰度↔HSV）；模糊、锐化、阈值化
2. **图像分析**：找边缘、轮廓、直线、圆、角点、局部特征；扫描文档边界、检测硬币、拼接全景
3. **视频与摄像头处理**：打开摄像头/视频文件、逐帧处理、背景消除、光流估计、运动跟踪
4. **几何与三维视觉**：透视矫正、相机标定、镜头畸变校正、双目视觉、三维重建
5. **配合深度学习部署**：OpenCV 读取/预处理图像 → PyTorch 模型推理 → OpenCV 画检测框

## 一个典型例子：人脸检测

- **OpenCV**：打开摄像头、取每一帧、调整尺寸和颜色格式
- **PyTorch**：让训练好的模型判断"哪里是人脸"
- **OpenCV**：把人脸框和置信度画回屏幕

## OpenCV 边界

- 有 `cv2.dnn` 模块能跑部分模型，但**不是**训练大型深度网络的主力
- 不擅长：训练、GPU 自动求导、大规模分布式——这些是 PyTorch 的领域
