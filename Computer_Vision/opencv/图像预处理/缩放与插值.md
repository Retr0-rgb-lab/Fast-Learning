# 缩放与插值

把图片按比例映射像素到新尺寸。目标像素位置常不在整数格点——**插值**就是决定新像素颜色怎么取的规则。

## `cv2.resize` 基础

```python
img = cv2.imread("cat.jpg")              # (H, W, 3) BGR
resized = cv2.resize(img, (224, 224))    # dsize 是 (width, height)，不是 (H, W)
```

> [!warning] `dsize` 是 `(宽, 高)`
> `cv2.resize(img, (W, H))`——**不是** NumPy 的 `(H, W)` 顺序。最容易写反。

按比例缩放：

```python
small = cv2.resize(img, None, fx=0.5, fy=0.5)   # 宽高各缩一半
```

`dsize` 和 `fx/fy` 二选一即可。

## 插值方法怎么选

| 场景 | 方法 | 原因 |
| ---- | ---- | ---- |
| 缩小 | `INTER_AREA` | 按像素面积采样，缩小更干净 |
| 放大 | `INTER_LINEAR` 或 `INTER_CUBIC` | 双线性够用；立方更平滑、更慢 |
| 默认 / 实时 | `INTER_LINEAR` | 速度和质量折中 |

默认就是 `INTER_LINEAR`。缩小建议显式写 `INTER_AREA`。

### 3 种插值对比

| 方法 | 邻域 | 本质 | 观感 |
| ---- | ---- | ---- | ---- |
| 最近邻 (INTER_NEAREST) | 1 个 | 复制最近像素 | 块状、快 |
| 双线性 (INTER_LINEAR) | $2\times2=4$ | 两方向线性 | 较平滑，略糊 |
| 双三次 (INTER_CUBIC) | $4\times4=16$ | 两方向三次曲线 | 更细，更慢 |

像素画用最近邻保硬边；照片放大常用双线性/双三次。

## 为什么是 2D 插值

1D 插值：一条线上两点之间估一个值。图像是**二维网格**，新点落在 $(10.3, 20.7)$ 这样的非整数位置时，必须同时看左右和上下，所以是 2D 插值。

**bi-** 就是"两个方向各做一次"——双线性就是先沿 x 插一行、再沿 y 插一列。

## 为什么放大 10 倍有"马赛克"感

最近邻插值每个原像素被复制到附近 $10\times10$ 个新像素，相邻原像素颜色差放大后变成整块同色方块。**不是差别被数学上乘大**，而是**同一颜色被铺成更大的色块**。换双线性/双三次，边缘就会平滑。

## 直接拉伸 vs Letterbox

直接 `resize` 到正方形会把物体压扁。检测模型（如 YOLO）更常用 **letterbox**：按比例缩放到最长边贴合目标尺寸，再补灰边：

```python
h, w = img.shape[:2]
r = min(640 / h, 640 / w)
new = (int(w * r), int(h * r))
resized = cv2.resize(img, new, interpolation=cv2.INTER_LINEAR)
pad = cv2.copyMakeBorder(
    resized,
    0, 640 - new[1], 0, 640 - new[0],
    cv2.BORDER_CONSTANT, value=(114, 114, 114)
)
```

分类网络（ResNet 之类）通常直接拉伸或先缩放再中心裁剪，不一定 letterbox。

## 一句话

> 缩放 = 映射到目标格子；非整数位置的颜色 = 用插值估计。
