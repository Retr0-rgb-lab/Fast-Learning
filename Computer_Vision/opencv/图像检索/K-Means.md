# K-Means

无监督地把相似样本分组。理想目标：**簇内距离小**、**簇间距离大**。

## 分配—更新循环

1. 随机初始化 $K$ 个聚类中心；
2. 计算每个样本到各中心的距离，**分配**给最近的那个；
3. 得到当前轮的**簇分配（cluster assignment）**；
4. 对每个簇内的所有样本取**均值**，作为新中心；
5. 回到第 2 步，重复到**收敛**——样本不再换簇，或簇分配变化小于阈值。

```text
随机 K 个中心
   ↓
分配：每个样本归最近的中心        ← 得到本轮簇划分
   ↓
更新：每个簇内取均值 → 新中心
   ↓
收敛了吗？没有就回去重新分配
```

> [!warning] 第 3 步的产物不叫"分类图"，叫**簇分配**
> K-Means 是无监督学习，簇编号本身**没有**预先给定的类别语义。cluster 3 就是 cluster 3，不等于"猫"。

## 为什么更新中心要取均值

因为**均值让簇内平方误差和最小**。记 $\mathcal{C}_1,\dots,\mathcal{C}_K$ 为 $K$ 个簇（花体是"样本集合"），$\boldsymbol{\mu}_k$ 为第 $k$ 个簇的中心。固定簇归属时，目标函数是

$$
J=\sum_{k=1}^{K}\sum_{\mathbf{x}\in\mathcal{C}_k}\lVert \mathbf{x}-\boldsymbol{\mu}_k\rVert^2
$$

对中心 $\boldsymbol{\mu}_k$ 求梯度并令其为零：

$$
\frac{\partial J}{\partial\boldsymbol{\mu}_k}=2\sum_{\mathbf{x}\in\mathcal{C}_k}(\boldsymbol{\mu}_k-\mathbf{x})=0
\quad\Rightarrow\quad
\boldsymbol{\mu}_k=\frac{1}{|\mathcal{C}_k|}\sum_{\mathbf{x}\in\mathcal{C}_k}\mathbf{x}
$$

也就是说：**取均值是在"归属不变"这个前提下，一步到位的最优位置。** 每次更新中心都在下降 $J$，所以这个循环会朝更好的解走。

对比"随机挑一个簇内样本当中心"：

| | 取均值 | 随机挑一个点 |
| --- | --- | --- |
| 是否保证 $J$ 不增 | 是 | 否，可能变差 |
| 是否依赖随机数 | 否，可复现 | 是，结果不可复现 |
| 几何含义 | 簇的几何中心 | 簇里的某个成员 |

## 五条局限

- **$K$ 必须预先设定**——过大过小都影响结果；
- **随机初始化不同 → 结果不同**（可能停在不同局部最优）；
- 假设簇围绕中心、**近似球形且大小相近**；
- **对离群点敏感**——离群点会把中心拽走；
- 每个样本必须属于某一簇，**没有"噪声"这个出口**。

对应的补救：

| 局限 | 常见做法 |
| --- | --- |
| $K$ 要预设 | 肘部法 / 轮廓系数选 $K$；或改用 [[密度聚类]]，完全不用预设 |
| 随机初始化 | **k-means++** 初始化（先按距离平方加权撒点），或多次重启取 $J$ 最小的结果 |
| 簇形状非球形 | 换 [[密度聚类]] |
| 离群点敏感 | 先做离群点检测并剔除；或用带噪声标签的变体 |

## 附带辨析：强化学习不属于无监督学习

K-Means 是典型的**无监督学习**——训练数据只有输入、没有标签，目标是发现数据内在结构。这类方法在本讲里出现过 K-Means、DBSCAN、PCA。

**强化学习不属于无监督学习**：它与环境交互、接收奖励信号来学策略。奖励虽不是每个样本的标准标签，但它是**明确的外部反馈信号**，作用上等价于一种标签。有/无标签这条线，比"有没有输出"这条线更能区分三者。

## 一句话

> K-Means = 分配—更新—收敛。取均值不是随便选的，是簇内平方误差的最小化解。
