# CBIR 基于内容的图像检索

**CBIR（Content-Based Image Retrieval）**：不用人工标签、文件名或文字描述，直接利用图像的视觉内容（特征）寻找相似图像。

课件里的例子是 IMHere 这个"我在这里"类的社交游戏：用户上传一张代表自己当前位置的照片（token）当线索，系统在已注册的照片库里找出内容最接近的一张。

## 流程

```text
离线：数据库 N 张图 ──特征提取──> x1, x2, ..., xN（存起来）

在线：查询图 ──特征提取──> q
                        ↓
              计算 q 与每个 xi 的相似度/距离     ← O(N)
                        ↓
              按相似度排序 → ranked list → Top-K
```

1. **预处理**：为数据库每张图提取并保存特征向量；
2. 用户上传 query，提取它的特征向量；
3. 与每个数据库向量比较；
4. 按相似程度排序，形成 ranked list；
5. 返回最相似的若干张。

判据不是"像素是否完全相同"，而是**特征向量是否接近**（见 [[图像特征空间]]）。

> [!warning] 前提：q 和 x_i 必须同维同源
> 查询图和库里的图必须用**同一套特征提取器**，得到同维度、同语义的向量。换了提取器，距离不可比。
> 另外 q 是 1 个向量、$x_i$ 也是 1 个向量，**一个对一个**——这个假设在 [[Bag of Visual Words]] 里会被打破。

## 检索 ≠ 分类

> [!warning] 本课件措辞里"然后进行分类"要纠正
> CBIR 的首要任务是**检索与排序**：返回最相似的 Top-$K$ 图像。
> **分类**是把样本赋予**预先定义**的类别，比如"猫 / 狗 / 汽车"。CBIR 没有标签体系，返回的是相似度序，不是类别。

## 与 K-Means 的分工

| | 输入 | 产出 |
| --- | --- | --- |
| **K-Means** | 整个数据集 | 自动分组，无 query |
| **CBIR** | 一张 query | 库内的相似度排序 |

**最基本的 CBIR 不需要先做 K-Means**——直接逐张比较就行。K-Means 是在下一步作为一种"索引"思想，用来让大规模检索变快（见 [[粗到细检索]]）。

## 例子

query 与库中三张图的距离分别是 $0.2$、$1.1$、$0.5$。按距离升序，检索结果依次是：$0.2$ → $0.5$ → $1.1$。

排序依据：距离越小越相似，所以升序排。（若用余弦相似度则降序。）

## 一句话

> CBIR = 把 query 变成向量，在库里逐个比距离，排序取 Top-K。$O(N)$ 是它唯一的硬伤。
