# 复习自测题

本讲（Lecture 5: Image Retrieval）的自测题汇总。**先自己答，再回笔记核对**——每题后面括号里是答案在哪一篇。

## 必须记住的数字

| 场景 | 答案 | 出处 |
| --- | --- | --- |
| 100 万张图、每次比较 100 ms，朴素 CBIR 一次查询 | 约 **27 小时** | [[粗到细检索]] |
| 朴素 CBIR 查询阶段复杂度 | $O(N)$ | [[CBIR 基于内容的图像检索]] |
| 10 000 张图分 100 簇，粗搜后进 top-2 | 粗搜 100 + 精搜 200 = **300** 次 | [[粗到细检索]] |
| PCA：512 维降 2 维时投影矩阵 $W$ 的形状 | $512\times2$ | [[降维与 PCA]] |
| PCA：$X_c\in\mathbb{R}^{N\times512}$、$k=2$ 时 $Z$ 的形状 | $N\times2$ | [[降维与 PCA]] |
| PCA 与 SVD 的换算 | $\lambda_i=\sigma_i^2/(N-1)$ | [[奇异值分解 SVD]] |
| 奇异值与 $A^TA$ 的关系 | $A^TA\mathbf{v}_i=\sigma_i^2\mathbf{v}_i$ | [[奇异值分解 SVD]] |
| 簇内平方误差的梯度解 | $\boldsymbol{\mu}_k=$ 第 $k$ 簇内所有样本的均值 | [[K-Means]] |

## 一句话串起 K-Means / CBIR / BoVW

- **K-Means**：不给 query，把整个库自动分成 $K$ 组。
- **CBIR**：给了 query，在库里按相似度排序返回 Top-K。
- **BoVW**：局部特征数量不定，用视觉词典量化成固定长度词频直方图，好让 CBIR 能比。

## 一句话总纲

```text
图像 → 特征向量 → CBIR 相似度检索
大量图像 → 聚类索引 → 先粗后细加速
多个局部 descriptor → BoVW 词典 → 词频直方图 → 检索
高维不可视 → PCA / t-SNE → 观察结构与可分性
```
